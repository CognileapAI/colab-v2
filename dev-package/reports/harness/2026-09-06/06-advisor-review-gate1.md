# Advisor review — harness-fable51 design-draft (gate ①, 2026-09-06)

## Verdict: NO-GO as written → GO-with-conditions after the edits in §3

For: The diagnosis is right (73 candidates, 2.4MB bootstrap, 22 frictions that live in human memory), the constraints are honored on paper (main = orchestrator, advisor 3 gates kept, autonomy block only in lane-worker/researcher, serial lanes, no worktree/parallel hook duplication), and the rollback section (archive → verify → delete) is sound. Abandoning it means another round of "remember the workaround" sessions.

(2) `gates/run.sh` already implements green / red(판정) / red(준비) with exit 78 and `::gate-readiness-failure::` markers and a counted summary (run.sh:452-493) — P2 as designed rewrites a working 3-state into a 4-state that adds a `SKIP` escape hatch the repo explicitly forbids (run.sh:39 "대상 0건은 전부 red", CLAUDE.md §4). Presenting this to Ted now would sell a phase that undoes his own fail-closed design and a folder layout that doesn't run.
