## CoLAB에서 우선순위가 높은 G2 격차

1. (e) ADR 검사 코드(`adr_gate.py`)는 있는데 실행하는 게이트·CI가 없다. `docs/decisions` 6건이 PR 본문 검사를 거칠 때만 간접 검증된다. 비용은 게이트 1개이고 새 훅이 필요 없다.
2. (d) `hook_names`에서 settings.json 배선으로 가는 방향의 drift는 검출되지 않는다. shim과 원본은 있는데 settings.json에서 등록이 빠지면 `harness-contract`와 `agent-bridge check`가 모두 green이다(bridge는 Claude와 Codex의 대칭만 본다). 보안 훅 4개가 조용히 꺼질 수 있는 경로다.
3. (c) 사용자 절대경로 검사가 없다. WSL `/home/ttlhi10/...`와 Windows 경로를 함께 쓰는 저장소이고 에이전트가 `.agents/**`·`docs/**`를 쓴다. 게이트 확장만으로 막을 수 있다.
4. (b) 기존 PreToolUse 가드는 Edit|Write만 보고 Bash `sed -i`·`>`를 보지 않는다. 생성물 선언 목록(`protected_paths`)도 없다. 우선순위는 3보다 낮다: 사후 게이트(`generated-up-to-date`, `migration-drift`)가 있다.
5. (a)(f)는 도입 비용이 크다: (a)는 Codex 대칭 예외와 `/hooks` 재신뢰가 필요하고, (f)는 drvfs 실행 비트·worktree별 hooksPath 문제가 있다. 효과가 보고 형식과 사람 커밋에 한정되므로 후순위다.

## 미확인
- `core.hooksPath`는 `.git/config`를 직접 읽어 확인했다(git 명령은 격리 제약으로 실행하지 못함). worktree별 `config.worktree`는 확인하지 않았다.
- git-guard의 5개 열거 항목별 테스트 유무는 `test_agent_bridge.py` 전문을 읽지 않아 확정하지 못했다.
