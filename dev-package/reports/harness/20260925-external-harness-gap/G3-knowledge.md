## G3 에서 CoLAB 에 중요한 갭 (우선순위)

1. **b1 상시 로드 줄 상한 부재** — AGENTS.md 가 읽도록 지시하는 규칙 합계 578행에 상한·검사 0건. `bootstrap-diet.sh` 는 비차단 안내뿐. 외부처럼 `harness.yaml` 선언 + `config.py` 검사를 두면 규칙 비대가 PR 단계에서 드러남. 비용 대비 효과 최대.
2. **a1/a2 판정 기준·변경 절차 부재** — 원칙이 ADR 6건·colab-rules·스펙에 흩어져 새 기제 추가 시 판정 자리가 없음. 단 외부 원칙 1·2는 우리 ADR-0005·intent 커밋 관행과 반대 방향이므로 문구 이식이 아니라 우리 결정에 맞춘 4~5줄 판정 질문으로 작성해야 함.
3. **c2 vendored 재현성** — mattpocock·superpowers 출처에 커밋 SHA 없음(`VENDORED.md:31-32`). 개조본이라 vendor 도구는 부적합하나 SHA·해시 기록은 저비용.
4. **c1 문서 드리프트** — `dual-agent.md:39` "공통 스킬 13개" vs 실측 17(+Codex 전용 1). symlink 전환 여부와 별개로 즉시 정정 대상.
5. d1(eval)·e1(역할)·f1(템플릿)은 우리 쪽이 동등 이상 — 외부에서 가져올 것 없음.
