# AI 검색 개발 — WSL stage 시험 직전 인계

사용자 범위: dev 배포 없이 개발·로컬 검증·stage 시험 준비까지. dev/stage 배포·원격 데이터 쓰기·main push·모델 호출 없음. 현재 변경은 `codex/stage3-next`의 미커밋 작업이다.

## 구현

- 파일별 근거 초안·확인 저장, 원문/출처/hash, 확인 주체·시각, 수정 충돌 검사.
- 대상 파일 교체 시 stale. 파일 삭제 시 근거 정리. 연구실·본문 접근·편집 권한 유지.
- 접근 가능한 최신 확인 근거로 역할·기간·모델·변수 등을 검색하고 확인/불일치/미상을 구분한다. 자료 품질은 근거 없이 보장하지 않는다. 원래 잠긴 메타 후보와 순위·이어보기 규칙을 유지한다.
- 상세에서 근거 읽기·편집·확인·재확인. 편집 권한 없는 본문 접근 독자는 출처를 읽을 수 있다.
- 실제 레퍼런스 9묶음의 본체97파일 입력 묶음, 원문 변경 검사, stage 실제 파일 ID를 읽어서 연결하는 사전 검사/초안 입력 도구.

## 검증

- core-api 전체: 1152 통과, 실패0, skipped0, e2e표식6 제외. 최종 기간 방어 변경은 별도로 순수 조건11건 및 레퍼런스12문항 API 시험을 재실행해 통과했다.
- 레퍼런스 통합: 일회용 DB에 실제 메타 snapshot과 파일 식별을 구성하고 공개 API로 근거97건 확인 저장, 골든12문항 후보·품질 미상·직접관측 불일치·역할·잠긴 원문 비노출 확인. 파일 수치 데이터를 가공한 시험은 아니다. 해석 단계는 고정 HTTP 대역이다.
- 실제 브라우저: 초안 저장→확인 저장→새로고침 유지→검색 근거→상세 이동→로그아웃 통과. 일회용 DB·실제 core/frontend, 해석 HTTP 대역, 종료·정리 exit0.
- eval 도구43건, 타입검사, 프로덕션 빌드, 계약 lint·seam·생성물13건·import경계8건·migration단일head·RLScoverage·작업 대장 통과.
- schema diff는 격리 backend 사본의 전용 tmpfs DB에서 두 체인 drift0. 부모 사본의 schema/migration 파일이 그 사본과 바이트 일치함을 확인했다.
- 전체 frontend: WSL 내부 동일 소스 사본105파일1261건 통과. Windows 마운트에서의 앞선 전체 실행은 exit143으로 중단됐으며 통과로 세지 않는다.
- AI 서비스 기존 검증142건 이후 해당 소스 hash 변경0. 실제 모델 평가는 보류한 상태다.

## 수정과 한계

통합 중 빈 ID 목록 SQL 타입 오류와 데이터셋 속성명 오류를 재현해 수정했다. 근거 후보가 원래 주제/잠긴 후보를 지우는 문제, SPI 예외가 다른 부정을 무시하는 문제, 축약 날짜 범위를 첫 달/첫날로 축소하는 문제를 수정했다. 마지막 코드·사양 독립 검토는 approve다.

초기 브라우저의 좌표 클릭이 React 동작으로 이어지지 않아 실패했고, 실제 키보드 focus/Enter/Space 및 입력으로 전체 저장 여정을 검증했다. API를 직접 호출하거나 DOM click으로 브라우저 저장을 대신하지 않았다.

O1은 현재 지원 조건과 레퍼런스 범위의 로컬 검증까지 충족하며, 보류한 실제 모델·stage 의미 품질 전체 충족은 주장하지 않는다. O2·O3의 역할/근거/한계와 O4 상세 이동을 로컬 API/화면으로 확인했다. O5의 실제 보유 강수·식생·가뭄 및 최초 골든 문항을 유지했다. 이번 로컬 개발 범위를 넘는 추가 기능은0건이다. 전체 K4 완료 정의와 A층 과거 미결은 닫지 않았다.

원문은 수집 당시 붙여 넣은 사본이다. 외부 DOCX 수정 자동 감지나 근거 전체 편집 이력 영구 보관은 구현 범위가 아니다. 기존 DB 설명은 덮어쓰지 않는다. 기간 경계가 연속 관측/결측률 보장은 아니다. 해석 불가능한 복합 조건은 확정 필터로 사용하지 않는다.
