## 결정과 종료 조건

현재 배포 오케스트레이터가 보존 결정과 이 기록의 책임을 맡는다. 원본 기록이 사라진 캐시의 이미지 바이트는 스냅샷만으로 복원할 수 없으므로, 배포 과정에서 증거를 잃지 않도록 기존 파일을 그대로 보존한다. gate가 제공하는 exact-key 정책에 아래 9키만 선언한다. 고아가 없어진 것으로 보고하지 않으며 검사 결과에 보존 9건을 표시한다.

원본 행이 복원되거나 별도 캐시 회수 승인이 주어지면 해당 키를 재분류하고 보존 선언을 해제한다. 회수는 기존 invalidation 경로를 사용하며 이 결정은 삭제·이동·DB 변경을 허용하지 않는다. 새로 발견한 고아는 자동 추가하지 않고 계속 red로 판정한다. 배포 후 같은 검사로 새 미선언 고아가 없는지 확인한다.
