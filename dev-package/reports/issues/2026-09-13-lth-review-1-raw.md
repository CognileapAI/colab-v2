## 4. 개선 항목

#### I-1 계산된 가공 단계와 선택한 단계가 달라도 별도 확인 없이 허용됨

- 권장 조치: 차이가 생긴 이유와 두 값의 근거를 함께 보여 준다. 기본값은 계산 결과로 맞춘다. 사용자가 다른 단계를 유지하려면 사유 입력과 명시적인 확인을 거치게 한다. 불일치 상태를 목록과 검토 화면에도 표시한다.

### 보통

- 판단: 검색 결과 수 자체의 오류로 단정하기보다는 전체 연구실 보기와 우리 연구실 검색의 범위가 화면에서 섞여 보이는 문제다.
- 권장 조치: 검색창 옆에 우리 연구실 25건에서 검색처럼 범위를 먼저 표시하고, 필요하면 전체 연구실과 우리 연구실을 고를 수 있게 한다.

#### I-3 미검증 상태의 표현이 직관적이지 않음

- 영향: 색상과 취소선을 자세히 보지 않으면 검증 완료 상태로 오해할 수 있다.
- 권장 조치: 미검증, 요청 없음, 검토 대기처럼 실제 상태를 한국어로 표시하고 상태별 색상과 도움말을 통일한다.

#### I-4 모바일 계정 표에 좌우 이동 안내가 없음

- 영향: 화면 오른쪽에 있는 상태, 최근 로그인, 비밀번호 재설정, 비활성화 작업을 발견하기 어렵다.
- 권장 조치: 표 위에 좌우 이동 안내를 추가하고, 이메일 열을 고정하거나 모바일용 카드 목록을 제공한다.

#### I-5 현재 로그인한 계정의 비활성화 동작을 더 안전하게 보호할 필요가 있음

- 권장 조치: 본인 비활성화를 막거나, 다른 사용 가능한 관리자가 있는지 확인한 뒤 계정명 입력과 재확인을 요구한다.

- 잘못된 로그인 정보에 대한 오류 안내와 경고 영역 제공

## 7. 권장 처리 순서

1. 연구실 전환 버튼의 동작 또는 비활성 상태를 확정한다.
2. 가공 단계 불일치에 확인 절차와 상태 표시를 추가한다.
3. 비활성 계정의 권한 노출과 현재 계정 비활성화 보호를 정리한다.
4. 프로젝트 카드, 본문 영역, 제목 단계의 접근성 결함을 수정한다.
5. 검색 범위와 검증 상태 문구를 명확하게 바꾼다.
6. 모바일 표 안내, 빈 상태, 로그인 재입력, 오탈자를 정리한다.
