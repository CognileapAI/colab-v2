## 5. 기획자에게 되돌릴 것

- 「할 일 함」 = 오탈자가 아니라 정한 용어다. 같은 표기가 화면 2자리 ＋ 계약 설명 ＋ 도메인·권한 원칙·작업 단위 문서 ＋ 정본 개정 기록에 쓰였고, 「할 일함」·「할일함」·「할 일 목록」 표기는 레포 전역 0건이다(계수 기준 = 해당 문자열 grep). 바꾸려면 기획 정본을 먼저 고치고 목업 패키지·계약 설명·화면 2곳을 한 회차에 함께 움직인다 — 권고는 현 표기 유지.
- 로그인 실패 시 이메일 삭제 = 코드에서 확인되지 않는다. 실패 처리에서 지우는 것은 비밀번호뿐이고 이메일을 지우는 호출은 레포에 없다. 브라우저 자동완성·비밀번호 관리 도구 개입 가능성이 남으므로 **관측 1건을 요청한다** — 잘못된 자격으로 제출한 직후 이메일 칸의 값이 비는지, 비밀번호 관리 도구 확장을 끈 상태에서도 같은지.
