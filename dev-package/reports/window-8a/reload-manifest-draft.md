## 3. 입력 형태 — `load-seed.py` 가 실제로 읽는 것

`run()` → `manifest["datasets"]`, `_files_of()` → `f["path"]` · `f["kind"]`. `--round` 는 **데이터셋 단위 필터**다.

```json
{ "datasets": [ { "key": "D-07", "round": 3, "name": "…", "topic": "…", "summary": "…",
    "files": [ { "path": "<--source-root 기준 상대>", "kind": "본체" },
               { "path": "…", "kind": "기준 격자 파일" } ] } ] }
```

`kind` 는 **정확히 두 값**(`본체` · `기준 격자 파일`)이고 도구가 이름을 **완전 일치**로 대조한다.
부르는 op 은 넷뿐 — `listDatasets` · `createUpload` · `createDataset` · `attachUploadGridFiles`. **DB 에 접속하지 않는다.**

⚠ **회차 ⑦(기준 격자)은 별도 회차로 분리되지 않는다** — 격자 6건은 소속 데이터셋의 회차(③·⑥)에 함께 실린다.

## 5. 「지어내지 않은 것」 — 이 초안이 답하지 않는 물음

1. **`#28` 이 지금도 열린 블로커인가.** 확정판 매니페스트 2건이 실재하는데 `§4 #28` 은 여전히 열려 있다 —
   **문서가 실물보다 낡은 쪽**으로 보이나, 이 회차는 그것을 **판정하지 않았다**. `[미확인]` · 푸는 법 = `#28` 을 연 회차의
   미해결 하위 쟁점(있다면)을 `sessions/S2-BLOCKER-INVESTIGATION.md` 에서 대조하는 것.
2. **`rdr_500m_latlon.nc` ↔ `Lat_HSR.npy`/`Lon_HSR.npy` 값 불일치.** `DATA-REFERENCE.md` 가 **열린 질문**으로 명시한 자리다.
   어느 쪽이 정본 격자인지 이 회차가 **정하지 않았다** — 매니페스트가 이미 고른 6건을 그대로 둔다.
3. **RN15(`D-08`) 표준위도 결손.** 헤더에 표준위도 1개뿐이라 재현 시 위도 1.8 km · 경도 1.6 km 오차.
   `LAT_RN15.npy`/`LON_RN15.npy` 를 그대로 쓰는 것 외 대안이 없다(문서 스스로 명시). **지어낼 수 없다.**
4. **계획치 139 의 원본 대조.** `S2-EXEC-PLAN §8` 회차표까지 거슬러 세지는 않았다 — `_계수` 의 자기 설명을 인용만 했다.
5. **적재 뒤 멱등 판정.** 도구는 **이름 완전 일치**로 건너뛴다. dev 는 카탈로그가 비어 있을 것이므로 **전건 신규 적재**가
   예상되나, 이 회차가 dev 를 **조회하지 않았으므로** 그 예상을 실측으로 적지 않는다. `[미확인]`
