- 근거 ⑵ — 게이트가 남긴 `…account-admin.light.png` 에 **「Co-Lab · 로그인 · 이메일 · 비밀번호 ·
  들어가기」 카드**가 찍혀 있다. 계정 목록 표는 한 줄도 없다.
- 근거 ⑶ — 같은 사실을 게이트 밖에서 직접 재현했다. 로그인 전 `design` 세션에서
  `/account-admin` 을 열자 `get count ".account-table"` = **0**, `get count ".login-submit"` = **1**.

따라서 **표 본문·고정 열의 computed 글자 크기와 대비는 이 게이트가 판정하지 않았다**(ⓖ 미측정).
「페이지 1건 · 13px 미만 0건」은 로그인 화면에 대한 참이다. 이 레인이 남긴 계정 목록 화면의
시각 근거는 `images/` 의 라이트·다크 스크린샷이고, 그것은 **사람이 보는 근거이지 계측이 아니다.**

이 회차에 로그인 상태를 그 세션에 심어 다시 재려 했으나 성립시키지 못했다 — 호스트 뮤텍스를
쥔 옛 데몬을 죽이는 과정에서 그 세션의 chrome 이 함께 죽어 로그인이 날아갔고, 다시 로그인한
뒤에도 `AuthGate` 가 재인증 오버레이 상태(목록 6행과 로그인 폼이 동시에 잡히는 상태)로 남았다.
**억지로 green 을 만들지 않고 미측정으로 남긴다.**

## 후속으로 올리는 것 (이 이슈 범위 밖 · 이 레인이 실행 중 만난 것)

- **`frontend-visual` 은 인증이 필요한 화면을 조용히 로그인 화면으로 잰다.** 판정부
  `live_audit.sh` 는 `${AB_SESSION:-design}` 세션으로 URL 을 열고, 그 세션에 로그인 상태가
  없으면 `AuthGate` 가 `LoginPage` 를 세운다. **실측으로 확인했다** — 로그인 전 `design` 세션에서
  `/account-admin` 을 열자 `.account-table` 0건 · `.login-submit` 1건이었다. 그런데도 게이트는
  「페이지 1건」으로 세어 요약만 보면 계정 관리 화면을 잰 것처럼 보인다 — green-by-skip 에
  가까운 자리다. `live_audit.sh` 머리말은 그 세션에 미리 로그인해 두면 된다고 적지만,
  **이 레인은 시도했으나 성립시키지 못했다**(그 세션의 chrome 이 뮤텍스 정리 중 함께 죽었고,
  다시 로그인한 뒤에도 재인증 오버레이 상태로 남았다). 게이트가 ⑴ 그 전제를 출력에 찍거나
  ⑵ 로그인 화면으로 떨어진 것을 감지해 드러내는 수정이 필요하다.
- **호스트 뮤텍스를 쥔 채 남은 `agent-browser` 데몬이 다음 회차의 게이트를 막는다(#120 재발).**
  이번 회차에서 `frontend-test` 가 `flock -w 900` 에 걸려 **약 4분** 멈춰 있었다. 잠금
  `/tmp/colab-v2-gate-host-mutex/host` 를 `fuser` 로 보니 **8시간 전(10:24)에 뜬** 데몬
  `agent-browser-linux-x64`(pid 2363839)와 그 chrome(2363853)이 fd 를 쥐고 있었다 — 이 레인이
  띄운 데몬(3080485)이 아니라 **이전 회차가 남긴 것**이다. 그 둘을 죽이자 즉시 풀렸다.
  #120 보고서가 올린 것과 같은 결함이고, 고쳐지지 않아 **다음 회차가 또 걸렸다.** 게이트가
  브라우저를 부를 때 fd 를 닫거나(`flock --close`) 잠금 밖에서 부르는 수정이 필요하다.
- **`COLAB_GATE_REPORT_DIR` 와 `COLAB_TASK_ID` 는 함께 쓸 수 없다.** 함께 주면 실행기가
  `explicit report directory differs from current task run` 준비 실패(78)로 막는다
  (`gates/run.sh` :45). #120 회차가 같은 자리를 만났고 이번에도 같았다 — 문서(`docs/development/dual-agent.md` :138)
  의 예시는 task 없는 경로용이라는 사실이 그 자리에 적혀 있지 않다.
- **`.account-row-note` 의 `overflow: hidden` 이 flex 줄 높이를 0.5px 바꾼다.** 위 ⓘ 참조.
  표 행 높이를 픽셀로 잠그고 싶은 자리라면 이 상호작용을 알고 있어야 한다.
