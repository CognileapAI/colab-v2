|---|---|---|
| 27 대표 그림 | 별도 이미지 저장·소유권 검사·데이터셋 연결·Bearer 조회를 추가했다. 등록 뒤 이미지 저장 실패는 생성된 ID를 보존해 이미지 PUT만 재시도하고, 교체·삭제 뒤 자동 미리보기로 복귀한다. | 잘못된 PNG 거절 뒤 데이터셋 1건/대표 그림 0건, 같은 ID에 정상 PNG 재시도 뒤 1건. 상세 reload·교체·삭제·자동 그림 decode까지 브라우저 21단계에서 확인 |
