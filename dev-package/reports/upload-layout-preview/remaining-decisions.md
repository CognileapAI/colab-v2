# 남은 저장·조회 범위 결정

상태: 2026-09-09 사용자 승인 — 세 항목 모두 포함. Astra 계획 검토의 저장·권한·수명 조건을 반영해 Sol 개발 중이다.

| 정책 | 현 상태와 충돌 | 포함 시 구체적 구현 | 제외 시 남는 차이 |
|---|---|---|---|
| 27 대표 그림 | 사용자가 고른 그림은 objectURL로 화면에서만 보임. 지속 저장 API 없음 | 선택한 이미지의 업로드·소유권 검사·데이터셋 연결·재조회 경로를 추가. 자동 미리보기는 기본값으로 유지. 새로고침·편집·실패재시도 실제 검증 | 수동 교체는 재접속 후 유지되지 않음. 자동그림 검증과 별도로 미달 기록 |
| 37~38 계보 찾기 | 이름검색·Lv·주제와 후보페이지 전체조회는 구현. DatasetRow에는 원본파일명/기간/분류/출처 요약 없음 | 기존 자료에서 후보 전용 조회필드를 제공하고 이름·파일명 검색, 고려대분류·기간 필터와 결과카드 정보를 연결. 접근권한·연구실 경계는 유지 | 파일명/기간 검색과 확장자·기간·출처 결과정보 미달 |
| 23 격자 입력 | 원본 PRD는 선택 자유입력, 이전 리뷰는 자동칸 수용. 현 자동칸은 빈값이고 명시 변경결정 미확인 | 사람의 격자 설명을 저장할 별도필드와 기존 자동격자의 표시 우선순위를 명시. 자유문자열을 실제 배열형상·좌표로 사용하지 않음. 입력→저장→상세/편집 검증 | 자유입력·지속저장 미달. 이전리뷰를 사용자승인으로 취급하지 않음 |

구현 경계는 라운드 `7~9. 승인된 계약 확장`에 확정했다. 회귀시험 RED부터 작성한다. 운영배포·main병합 권한은 이 승인과 별개다.
