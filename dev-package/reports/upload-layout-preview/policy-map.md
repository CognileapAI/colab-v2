# 정책 대응표 — 업로드·상세

기준: rev1 내장 정책 65개. 화면 기준은 rev2. 이 표는 요구사항 추출이며 구현 일치 판정이 아니다.

| 번호 | 화면 요소 | 동작·상태 요구 | 구현 검수 |
|---|---|---|---|
| 1 | 업로드 진입 버튼 | 업로드 흐름의 시작점이다. 상단 메뉴(GNB)에 1급 버튼으로 상시 노출된다. 어느 화면에 있든 이 버튼 하나로 업로드 모달이 열린다. 데이터셋 목록 화면의 업로드 버튼도 같은 모달을 연다. 업로드는 늘 파일 놓기(장면1)부터 시작한다. 올린 파일 없이 입력 화면으로 시작하지 않는다. 클릭 → 업로드 전체 화면 모달을 연다. 뒤 화면은 그대로 문맥으로 남는다 | 미검증 |
| 2 | 업로드 전체 화면 모달 | 업로드는 화면이 아니라 화면을 통째로 덮는 전체 화면 모달이다. 화면으로 두면 상단 메뉴의 어느 탭에도 속하지 않아 지금 어느 환경인지가 사라진다. 헤더는 제목(업로드)과 대상 연구실, 닫기만 갖는다. 파일의 정체는 헤더가 아니라 등록 단계 줄의 파일 배지가 말한다. 장면은 둘이다. 파일 놓기(장면1)와 입력(장면2). 파일이 올라와야 입력으로 넘어간다. 상단 메뉴 업로드 클릭 → 모달이 열리고 뒤 화면 스크롤을 잠근다. 늘 파일 놓기부터 시작한다; 바깥 여백 클릭 · 닫기(×) → 닫기 확인 모달을 먼저 띄운다 | 미검증 |
| 3 | 파일 드롭 영역 | 파일을 끌어다 놓거나 눌러서 고른다. 포맷을 가리지 않는다. 같은 확장자 파일 여러 개를 한 번에 놓으면 데이터셋 하나로 묶인다. 확장자가 섞이면 첫 종류만 받고 나머지는 뺐다고 알린다. 한 데이터셋은 한 확장자다. 파일을 끌어다 놓기 → 파일 분석이 시작된다; 영역 클릭 → 파일 선택 창을 연다 | 미검증 |
| 4 | 파일 고르기 버튼 | 끌어다 놓기의 대안 경로다. 파일 선택 창을 연다. 목업 검토용 지름길로, 파일 없이 눌러도 지금 포맷의 샘플 파일이 올라온 것으로 처리한다. 제품에서는 파일 선택 창만 연다. 클릭 → 파일 선택 창을 연다(목업: 샘플 파일 업로드로 처리) | 미검증 |
| 5 | 미리보기 지원 확장자 안내 | 지도 미리보기까지 그려지는 확장자를 알린다. 업로드 자체는 포맷을 가리지 않는다. 여기 없는 확장자도 올릴 수 있고, 미리보기만 못 그린다. 확장자 표기는 `*.nc` 처럼 확장자 그대로 쓴다.  | 미검증 |
| 6 | 파일 분석 진행 | 올리기 → 읽기 → 확장자·용량 확인 순으로 진행을 알린다. 분석이 끝나야 다음 버튼이 켜진다. 올리기와 입력을 사람이 명시적으로 가른다. 여러 개를 묶어 올렸으면 조각 목록이 함께 열린다. 조각은 파일명과 용량만 적는다. 분석 완료 → 완료 칩으로 바뀌고 다음 버튼이 활성화된다; 파일 빼기(행동 줄) → 분석을 중단하고 드롭 영역으로 돌아간다 | 미검증 |
| 7 | 대상 연구실 표시 | 전체 화면 모달이 연구실 전환기를 가리므로, 어느 연구실에 올리는지를 헤더가 대신 말한다. 이름의 정본은 연구실 전환기의 현재 값이다.  | 미검증 |
| 8 | 바로 미리보기 | 파일이 놓이면 서버가 첫 변수의 기간 평균 한 장을 자동으로 그린다. 변수·시각 선택은 없다. 왼쪽 열에 고정(sticky)되어, 메타데이터를 그림을 보며 적을 수 있다. 이 축소본이 대표 그림(썸네일)의 기본값이 된다. 파일명은 여기 다시 쓰지 않는다. 파일 정체는 등록 단계 줄의 파일 배지 한 곳이 말한다. 확장보기(⤢) 클릭 → 오버레이로 크게 연다 | 미검증 |
| 9 | 미리보기 확장보기 | 좌측 미리보기는 참조용 크기라, 크게 봐야 할 때 오버레이로 편다. 확장보기는 상세 화면 뷰어와 같은 동작을 그대로 쓴다: 휠 확대, 끌어 이동, 커서 위경도, 초기화. 클릭 → 확장보기 오버레이가 열린다; 오버레이 바깥 클릭 · 닫기(×) → 오버레이를 닫고 입력으로 돌아온다 | 미검증 |
| 10 | 등록 단계 표시기 | 등록은 3단계다: 분류 → 메타데이터 입력 → 연결. 한 번에 한 단계만 보인다. 막지는 않는다. 표시기를 눌러 아무 단계로나 이동할 수 있다. 단계를 전환하면 본문이 맨 위로 올라간다. 이미 맨 위면 움직이지 않는다. 단계 이름 클릭 → 그 단계로 이동하고 본문을 맨 위로 | 미검증 |
| 11 | 등록할 파일 배지 | 지금 등록하는 파일의 정체를 말하는 유일한 자리다. 같은 줄의 탭 이름과 역할이 달라 글자가 아니라 배지로 둔다. 장면2에 드롭 영역은 없다. 다른 파일을 올리는 길은 이 배지의 ×(파일 빼기) 하나다. × 클릭 → 파일을 빼고 장면1로 돌아간다. 입력하던 내용은 사라진다고 알린다 | 미검증 |
| 12 | 분류 카드 (고려대 3축) | 등록 첫 단계. 분류 · 유형 · 가공 단계 세 셀렉트만 둔다. 목록 필터가 이 세 축을 그대로 받는다. 메타데이터(자유 입력)와 성격이 달라 단계를 뗐다. 가공 단계가 뒤 논리(Lv0 출처 필수 · 연결 가능 범위)를 좌우하므로 가장 먼저 정한다. 고른 값 아래 고려대 표의 정의와 대표 예시가 한 줄로 보인다. 가공 단계는 설명에 적을 필수 항목까지 안내한다(Lv0 만 출처 주소·내려받은 날을 칸으로 받는다).  | 미검증 |
| 13 | 분류 선택 (Category) | 고려대가 정의한 Data Category 5종에서 고른다. 필수다. 수문 인자 · 기상·기후 인자 · 식생·탄소 인자 · 사회·경제 인자 · 환경 인자. 지형(DEM)이 5종 어디에도 들어가지 않아 매핑 기준을 확인 중이다. [검증필요] 고른 값 아래 정의와 대표 예시가 한 줄로 바뀌어 보인다. 선택 → 데이터셋의 분류가 정해진다. 나중에 목록 필터가 이 값을 받는다 | 미검증 |
| 14 | 유형 선택 (Type) | 고려대가 정의한 Data Type 6종에서 고른다. 필수다. 지상관측자료 · 위성자료 · 재분석자료 · 수치모형자료 · 합성자료 · 관측 기반 산출물. 분류(무엇에 대한 값인가)와 유형(어떻게 얻은 값인가)은 다른 축이다. 고른 값 아래 정의와 대표 예시가 한 줄로 바뀌어 보인다. 선택 → 데이터셋의 유형이 정해진다 | 미검증 |
| 15 | 가공 단계 선택 | 고려대가 정의한 Data Level 네 단에서 고른다. 필수다. Lv0 원시 데이터 · Lv1 기초 전처리 완료 · Lv2 도출된 2차 산출물 · Lv3 유형화·고차 분석 결과. 자동으로 맞추지도 잠그지도 않는다. 여기서 고른 단계가 기준이 되어, 연결 단계에서 그 이하의 가공 전 데이터만 고를 수 있다(부모 Lv ≤ 자기 Lv). 같은 단계 가공을 허용한다. 실사례가 Lv0 > Lv1-A > Lv1-B > Lv2 로 간다. 고른 값 아래 정의와 대표 예시가 한 줄로 바뀌어 보인다. 선택 → Lv0 을 고르면 출처 주소·내려받은 날 칸이 열린다 | 미검증 |
| 16 | 메타데이터 입력 카드 | 당장은 AI 활용을 배제하고 사람이 직접 적는다. 자동으로 채워지는 값은 파일에서 읽은 확장자·용량뿐이다. 구획은 셋이다: 파일에서 자동으로 읽은 값 · 사람이 적는 값 · 부가 정보(선택). 카드 헤더는 보조 표면색으로 본문과 구분한다.  | 미검증 |
| 17 | 확장자 (자동) | 파일에서 자동으로 읽는 값이다. 사람이 고칠 수 없다. `*.nc` 처럼 확장자만 적는다. 확장자는 포맷을 특정하지 못한다. `.hdf` 하나가 HDF4-EOS 와 HDF5 둘을 가리킨다. 포맷을 단정하려면 파일 첫 바이트(매직 넘버)를 읽어야 하는데, 이번 범위에서는 하지 않는다.  | 미검증 |
| 18 | 용량 (자동) | 파일에서 자동으로 읽은 값이다. 자동 태그가 붙고 수정할 수 없다.  | 미검증 |
| 19 | 데이터셋 이름 입력 | 유일한 필수 입력이다. 이름 없이는 데이터셋을 만들 수 없다. 파일명(식별자)과 별개인, 사람이 붙이는 이름이다. 상세 헤더의 제목이 된다.  | 미검증 |
| 20 | 변수 표 (행 입력) | 변수마다 한 행이다. 변수명 · 단위 · 값 범위 · 결측률 · 대표 여부를 함께 받는다. 단위와 값 범위는 변수마다 다르다. 변수 3개에 단위 1개면 어느 변수 것인지 알 수 없어 행으로 받는다. 대표 변수 하나가 목록과 상세에서 이 데이터셋을 대신한다. 변수 추가 → 빈 행이 하나 늘고 첫 칸에 커서가 간다; 행 빼기(×) → 그 행을 지운다. 대표 변수를 지우면 첫 행이 대표가 된다 | 미검증 |
| 21 | 기간 입력 | 데이터가 담은 기간을 사람이 적는다. 자유 입력이다. 예시 안내: 2025-06 ~ 2025-09.  | 미검증 |
| 22 | 좌표계 입력 | 좌표계를 사람이 적는다. 자유 입력이다. 예시 안내: EPSG:5179.  | 미검증 |
| 23 | 격자 입력 (선택) | 격자 해상도를 적는 선택 입력이다. 예시 안내: 0.05°.  | 미검증 |
| 24 | 설명 입력 (필수) | 연구자가 직접 쓰는 맥락이다. 필수 입력이다. 칸을 따로 만들지 않은 필수 항목(보간 방법 · 산출 수식 등)도 여기에 적는다. 이 값이 이 데이터의 값어치라서 상세 화면에서도 자기 자리를 갖는다.  | 미검증 |
| 25 | 관측 간격 입력 (부가 정보) | 관측·산출 간격을 적는 선택 입력이다. 예시 안내: 10분 · 1시간 · 1일.  | 미검증 |
| 26 | 공개 범위 선택 | 이 데이터셋을 누가 볼 수 있는지 정한다. 기본값은 연구실 구성원 전체다. 상세 화면의 접근·다운로드에 그대로 표시된다. 상세에만 있고 업로드에서 안 받으면 그 값이 어디서 왔는지 설명할 자리가 없다. 대개 기본값 그대로 두고 넘어간다. 선택 → 공개 범위가 정해진다 | 미검증 |
| 27 | 대표 그림(썸네일) | 미리보기 축소본이 자동으로 대표 그림이 된다. 따로 만들 필요가 없다. 그림을 누르면 이미지 파일로 직접 바꿀 수 있다. 자동본에는 설명을 달지 않는다. 직접 바꿨을 때만 파일명과 되돌리기(×)가 뜬다. 그림 클릭 → 이미지 파일 선택 창을 연다; × 클릭(직접 올린 그림) → 자동 생성본으로 되돌린다 | 미검증 |
| 28 | 계보 등록 카드 | 이 데이터가 무엇을 가공해 만들어졌는지(상류)를 기록하는 자리다. 연결 단계는 카드 두 장이다: 계보 등록(어디서 왔나) · 연관 프로젝트·논문 등록(어디에 쓰나). 긴급 범위에는 AI 제안이 없어 모든 연결이 직접 연결이다.  | 미검증 |
| 29 | 직접 연결 목록 | 연결한 가공 전 데이터가 항목으로 쌓인다. 항목에는 파일명, 가공 단계, 직접 연결 표시, 연결 경로가 보인다. 항목마다 가공 방식(선택)을 적을 수 있고, 지우기로 뺄 수 있다. 연결한 사람과 날짜가 계보에 남는다. 지우기 → 그 연결을 빼고 건수를 다시 센다 | 미검증 |
| 30 | 계보 연결 안내 (0건) | 연결한 가공 전 데이터가 없을 때만 보이는 빈 상태 안내다. 연결이 1건이라도 생기면 사라진다.  | 미검증 |
| 31 | 가공 전 데이터 직접 추가 | 검색 모달을 열어 연구실 안 데이터셋에서 가공 전 데이터를 찾아 연결한다. 클릭 → 가공 전 데이터 직접 찾기 모달을 연다 | 미검증 |
| 32 | 모름으로 남기기(기록 없음) | 계보는 등록의 관문이 아니다. 가공 전 데이터를 못 찾아도 등록을 막지 않는다. 체크하면 기록 없음으로 남고, 상세 화면의 계보 빈 상태에서 나중에 채울 수 있다. 체크 / 해제 → 기록 없음 표시를 남기거나 지운다 | 미검증 |
| 33 | 연결 가능 가공 단계 안내 | 계보 등록 카드에 늘 보인다. 이 데이터의 가공 단계를 기준으로 어느 단계까지 연결할 수 있는지 말한다(Lv0~자기 Lv). 기준을 바꾸는 길(분류로 이동)을 링크로 준다. 값을 자동으로 바꾸지 않는다. '분류'에서 바꾸기 클릭 → 분류 단계로 이동한다 | 미검증 |
| 34 | 원천 표기 입력 | 연구실 밖 출처(재분석 자료, 위성 산출물 등)의 이름 표기다. 연구실 안 데이터셋이 아니므로 연결이 아니라 표기다. 계보 그래프에서 이동할 수 없는 원천 노드로 그려진다.  | 미검증 |
