## 7. 파일럿 — 첫 3건 등재 직후 자동 메타를 눈으로 본다

**왜 여기인가.** 이 재시드의 목적은 자동 메타를 얻는 것이고(intent), 자동 메타는 `seed` 단계의
**업로드 분석에서만** 들어온다. 28건을 다 심고 나서 「축이 전부 NULL」을 발견하면
3.64 GB 업로드와 ≈20분을 버린다. **3건에서 먼저 본다.**

### 7-1 언제

- `seed` 단계는 `projects → datasets → verify → report` 네 국면을 차례로 돈다(`stages.sh:600-602`).
- `datasets` 국면이 진행 상태를 `dev-package/tools/dev-seed/.work/state.json`
  (＝ `COLAB_SEED_WORK_DIR` 기본값)에 적는다. **완료 계수가 3 이상**이 되면 아래 질의를 낸다.

### 7-2 무엇을 (읽기 전용 SQL · 한 번)

```sql
-- dev 플랫폼 DB · 읽기만 한다
select d.id,
       a.format        is not null as has_format,
       a.crs           is not null as has_crs,
       a.grid          is not null as has_grid,
       a.period_start  is not null as has_period_start,
       a.total_size_bytes
  from d3_dataset d
  left join d3_dataset_autometa a on a.dataset_id = d.id
 order by d.id
 limit 3;
```

- 네 칸은 전부 `d3_dataset_autometa` 의 실재 컬럼이다(`db/platform/schema.sql:557-566`).
- 내는 법 = `stages.sh:249-258` 과 같은 한 벌
  (`docker run --rm --network host --user 0 -v /etc/colab/platform-owner-db.url:/s/owner.url:ro postgres:16-alpine`).

### 7-3 중단 규칙

| 관찰 | 판정 | 행동 |
|---|---|---|
| 3건 모두 `has_format`·`has_crs`·`has_grid`·`has_period_start` 가 **전부 false** | 자동 메타 경로가 죽었다 | **즉시 중단.** 목적 자체가 성립하지 않는다 |
| 3건 중 `d3_dataset_autometa` 행이 **아예 없다**(좌외부결합이 NULL) | 분석이 돌지 않았다 | **즉시 중단** |
| 축 넷 중 **일부만** 차 있다 | 자료 성질일 수 있다(격자 없는 표 자료 등) | **계속**하되 `verify` 에서 다시 본다 |
| 3건 모두 네 축이 차 있다 | 정상 | 계속 |

- ⚠ 「중단」은 **되돌리기가 아니다.** `reset` 은 이미 돌았고 그 걸음은 되돌릴 수 없다.
  중단은 「업로드를 더 쌓지 않고 멈춰 원인을 본다」는 뜻이다. 이을 때는 `--from seed`.
- ⚠ **NULL 을 0 으로 접지 않는다** — 질의가 아무 행도 안 주는 것과 축이 NULL 인 것은 다른 사건이다.
  위 표가 둘을 따로 둔 이유다(`stages.sh` 의 `preview_verdict` 가 배운 자리와 같은 계열).

## 8. 이 문서가 **증명하지 않는** 것

- `reset`·업로드·등재 28건·미리보기 판정의 실제 실행. 리허설은 **원격 줄이 읽히는가**만 잰다(WU1 §3).
- WU1 §7 의 도구 결함 2건(`project_index()` 앵커 의존 · 미리보기 순회기 대기 조건)은 **그대로**다.
  intent 가 「선행 조건으로 다루되 고치지 않는다」로 둔 항목이고, 이 레인도 고치지 않았다.
  ⇒ `seed` 의 green-by-skip 위험은 **남아 있다.** 판정에서 `previewJudgment[]` 의 「판정불가」를
  통과로 세지 않는다.
- 조건 4(사람이 dev 를 쓰는지)는 §5 의 한계대로 **사람이 확인한다.**
- WU2 의 소요는 여전히 **[미확인]** 이다.
