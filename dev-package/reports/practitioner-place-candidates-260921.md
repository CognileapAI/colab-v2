# 자료 28건의 지역 후보표 (2026-09-21)

Ted 결정 2(2026-09-21) 축자 — 「**가**를 넣고, 보조하는 용도로 **나**를 해야하지 않을까?」
㈎ = 정본(DATASETS.md)의 지역 문면을 지명으로 세운다 · ㈏ = bbox 로 보조 검증한다.

⚠ **이 표는 후보일 뿐이다.** 정본 `DATASETS.md` 4건은 **한 글자도 고치지 않았다**.
Ted 가 이 표의 「후보 상위 지명」을 확인해 준 뒤에야 정본에 지역 문면이 들어가고,
그때 `region` 이 `reviewed` 근거로 선다. 확인 전까지 조건 검색의 지명 술어는 여전히 비어 있다
(1회차 후속 7번 — 「28건 중 한반도를 문면으로 고정한 정본이 0건」).

## 읽는 법

- **정본 문면(축자)** — `dev-package/reports/reference-data/datasets-md/**/DATASETS.md` 의
  `description` 에서 공간을 말하는 부분만 그대로 옮겼다. 없으면 「(없음)」이다.
- **후보 상위 지명** — 그 문면에서만 세운다. 지어내지 않는다. 근거가 없으면 **「?」**다.
  - `직접` = 문면이 지명을 말한다.
  - `간접` = 문면이 **기관·관측망 이름**을 말할 뿐이다(기상청 API허브·국가기상위성센터).
    기관은 공간범위가 아니므로 승격 전 확인이 필요하다.
- **보조 bbox** — `d3_dataset_grid_profile` 의 w/s/e/n 또는 `canonical-metadata.json` 의
  `bbox` 가 한반도 상자(위도 33~39 · 경도 124~132) 안에 **온전히** 들어가는가.
  ⭑ **28건 전부 「미상」이다** — 두 자리 어디에도 bbox 가 **0건**이다(전수 확인).
  보조 규칙 `rule:bbox-korea-peninsula` 는 생성기에 서 있지만
  (`dev-package/tools/dataset_evidence_backfill.py` 의 `region_from_bbox`) 먹일 값이 없어
  만든 초안이 0건이다. 없는 것을 「미상」이 아니라 사실로 바꾸지 않는다.

## Ted 가 판정해 줄 것

1. **간접 5건(seq 1·2·6·19·20)** — 기관 이름을 지명으로 승격해도 되는가.
   기상청 관측망 = 남한, 국가기상위성센터 GK-2A = 한반도/동아시아 중 무엇인가.
2. **연구대상지 2건(seq 3·4)** — 「특정 연구대상지」가 실제로 어디인가. 정본에 그 지명을 넣을 것인가.
3. **타일 코드 8건(seq 21~28)** — MGRS/sinusoidal 타일을 상위 지명으로 펴는 표를 정본에 붙일 것인가.
   붙이면 그때부터 bbox 보조 규칙도 실제로 먹일 값을 갖는다.
4. **파생 6건(seq 5·8·9·10·11·12)** — 부모의 범위를 자식이 잇는다고 볼 것인가.
   그것은 문면이 아니라 계보 추론이므로, 승격해도 **초안** 등급이 맞다고 본다.

## 미해결

- `d3_dataset_grid_profile` 이 비어 있는 것은 **DEV 도 마찬가지인지 확인하지 못했다**.
  원격 DEV DB 를 이 회차에서도 직접 질의하지 않았다(Ted 결정 5 ㈎ 유지).
  DEV 에 격자 프로파일이 실려 있다면 보조 bbox 열은 그 값으로 다시 채워야 한다.
- 「한반도」와 「남한」을 구분해 적었다. 정본이 둘을 가르는 문면을 가진 자료는 **0건**이다.
