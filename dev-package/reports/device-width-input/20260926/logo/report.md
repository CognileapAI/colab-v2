## 1. 원인 · 규칙

- 셸 CSS 끝 `(pointer: coarse)` 블록의 `.gnb a.brand { min-width: var(--control-height) }`(44)가 flex 항목의 자동 최소 폭(내용 폭)을 대신한다. 1024 터치에서 항목 합이 막대 폭을 넘자 묶음이 내용(92.1)보다 좁게(86.3 · 76.3) 줄었고, 줄어들 수 있는 표식이 그 몫을 받았다.
- 규칙(같은 블록 · 파일 끝 블록 1개 유지): `.gnb a.brand { flex-shrink: 0; }`. 900 이하에서는 묶음 = 44(내용 26 < 44)로 전과 같다.
- 시험: `frontend/test/device-width-input-20260926-L2a.test.ts` 「로고 묶음(`.gnb a.brand`)은 터치에서 줄어들지 않는다」 — RED `expected +0 to be 1` → GREEN. 기존 단언 삭제 0.
