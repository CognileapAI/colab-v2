## 한계와 후속 단계
- iframe의 선택 너비는 현재 창의 가용 폭보다 커질 수 없다. 정확한 375/768/1440 실측은 별도 브라우저 viewport 캡처를 근거로 한다.
- iframe 높이는 고정된 검토용 값이다. 실제 휴대폰 가상 키보드·Safari 사용자 여정은 검증하지 않았다.
- fixture의 축 필터는 실제 서버의 전체 필터 지원을 증명하지 않는다. 결과 변화 증거는 기존 로컬 엔진이 지원하는 주제 필터다.
- 데이터셋 상세 이동·대시보드의 다른 화면 이동·검색·저장 등 전체 서비스 사용자 여정은 이 미리보기에서 검증하지 않았다.
- 테마 설정 저장·OS 연동·초기 테마 적용은 전체 확장 단계에서 구체화한다. 이번에는 두 팔레트의 실제 화면 제안이다.
- 대표 화면 확인 후 전체 화면별 적용 목록·공통 토큰·레이아웃 기준을 고정하고 확장한다.

## 중간 실패 기록
- 이전 gate 실행은 추가 audit entry 타입 오류 수정으로 입력이 변경되어 중단했다. 성공 결과로 계수하지 않는다.
- 초반 필터 메뉴는 모바일에서 잘렸고 선택 표시 9px/대비 1.84 문제가 있었다. 화면 하단 메뉴와 13px·on-primary 텍스트로 보완 후 별도 상태 재검증했다. `catalog-filter-probe.json` 등 초기 산출은 실패 탐색 기록이며 최종 근거로 사용하지 않는다.
- 기본 CSS 팔레트 회귀 검사 2건은 scoped 다크 토큰을 전역 기본값으로 잘못 읽어 실패했다. 기본 팔레트의 `:root` 해석만 보도록 보완하고, scoped 토큰 혼입 방지 fixture를 추가했다. 기존 밝기·대비 합격 기준을 유지한다. 최종 전체 결과는 gate-summary.json을 따른다.
- 처음 별도 tsc 구성은 임시 디렉터리에서 타입 라이브러리를 찾지 못해 준비에 실패했다. 실제 frontend 의존 경로를 연결한 뒤 fixture actions 누락을 발견·수정하고 통과했다.
