# DV·ST 디자인 배포 완료

- [DV 열기](https://d31zgpff2091oh.cloudfront.net/)
- [ST 열기](https://www.colab-hydro.com/)

승인된 글꼴·간격·컨트롤·테마 디자인을 두 환경에 반영했다. ST에는 별도로 배포된 최신 로그인 개선판 `login-hardening-final-r5-20260912`의 이메일 로그인, 비밀번호 변경, 계정 관리, 세션·작성 중 작업 보호를 보존했다.

## 최종 증거

| 확인 | DV | ST |
|---|---|---|
| 공개 배포 파일 hash | 96개 일치 | 96개 일치 |
| 사전/사후 환경 검사 | 각각 doctor 15/15, 생략0 | 각각 상태 검사 15/15, 생략0 |
| 회귀 | 기존 검증 디자인 1,216개 통과 | r5 통합본 104파일·1,253개 통과 |
| 공개 브라우저 | 밝게/어둡게 ×375/1440, 4회 | 밝게/어둡게 ×375/1440, 4회 |

8개 공개 화면 검사에서 폰트 로딩·테마 선택 후 새로고침 유지 확인, 작은 본문/대비 미달/문서 가로 넘침/브라우저 오류 각0건. ST 추가 인증 화면은 4상태×2테마×2너비=16개를 격리 fixture로 촬영·계측했다. 재로그인 입력이 비활성 보존 모달에 포커스를 빼앗기지 않는 검사도 통과했다. 이미지 내 96파일을 빌드와 대조했고, sourcemap의 빌드 경로 차이는 170개 실제 제품 소스 내용 일치로 별도 확인했다.

ST는 frontend 서비스만 교체했다. 교체 전후 다른 컨테이너7개의 ID·이미지 불변을 확인했다. DV는 웹 버킷만 갱신했다. 이 작업은 DB·백엔드·터널 변경이나 제품 계정/데이터 쓰기, 커밋·main push를 수행하지 않았다.

## 배포 중 조정

첫 ST 작업 폴더에는 미배포 로그인 개선이 섞여 있었다. 이를 버리고 실제 배포 sourcemap에서 160개 제품 모듈을 복원해 디자인만 합친 첫 통합본을 배포·검증했다. 직후 별도 작업이 ST에 로그인 개선 r5를 배포해 디자인이 덮어써졌다. 이 시점의 이전 통합본 결과는 최종 완료 근거가 아니다.

최종본은 새 r5 배포 이미지와 실제 sourcemap을 다시 고정해 통합했다. 기존 기능 보존을 독립 검토하고, 전체1,253테스트와 추가16화면을 새로 검증한 뒤 교체 직전 r5 이미지 hash를 확인했다. 최종 공개 파일과 실제 실행 이미지를 다시 대조했다. 과거 실패·중단·교체본의 증거는 보존하되 최종 파일은 `st-r5-*`, `public-browser.json`, `status.json`이다.
