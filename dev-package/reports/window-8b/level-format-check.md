### 2-1. 레벨 축의 gap 둘 — 구체적으로

**⛔ gap-A · 가뭄에 줄 `topic` 이 없다.** DB CHECK 4값(`강우·강수`·`식생·NDVI`·`지형·DEM`·`토지피복·LULC`)에
**가뭄이 없다.** 넣을 수 있는 값은 `NULL` 뿐이고, 그러면 **Ted 가 폴더로 나눈 세 주제 중 하나가 카탈로그에서 사라진다.**
푸는 법 둘 — ⑴ `topic` CHECK 에 값 추가(**정본 개정 ＋ 마이그레이션** · Ted 판정 자리) ⑵ `NULL` 로 두고 이름으로만 구분(**분류 손실**).

**⛔ gap-B · 가뭄은 `Lv.1` 인데 부모가 없어 `Lv0` 으로 계산된다.** `03.drought/` 아래에는 **`Lv.1` 하나뿐**이고
`Lv.0` 폴더가 없다. `processing_level()` 은 주입력 부모가 없으면 **0** 을 낸다 — `sourceLabel`(원천 표기)을 붙여도
`lineage_state` 만 `원천` 이 되고 **레벨은 0 그대로**다. **폴더가 Lv.1 이라고 적은 것과 화면 배지가 어긋난다.**
푸는 법 — 가뭄의 Lv.0 원천이 무엇인지 Ted 가 지정해 부모 데이터셋으로 함께 적재하거나, 「가뭄 Lv.1 은 Lv0 으로 표시된다」를 받아들인다.

**⚠ 미확인 하나** — 식생 `Lv.2`(#8)의 **주입력 부모가 `Lv.1` 인지 `Lv.1_(Model_Input_Data)` 인지 폴더가 말하지 않는다.**

### 3-1. 포맷 축의 gap 둘 — 구체적으로

**⛔ gap-C · 제품에 포맷 축이 없다.** `format` 은 **파일마다 자동으로 읽는 값**이고(`VAL-003` · 수정 불가)
**데이터셋을 묶는 칸이 아니다.** `topic` 4값에도 포맷이 없고 카탈로그에 포맷 패싯이 **0건**이다.
⟹ grib/nc/bin/tif/HDF5 갈래는 **데이터셋 이름(자유 문자열)에만** 남길 수 있다. **패싯으로는 못 남긴다.**

**⛔ gap-D · 다섯 역할 폴더가 `kind` 두 값에 안 들어간다.** `d3_file.kind` CHECK = `본체` · `기준 격자 파일` 둘뿐이다.
- `00.Data`(168) → `본체` 로 선다.
- `04.Lat_Lon_info`(17) → 대체로 `기준 격자 파일` 로 선다. ⚠ 단 `pdf` 1건은 격자가 아니다.
- `02.Results`(72 · **2.1 GB**) → 가공 **결과**다. `본체` 로 실으면 **원자료와 결과가 한 데이터셋에서 구분되지 않는다**
  (레벨로 갈라야 할 것을 파일 종류로 뭉갠다).
- `01.Code`(7 py) · `03.Figure`(62 png) → **데이터가 아니다.** 실을 `kind` 가 없다.
⟹ 폴더 그대로 한 데이터셋에 부으면 **Ted 의 역할 분류가 통째로 평평해진다.**

**⭐ 다만 길이 하나 있다** — `F-3`(가·나)의 **`d3_file.relative_path`**(마이그레이션 `0009`)가
「폴더 구조를 등록 뒤에도 유지」한다. **역할 폴더 이름은 경로로 살아남는다.**
⚠ 그러나 그것은 **표시용 경로**이지 패싯·필터·레벨이 아니다 — **분류가 아니라 문자열**이다.

**⭐ 대안 무늬 하나** — `02.Results` 를 **같은 포맷 벌의 `00.Data` 를 주입력 부모로 삼는 별도 데이터셋**으로 세우면
레벨 축(Lv0 → Lv1)으로 역할이 재현된다. **이 제안은 매니페스트 설계 결정이라 Ted 자리다.**

## 4. 판정 — **gap. 적재하지 않는다.**

| 축 | 재현되나 | 막는 것 |
|---|---|---|
| 레벨(강수·식생) | **된다** — `lineageParents`＋`parentRole: 주입력` 으로 Lv0→Lv1→Lv2 가 그대로 선다 | 식생 Lv.2 의 부모가 둘 중 어느 쪽인지 `[미확인]` |
| 레벨(가뭄) | **안 된다** | gap-A(`topic` 4값에 가뭄 없음) · gap-B(Lv.0 부모 부재 ⟹ Lv0 으로 접힘) |
| 포맷 5갈래 | **안 된다** | gap-C — 제품에 포맷 패싯이 없다. 이름에만 남는다 |
| 역할 5폴더 | **안 된다** | gap-D — `kind` 2값 · `01.Code`·`03.Figure` 는 실을 자리가 없다 |

⛔ **되돌릴 수단이 0 이다**(dev `deleteDataset` 501). 위 넷 중 하나라도 정해지지 않은 채 부으면
**Ted 가 폴더로 표현한 분류가 지워진 채 고정된다.** 그래서 멈춘다.

### 다음 회차가 받아야 할 결정 — 다섯

1. **가뭄 `topic`** — CHECK 4값에 추가(정본 개정 ＋ 마이그레이션)인가, `NULL` 수용인가.
2. **가뭄 Lv.0 원천** — 부모로 함께 적재할 것이 있는가. 없으면 「Lv0 으로 표시됨」을 수용하는가.
3. **식생 `Lv.2` 의 주입력 부모** — `Lv.1` 인가 `Lv.1_(Model_Input_Data)` 인가.
4. **`02.File-format` 묶음 단위** — ⑴ 포맷 벌당 데이터셋 1개(역할은 `relative_path` 로만 남음) 인가
   ⑵ 포맷 벌당 `00.Data`(Lv0) ＋ `02.Results`(Lv1) 두 데이터셋 인가.
5. **`01.Code`·`03.Figure`·`#readme` 처리** — 적재 제외인가, 별도 자리를 만드는가.
   (`desktop.ini` 50건은 **무조건 제외**로 본다 — 윈도 부산물이다.)
