# Intent: CoLAB 전체 화면을 차분하고 일관된 업무 도구로 정비한다
메타 — 발의자: Ted · 작성 2026-09-12 · 승인 2026-09-12 (대화의 명시 승인)

## 문제
- 글꼴·컨트롤·여백이 불균일해 화면이 조잡하게 느껴지고 정보 구분이 어렵다.
- 스타일 누락 복구와 기술 검사만으로는 사용자가 원하는 전체 디자인 완성도를 확인할 수 없다.
- 화면·기기·테마가 달라도 일관되게 읽고 작업할 수 있는 디자인 기준이 필요하다.

## 원한 결과 (proposed outcome)
- 절제된 색상, 명확한 글자 위계, 일정한 여백으로 차분하고 정돈된 업무 도구의 인상을 만든다.
- 목록은 데이터를 비교하기 좋게 촘촘하게, 입력·안내는 읽고 조작하기 편하게 여유 있게 구성한다.
- 데이터셋 목록·대시보드·입력 모달을 실제 화면으로 먼저 확인하고 Ted가 방향을 확인한 뒤 전체 화면으로 확장한다.
- 전체 화면의 스타일 일관성·반응형·접근성을 검수하고 기존 기능의 회귀 검증을 마친다. 자동 검사 통과를 시각적 디자인 확인의 대체 근거로 삼지 않는다.
- 모바일에서도 모든 기능을 사용할 수 있고, 밝은 테마와 어두운 테마 모두 같은 기준으로 정비한다.

## 영향 범위
- 사용자 / 화면: CoLAB 전체 사용자 화면. 데이터셋 목록·대시보드·입력 모달을 대표 화면으로 선행 적용한다.
- 서비스 · 스키마 · 계약: 프론트엔드 표현·배치·공통 컴포넌트. 기존 기능과 서비스·스키마·API 계약을 유지한다.
- 계약 파괴 여부: 아니오

## 제약
- 기존 메뉴와 기능, 권한 및 상태 의미를 유지하면서 화면 내부의 배치·묶음·글자 위계·색상·공통 컴포넌트를 개선한다.
- 넓은 표는 표 내부 가로 스크롤을 허용하되 모바일에서 기능을 제외하지 않는다.
- 기존 스타일 복구 결과와 검수 증거는 출발점으로 활용한다. 이전 검증을 이번 디자인 변경의 검증으로 재사용하지 않는다.
- 도메인 경계·연구실 격리 등 CLAUDE.md의 불변 규칙을 유지하며, 생성된 타입·클라이언트를 직접 수정하지 않는다.
- 구체적인 서체·크기·간격·색상 값은 이 intent의 확정 사항이 아니다. 기존 디자인 기준과 대조해 대표 화면에서 제시하고 확인한다.

## 설계트리 (grill-me 결과)
- Q1 제품의 인상 → A 차분하고 정돈된 업무 도구 (권장안 수용).
- Q2 정보 밀도 → A 목록은 촘촘하게, 입력·안내는 여유 있게 (권장안 수용).
- Q3 구조 변경 범위 → A 기존 메뉴와 기능을 유지하되 화면 내부 배치·묶음 개선 (권장안 수용).
  - Q3a 모바일 지원 → A 모든 기능 사용 가능, 넓은 표는 내부 가로 스크롤 허용 (권장안 수용).
  - Q3b 테마 범위 → A 밝은 화면과 어두운 화면 모두 같은 완성도로 정비 (권장안 수용).
  - Q3c 적용 순서 → A 데이터셋 목록·대시보드·입력 모달을 먼저 확인한 뒤 전체 확장 (권장안 수용).
