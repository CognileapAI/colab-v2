# Intent: 계정 생성 폼의 문면·배치·기본값을 바로잡고 칸별 data-testid를 세운다
메타 — 발의자: sungwooHa (#84, #54) · 방향 결정: Ted · 작성 2026-09-17 · 승인 2026-09-17(초안 4건 제시 후 Ted 명시 승인)

## 문제
- 계정 관리 화면에서 계정을 만드는 조작이 `시스템 관리자 등록`으로 적혀 있다. 이 폼의 주 동작은 일반 사용자 계정 생성인데 문면이 관리자 등록으로 읽혀 화면의 뜻이 어긋난다.
- 관리자 여부 체크박스가 연구실·역할 선택 아래에 있어, 체크하면 위쪽 선택이 무의미해지는데도 사용자가 먼저 채우게 된다. 체크박스 기본값도 켜져 있어 아무 조작 없이 관리자 생성이 기본이 된다.
- 폼을 여닫을 때 제출 버튼 위치가 화면 세로 가운데로 흔들린다.
- (#54) 폼의 칸마다 `data-testid`가 없어 dev-seed 러너가 form `name`으로 칸을 짚는다. 문면·배치가 바뀌면 그 의존이 함께 깨진다.

## 원한 결과 (proposed outcome)
- 계정을 만드는 버튼과 탭 라벨이 모두 `사용자 생성`으로 읽힌다. 한 화면에 '초대'·'관리자 등록'·'사용자 생성'이 섞이지 않는다.
- 관리자 여부 체크박스가 폼 맨 위에 있고, 체크하면 연구실·역할 선택이 비활성(값 비움)이 되어 채울 필요가 없음이 화면으로 드러난다.
- 체크박스 기본값은 꺼짐이며, 아무 조작 없이 제출하면 일반 사용자 계정이 만들어진다.
- 폼 내용 길이가 바뀌어도 제출 버튼이 세로로 튀지 않는다.
- 폼의 7개 칸을 `data-testid`로 직접 짚을 수 있다.

- 서비스 · 스키마 · 계약: `frontend/src/routes/AccountAdminPage.tsx`와 `frontend/src/auth/login.css`의 신규 수식 클래스. API·DB 변경 없음.
