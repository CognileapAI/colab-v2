# Intent: Claude·Codex 공통 개발 환경 정착

발의자: 사용자 · 작성일: 2026-09-08 · 범위 승인: 현재 대화의 구현 지시
보안 설정·프로젝트 신뢰·외부 배포 권한은 별도이며 범위 승인에 포함하지 않는다.

## 문제

Claude 하네스를 Codex에 연결하는 동안 CLI·PATH 등의 개별 오류를 해결한 뒤 작업을 종료했다.
설정 파일 작성, 실제 등록, 브라우저 기동, 제품 E2E를 구분해 관리하는 전체 실행 계획이 없었다.
과거 개발본과 현재 제품·기획·자료의 역할도 불명확했다.

## 원한 결과 (proposed outcome)

1. `30 CoLAB-v2`를 현재 개발의 기준으로 유지하고 과거 작업은 보관 후보로 관리한다.
2. Claude·Codex가 같은 제품 규칙·역할·스킬 원본과 검사 로직을 사용한다.
3. Codex/Astra 실행, 설정·에이전트 discovery, 검증 경로를 실제 실행으로 확인한다.
4. agent-browser 사용자 여정 E2E와 로컬 모델 eval을 재현 가능한 판정으로 연결한다.
5. 전체 계획·의존·증거를 갱신하며 진행한다. 부분 작업의 완료를 전체 완료로 보고하지 않는다.

## 제약

- 기존 제품 기능·데이터·Claude 설정의 의미를 임의로 변경하지 않는다.
- 스킬·역할 본문을 두 도구용으로 수동 복제하지 않는다.
- 별도 API 키 기반 CI 모델 실행을 필수 조건으로 추가하지 않는다.
- 프로젝트 신뢰와 hook trust 승인 대기는 해당 단계만 막는다. 독립 작업은 계속한다.
- 보관 후보 지정은 삭제 승인이 아니다. 미커밋·미병합·worktree·경로 참조를 먼저 점검한다.
- 모델·테스트·자동 훅이 실제로 실행되지 않았으면 준비 완료와 실행 통과를 구분한다.
