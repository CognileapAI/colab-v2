# Intent: 보유 레퍼런스에서 연구에 필요한 자료를 찾고 구분하는 AI 검색
메타 — 발의자: Ted · 작성 2026-09-12 · 승인 2026-09-12 (직전 사용자 검토용 제안의 목적·첫 범위 채택; 세부 사양·구현·배포 승인 아님)

## 문제
- 공유받은 기상·환경·위성 자료를 연구에 사용하려는 사람이 정확한 파일명·전문 용어·폴더 구조를 모두 알고 있지는 않다.
- 보유 레퍼런스에는 원자료·가공 자료·모델 예측·보조입력이 함께 있으며, 기간·지역·변수·처리 방법과 한계가 파일명만으로 드러나지 않는다.
- 따라서 필요한 자료를 찾는 것과 찾은 자료의 역할을 이해해 선택하는 과정에 어려움이 있다는 사용자 상황을 첫 개발의 출발점으로 삼는다. 실사용자 인터뷰로 측정한 불편이라고 주장하지 않는다.

## 원한 결과 (proposed outcome)
- O1. 연구자는 정확한 이름이나 전문 용어 대신 목적과 기간·지역·자료 특성을 자연어로 입력해 필요한 데이터셋을 찾을 수 있다.
- O2. 결과는 요청과 맞는 이유를 보여주고, 원자료·가공 자료·모델 예측의 역할을 구분한다.
- O3. 결과는 근거로 확인 가능한 자료의 한계를 알려준다. 확인되지 않은 조건·품질을 적합하다고 단정하지 않으며, 해당 자료가 없으면 없다고 알린다.
- O4. 연구자는 검색 결과에서 상세 정보로 이동해 사용할 자료를 선택할 수 있다. 검색이 연구자의 최종 판단을 대신하지 않는다.
- O5. 첫 자료 범위는 실제 보유 레퍼런스의 강수·식생·가뭄을 중심으로 잡는다. 이미 합의한 식생 질문을 첫 골든 문항으로 유지하고 기대결과를 점진적으로 보강한다.

## 영향 범위
- 사용자 / 화면: 연구용 공유 자료를 찾는 연구자; 기존 자연어 검색 입력·결과·데이터셋 상세 이동 흐름.
- 서비스 · 스키마 · 계약: 자연어 검색, 자료 설명 정보 활용, 질의 해석·후보 탐색·순위·근거 조립. 필요한 변경은 자료 조사와 실험 후 사양에서 결정한다.
- 계약 파괴 여부: 이번 intent 기록에는 계약 변경 없음. 후속 구현의 파괴 여부는 사양에서 판정하며 필요한 승인을 기록한다.

## 제약
- 연구실·접근 권한 경계를 유지하며 실제 검색한 범위를 먼저 고지한다. 결과별 추천 근거는 한 줄로 유지한다.
- 근거는 실제 자료·설명에서 추적 가능해야 한다. 첨부 설명서 본문은 현행 검색 색인에 없으므로 이미 검색 가능하다고 가정하지 않는다.
- 100m 균등 분할 자료를 100m 직접 관측으로, 모델 예측을 관측값으로 설명하지 않는다.
- 데이터가 없거나 메타데이터가 부족한 상태와 검색 장애를 혼동하지 않는다.
- 첫 골든셋은 기존 검색 평가셋·기준선·제품 완료 정의를 대체하지 않는다.
- 제품 데이터셋·파일 ID와 평가 권한·자료 스냅샷을 연결한 뒤 검색을 평가한다. 문서 확인만으로 제품 검색 통과를 선언하지 않는다.
- 모델·검색 기술·설명 수집 방식·정량 기준을 여기서 선결정하지 않는다. 자료 조사 → 골든셋 보강 → 비교 실험 → 사양·구현 계획 순서를 따른다.
- 기존 도메인 경계·생성물 규칙·DB 체인·권한 규칙을 유지한다. 구현은 승인 사양과 외부 동작 시험을 따른다.

## 설계트리 (grill-me 결과)
- Q1 누구의 어떤 상황에서 시작하는가? → A 일반적인 사용자 상황 재질문보다 실제 보유 레퍼런스를 먼저 조사하고, 연구자가 자료를 찾아 역할을 구분해 선택하는 상황으로 시작한다(자료 기반 제안 채택).
- Q2 첫 자료 범위는 무엇인가? → A 강수·식생·가뭄 중심(권장안 수용). 포맷별 자료 탐색·가공 방법 비교는 후속 후보로 보존한다.
- Q3 어떤 결과를 얻는가? → A 조건에 맞는 데이터셋, 추천 근거, 자료 역할·확인 가능한 한계, 상세 정보 이동(권장안 수용).
- Q4 정답 기준은 어떻게 준비하는가? → A 기존 식생 질문 1건을 시작점으로 두고 검색 기대결과를 계속 보강한다(사용자 지시).
  - Q4a 추가 조사 질문을 곧바로 정답으로 확정하는가? → A 아니오. 실제 데이터와 근거를 대조하고 골든셋 보강 단계에서 검토한다.
- Q5 전체 작업은 어떻게 이어가는가? → A 현재 작업이 총괄, 독립 조사·실험·구현은 위임, 주요 산출물은 독립 검토. 전체 계획에서 현재 위치·결과·다음 행동을 관리한다(이전 운영 합의 유지).

## 미해결 질문
- 이 intent가 정한 목적·첫 자료 범위 수준에서는 없음.
- 후속 작업의 구체화 항목: 실제 제품 등록 ID·평가 자료 스냅샷·누락 설명의 보완 범위(작업 2), 추가 문항과 판정 기준(작업 3), 검색 방식·속도·비용·품질 기준(작업 4), 응답 표현·근거 연결·계약 변경(작업 5).
- 위 후속 항목은 결정이 끝났다는 뜻이 아니며, 확정 전 해당 구현으로 넘어가지 않는다.

## 범위 밖 (명시 제외)
- 연구 성능·자료 품질의 근거 없는 보장, 검색 단계에서의 수치 분석 실행, 새 가공 데이터 생성.
- 채팅형·연속 대화 UI 도입. 예시 후속 질문은 독립 검색 후보이지 대화 상태 유지 요구가 아니다.
- 모든 참조 폴더의 일괄 제품 등록, KWRA 발표 자료·사진 전체의 자동 검색 대상 편입.
- 모델·벡터 검색·RAG 등 특정 기술 채택을 선결정하는 것.
- 커밋·push·배포·운영 데이터 변경. 별도 대화 승인 범위를 따른다.
