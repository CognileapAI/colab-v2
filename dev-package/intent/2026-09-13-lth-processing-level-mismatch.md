# Intent: 가공 단계 불일치를 이행분·미구현분·재판정분으로 갈라 닫는다
메타 — 발의자: 이태헌 · 작성 2026-09-13 · 승인 2026-09-13

## 문제
- 데이터셋 상세에서 고른 가공 단계가 Lv2, 연결 데이터로 계산한 값이 Lv0 인데 「그대로 두어도 등록돼요」 한 줄만 뜨고 저장된다(확인 사례 = 기획자 보고의 시험 데이터셋 1건).
- 그 한 줄은 두 값만 말하고 **왜 갈렸는지는 말하지 않는다** — 판정문이 요구한 「사유 한 줄」이 화면에 없다.
- 부모를 한 건도 연결하지 않은 등록에서는 등록 화면에 경고가 아예 뜨지 않는다.
- 목록·검색·프로젝트 상세·검토 화면에 불일치가 전혀 보이지 않는다.
- 등록을 마친 뒤 사람이 고른 가공 단계를 화면에서 고치는 칸이 없다.

## 원한 결과 (proposed outcome)
- 검증 가능 문장 ⑴ — 불일치 안내 한 줄이 두 값 ＋ 각 값의 근거(사람이 고른 값 / 부모 최대 Lv＋1 · 부모 0건이면 0)를 함께 말한다. 상세와 등록 두 자리가 같은 문장을 쓴다.
- 검증 가능 문장 ⑵ — 데이터셋 목록의 가공 단계 칸이 불일치 행에 표식을 그린다(응답 열쇠는 이미 내려온다).
- 검증 가능 문장 ⑶ — 상세 편집에 가공 단계 칸이 있고, 저장 후 상세 표시값이 바뀐다.
- 검증 가능 문장 ⑷ — 위 셋의 시험이 각 1건 이상 green 이고, 불일치 상태에서 등록·저장이 계속 성공한다(기존 판정 유지 확인).
- 판정 = 새 판정 없이 닫히는 분(⑴·목록 표식·편집 칸)이 green 이고, 판정 반전이 필요한 분은 Ted 판정 대기로 분리 등재된다.

## 설계트리 (grill-me 결과)
- Q1 기획자 권고 ⑴(차이 이유 ＋ 두 값 근거 표시) → A **판정 이행 미달**이다. 판정문이 「화면에 사유 한 줄을 낸다」를 요구했고 실물 문장은 두 값만 말한다. 새 판정 없이 문장을 보강한다. 크기 **S**.
- Q2 권고 ⑵(기본값을 계산값으로) → A **판정 반전** — 판정문의 「기본 선택값 = Lv2」를 바꾼다. Ted 필요. 크기 **M**(`RegisterArea.tsx`·`UploadModal.tsx` ＋ 시험). **(권고안 수용 · Ted 2026-09-13 — 카드 ⑩ ⓐ 기본값을 계산값 추종으로)**
- Q3 권고 ⑶(사유 입력 ＋ 명시 확인) → A **판정 반전** — 「막지 않는다」의 반전이고 사유 저장 칸이 필요하다. 계약 열쇠 추가 ＋ `db/platform` 마이그레이션 1건 ＋ 라우트·도메인·화면. Ted 필요. 크기 **L**. AI 없이도 완결되는 성질은 영향받지 않는다. **(Ted 2026-09-13 — 카드 ⑩ 권고대로 이번 회차 밖 · 사유 칸 설계와 함께 다음 회차 판정 · 항목 등재)**
- Q4 권고 ⑷(목록·검토 표시) → A **미구현**이고 판정 저촉 없음. 목록은 화면만 고치면 된다(불일치 열쇠가 이미 응답에 실린다 · 프런트에서 그 열쇠를 읽는 자리는 상세 헤더 하나뿐). 프로젝트 표·계보 노드는 열쇠를 아직 받지 않는다. 크기 **S**(목록만) / **M**(표·노드·할 일 함).
- Q5 조사가 더한 ⑸(등록 뒤 수정 칸 부재) → A **미구현**. 프런트에서 사람 값을 전송하는 자리는 업로드 흐름 둘뿐이고 나머지는 모두 읽기다(조사 C 추가 실측). 계약 열쇠가 이미 있어 화면 칸 신설만으로 닫힌다. 크기 **S~M**.
- Q6 ⑷′(부모 0건 등록에서 경고 부재) → A **설계 차이**이고 ⑵ 와 **같은 판정에 매인다** — 등록 화면의 미리보기는 부모 Lv 를 모르면 만들지 않는 규칙이고(`LineageStep.tsx` 독스트링 축자 「부모 Lv 를 하나라도 모르면 미리보기를 만들지 않는다.」), 부모 0건을 0 으로 볼지가 기본값 판정과 한 건이다. 크기 **S**(advisor 게이트 ② 반영 — 결함으로 분류하지 않는다). **(권고안 수용 · Ted 2026-09-13 — 카드 ⑩ ⓐ 와 같은 판정 · 부모 0건이면 Lv0 ＋ 등록 화면 경고)**
- Q7 같은 계열의 선례 → A 안내 전용으로 더한 사례가 있다 — 사람 Lv0 ＋ 파생≠0 행의 출처 안내(구현 자리 `frontend/src/components/detail/BasicInfoGrid.tsx` · 주석 축자 「⛔ 안내로만이다 — 저장을 막지 않고 재입력을 강제하지 않는다.」). 차단 없이 안내를 더하는 방향은 기존 판정과 정합한다.
