# Intent: 확정 부모가 있으면 기록 없음 선언을 숨긴다
메타 — 발의자: joddanddan-commits · 작성 2026-09-16 · 승인 2026-09-16

## 문제
- 가공 전 데이터를 연결했는데도 "가공 전 데이터를 못 찾았어요" 항목이 비활성 상태로 남아 오류로 읽힌다.
- 실제로는 조회 오류가 아니라 부모 없이 등록하겠다는 lineageUnknown 선언이다.
## 원한 결과 (proposed outcome)
- 확정 부모가 1건 이상이면 기록 없음 선언 행 전체를 숨긴다. 연결 카드와 실제 오류·충돌 안내는 유지한다.
- 확정 부모가 없고 Lv1 이상이면 기존 선언을 표시한다. Lv0에서는 기존처럼 숨긴다.
- 연결을 모두 해제하면 선언 행이 다시 나타나고 기존 체크 상태를 보존한다.
- 부모 연결 상태의 등록 요청에는 기존처럼 lineageUnknown을 넣지 않으며, 연결한 부모를 유지한다.
## 영향 범위
- 사용자 / 화면: 업로드 계보 연결.
- 서비스 · 스키마 · 계약: 기존 프런트 표시 조건과 시험, 과거 정책의 개정 연결.
- 계약 파괴 여부: 아니오.
## 제약
- 이전 비활성+사유 노출 판정을 이 표시 범위에서 개정하며 이력은 보존한다.
- 선언 상태 초기화, 부모 자동 삭제, 진짜 조회 오류 숨김을 하지 않는다.
- 후보 조회/재시도, 가공 단계 상한과 계산 불일치 안내를 유지한다.
## 설계트리 (grill-me 결과)
- Q1 선언 자체 삭제 → A 확정 부모 연결 중에만 숨긴다.
- Q2 연결 해제 후 → A 기존 상태를 보존해 다시 표시한다.
- Q3 서버 계약 → A 기존 payload 생략 규칙을 유지한다.
