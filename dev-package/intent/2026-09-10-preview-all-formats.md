# 모든 지원 포맷 미리보기

## 사용자 요청

> GRIB과 일반 HDF5까지 미리보기를 확장하는 작업. 미리보기 모두 지원하는 작업

## 원하는 결과

- 기존 NetCDF, Binary, HDF4, GeoTIFF, NumPy 미리보기를 유지한다.
- GRIB1/2와 일반 HDF5를 실제 디코딩하여 변수 선택과 이미지 미리보기에 포함한다.
- 지원·자동 감지·미리보기 목록을 위 일곱 포맷으로 일치시킨다.
- 좌표가 없는 값은 기존 비지도 미리보기로 표시하고 좌표를 추정하지 않는다.

## 구현 가정

- GRIB 선택 ID는 메시지의 변수명·유효시각·수직층·격자 식별 정보를 포함해 동명 충돌을 피한다.
- 일반 HDF5 선택 ID는 루트부터의 dataset 전체 경로와 명시적 선행 차원 인덱스를 사용한다.
- 결측값은 원시값에서 먼저 마스킹하고 scale/offset을 적용한다.
- 문자열뿐인 파일, 손상 파일, 전부 결측인 값, 잘못된 선택은 성공으로 가장하지 않는다.
- COG는 기존 다섯 포맷 경로를 보존하고 신규 포맷이 업로드에서 미리보기에 도달하는 데 필요한 최소 처리만 더한다.

## 완료 조건

- 일곱 포맷의 단위·통합 시험과 실제 파일 렌더 커버리지 결과가 남는다.
- GRIB 및 일반 HDF5의 업로드→변수 선택→이미지 표시 사용자 여정을 검증한다.
- Docker 의존성 설치가 재현되고, 실행하지 못한 플랫폼 검증은 미완료로 남긴다.
