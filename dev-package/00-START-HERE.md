## 원칙 여섯

1. **경계가 먼저다.** 도메인 경계는 협업(누가 소유하나)과 컨텍스트 윈도우(에이전트가 담을 수 있나) 두 기준으로만 긋는다.
2. **계약 동결 → TDD → 게이트 통과.** 순서를 바꾸지 않는다.
3. **테스트가 오라클이다.** 오라클 없는 WU는 쪼갠다.
4. **AI는 제안만 한다.** D10은 D4(계보)에 쓰기 경로가 없다 — 규칙이 아니라 구조로.
5. **배포가 완료다.** I2 이후 모든 WU의 완료 판정에 staging 배포 green이 붙는다.
6. **절대경로를 문서에 적지 않는다.** v1의 HANDOFF가 이 규칙이 없어 실제로 틀렸다.
