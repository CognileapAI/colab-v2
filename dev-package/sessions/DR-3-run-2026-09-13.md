실행하며 드러난 것이고, 전부 `dev-package/tools/dev-seed/` 정본에 반영돼 있다.

1. **분석 완료 판정의 지목점** — 「분석 중」 표시의 소멸이 아니라 **완료 표시의 출현**으로 기다린다. 종전 방식은 큰 묶음에서 조기 통과했다.
2. **데이터셋 계수는 화면 머리말의 「N건」** — 표 행(`tr.clk`)은 한 페이지 20행뿐이라 전체 계수가 아니다. 종전 `a[href]` 계수는 **항상 0** 을 냈다.
3. **프로젝트 id 는 상세 URL 에서 회수한다** — 목록 링크에서 찾는 방식이 22:29·22:32 두 번 실패했다(`! 프로젝트 id 회수 실패`).
4. **단계 이동은 `reg-next` 한 testid** — 단계별로 다른 이름을 찾던 방식이 2단계에서 멈췄다.
5. **「＋ 추가」는 focus ＋ Enter** — 클릭 이벤트가 화면에 잡히지 않는 자리가 있다.
6. **격자 재확인(전체 파일 기준 영역 변경)** 을 등록 단계마다 다시 확인한다 — 파일이 늘면 영역이 바뀌어 확인이 다시 뜬다.
7. **대기 시간을 파일 건수에 비례해 준다** — 143건 묶음이 고정 대기에서 끊겼다. 격자 칸 대기는 상한 180s 이고 미출현은 「좌표 보유 판정」으로 읽는다(§5).
   ＋ **격자 경계 위생 실패는 등록을 멈추지 않는다**(§5 순번 16).
