2026-09-12~13 사용자 “왜계속 계획대로 안하고 멈추나. 계획 리스트업하고 전부 실행하라”에 따라 중간 단위마다 종료하던 방식을 중단하고 실험·제품 수정·기존 평가·실제 화면 검증을 이어서 수행했다. LLM 평가 보류는 유지했다.

## 판정 경계와 리뷰 반영

- 기존18의16통과는 필요 후보 포함/빈 후보 검사다. 수동2문항을 통과로 바꾸지 않았다.
- 새6은 **파일 후보 검사3개 + 관련 데이터셋을 오라클이 지정하는 조건 컴포넌트 검사3개**다. 후자3개는 실제 검색이 관련 자료를 회수하거나 답변을 생성했다는 증명이 아니다.
- 최초 새6 중 특정 날짜 파일 선택, 제외한 보조자료, 보간하지 않은 조건을 놓쳐 실패했다. 코드 수정 이후 최초 미공개 점수3/6을6/6으로 덮어쓰지 않았다.
- 독립 리뷰에서 추가 데이터셋이 섞여도 통과하던 부분집합 판정과, 보간 불일치에 해상도 근거를 잘못 표시하는 오류를 발견했다. 실패 시험 후 정확한 집합 비교와 보간 전용 출처로 수정했다. 수정 전 `heldout-revised.json`은 최신 근거가 아니다.
- 파일 역할·조건 판정 실험을 제품 필터에 연결한 것은 아니다. 제품 변경은 실제 검색어 정규화·파일명 주제 오인 수리·미확인 조건 설명이다. 실험 점수를 제품 점수로 보고하지 않는다.
- 제품은 연구실 범위·잠긴 카드·Verified·순위·페이징·503·해석 저하 계약을 유지한다. 브라우저 해석기는 HTTP 대역이며 실제 AI 서비스/LLM 평가는 아니다. 실제 SQL과 카드·상세 이동은 로컬 제품 코드다.
- E2E 도중 기존 로그인 실행기의 낡은 입력명/로그아웃 문구/DB URL 쌍 처리/초기 렌더 대기가 실패했다. 현재 fixture·화면에 맞춰 고친 뒤 전체 여정 exit0을 확인했다. 이전 실패를 무시한 재시도가 아니다.
- 서브에이전트 종료 훅은 격리사본 또는 동시 변경된 root의 기록을 검증하지 못했다. 훅 성공을 주장하지 않는다. 부모가 patch를 직접 검토·적용하고 자체 서비스 게이트와 화면 여정으로 검증했다.

## 실제 제품 검색 개선 측정

`literal-normalized.json`: 같은 dev25개 코퍼스와 같은 SQL을 확인했다. 기존7통과/3실패/2해당없음에서8통과/2실패/2해당없음으로 바뀌었다. 자동 포함 검사만이며 의미 판정12는 미실행이다. 로컬 수정 해석기→배포된 D3 읽기 전용 실행이고 배포된 전체 API를 수정한 것은 아니다.

## 기존 A층16건의 처리

기대값·기준선은 무수정이다. 추가자료를 버리거나 corpus를 몰래 줄이지 않기 위해 `--allow-extra-datasets`를 명시적으로 추가했다. 기본모드는 여전히 추가자료를 거부한다. 확대모드는 추가 결과를 `EXTRA:<id>`로 남기고 기준선 덮어쓰기를 금지한다. 결과6충족/9미충족/1판정보류이며, 아래 분류는 실패를 통과로 재분류하는 결정이 아니다.

| 항목 | 처리 방향 | 사유 |
|---|---|---|
| Q-01 기간·유역 | 수정 필요 | 강우 낱말만으로 기간·유역 조건을 충족한 후보처럼 보임 |
| Q-04 Bilinear | 수정 필요 | 방법 조건을 결합하지 않아 다른 가공 자료 혼입 |
| Q-05 GK2A NDVI | 재평가 조건 명시 필요 | 현재 데이터와 옛 정확집합 기대의 차이. 새 자료를 숨길 수 없음 |
| Q-06 천리안 | 재평가 조건 명시 필요 | 추가자료가 포함되어 옛 집합에서 회귀. 검색 자체 오류로 단정 금지 |
| Q-08 학회+다운스케일 | 수정 필요 | 다중 조건 결합과 역할 근거 필요 |
| Q-09 충청 | 재평가 조건 명시 필요 | 현재 corpus의 지역 일치 자료를 포함한 옛 정확집합 비교 |
| Q-11 강수량 | 명시적 한계/의미 검토 필요 | 접두 질의가 강수량 표기를 회수함. 옛 빈 결과 기대를 임의 변경하지 않음 |
| Q-12 위성 | 기존 판정보류 유지 | 기대문의 ‘등’과 토큰 중간 매칭 범위가 원 오라클에서 미결 |
| Q-13 다운스케 | 수정 필요 | 확장과 부분 표기의 의미 회수 부족 |
| Q-14 HSR 붙여쓰기 | 수정 필요 | 이름 유사도만으로 회수되지 않음 |

기존 실행기의 오래된 “합격선 없음” 출력은 현재 K4의 완료 정의를 대체하지 않는다. **미판정0+판정 후 전건통과를 충족하지 않았으므로 K4를 닫지 않는다.** RLS우회 읽기 전용 A층은 권한 증거가 아니며 Q19/Q20/B층16은 그 실행에서 미실행이다. 권한·장애는 별도 제품 회귀에서 검사했다.

## intent 대조와 남은 출시 조건

- O1 자연어 찾기: 영문 기술명 조사와 파일명 회귀 개선. 기간·지역·역할 전체 조건 검색은 실험 단계여서 제품 목적 완전 충족 아님.
- O2 역할·이유: 파일 역할을 출처로 검증하는 실험 구현. 제품 카드에서 검증된 파일 역할을 설명하는 기능은 아직 없음.
- O3 정직한 한계: 제품에 질문별 미확인 조건 설명 연결, 실험에서 불일치/근거없음 구분. 모든 검색의 의미 정확도를 보장하지 않음.
- O4 상세 이동: 실제 로컬 여정 검증.
- O5 레퍼런스 범위·골든 보강: 9묶음과24질문 확보. 기존 오라클 보존.

전체 계획의 남은 핵심은 **검토한 근거를 제품에서 수집·저장·갱신·권한에 따라 조회하는 경로 및 조건별 필터 통합**, 기존 품질 실패/오라클 미결 해소, 보류 중 모델 평가와 출시 검증이다. 이들을 단순 문구 수정으로 완료 처리하지 않는다. 제품 DB 쓰기·배포·main 반영은 수행하지 않았다.

## 최종 추가 검증

- 실제 로컬 해석기→고정 사전/그래프→dev D3 읽기 전용 재측정 `expanded-normalized-02.json`: 8통과/2실패/2해당없음. 이전 확장 기준선6/4/2 대비 개선됐지만 의미12문항은 미판정이다.
- 파일명 확장자 토큰이 사전에 다시 들어가는 결함까지 수정했다. 실제 해석기를 사용하는 통합 단위 시험으로 단독 tif·혼합 포맷 요청을 보존했다. 최종 AI142 통과(`ai-final-02/`).
- 프런트엔드 검색 관련3파일38시험 통과, 타입 검사 오류0. 전체 프런트엔드는 99파일1201시험 통과 후 worker 시작 timeout5건으로 **게이트 exit1 실패**(`frontend-final/`). 관련 시험 통과로 전체 실패를 대체하지 않는다.
- 평가 도구37시험 및 기존 A층 실행기3시험 통과. 알 수 없는 ‘말고’ 제외 요청이 파일 근거가 있다는 이유로 검증 완료 취급되던 실험 오류를 수정했다. 최신 보고서는 structured-probe-07 및 heldout-revised-03이다.
- core 순수 조건/조립 시험25통과, 전체 core1131통과. 브라우저 여정 종료 뒤 이번 작업의 로컬 HTTP 해석 대역도 종료했다.

## 근거 수집·갱신의 다음 단위도 실행

- `reference_evidence.py`: 설명서4개 실제 본문/문단/hash 수집, 기존 검토 주석10개를 snapshot 데이터셋/파일 ID에 연결했다. `source-provenance-01.json` 수집 exit0 및 원문 변경 검증 exit0(changed=[]).
- 새 시험5개: 실제 본문과 ID 연결, 원문 변경, 같은 이름 문서 중복, 대상 파일 부재, 루트 밖 경로 차단. 최초 모듈 미구현으로 준비 오류를 확인한 후 구현, 전체 평가 도구37시험 통과.
- 이는 설명서 텍스트 수집이며 자동 의미 추출/확인이나 제품 DB 저장이 아니다. 파일 내용 변경까지 현재 도구가 감지한다고 주장하지 않는다.
- 기존 기간·원천 컬럼은 재사용 가능하지만 파일 역할·출처 버전은 새 구조가 필요함을 확인했다. 자세한 바인딩·stale·삭제·잠김 규칙은 `prd/specs/STAGE3-AI-SEARCH-EVIDENCE-STORAGE.md`에 설계안으로 기록했다.
- 사용자에게 설명서 초안 추출 후 확인과 직접 입력 중 선호 흐름을 질문했다. 아직 응답 없음. 자동 의미 추출 구현에는 보류 중인 모델 결정도 필요하며 이를 우회해 임의 모델을 호출하지 않았다.
- 최종 대장 일치 검사 `ledger-final/` 통과(파서 대상 밖9건 명시), 공백 검사 통과. K4 open 유지.
