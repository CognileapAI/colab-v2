## 4. 판정 넷 — 실물을 보고 정했다

- **등록 전 업로드(S-04·S-08) = 제공하지 않는다.** 자리에 굽는 것은 접수분을 도는 워커
  (`domains/d5_ingestion.py:237` → `d5/pipeline.py run_file`)뿐이고, 미등록 미리보기는 `uploadId` 로
  **그리는 서버의 메모리에만** 산다(`JobStore` · TTL). **읽을 산출물이 그 경로에 서지 않는다.**
- **좌표 없는 자료(비지도형) = 기능이 없다.** **「실표본 n건」은 적지 않았다** — 자리 계수로 갈라 셀 수
  없다(②비지도형 층은 **모든 렌더가 만든다** · `.pgw` 있는 `.png` **15** / 없는 `.png` **17** / `.webp` **17**).
  **없는 수를 지어내는 대신 성질로 못 박았다.**
- **권한 = 본체 접근이 필요하다.** 잠긴 데이터셋은 `d3_file` 의 **`body_access` RESTRICTIVE** 아래서
  본체 행이 **0건**으로 보인다(`0001_p0_platform.py:487`). 확대(보기 권한만)와 **다른 자리**다.
- **음성 조건 — 내용 키만으로 값을 내주지 않는다.** 키 재료에 **연구실이 없다**(`MAP_TILE_KEY_FIELDS`).
  값 조회는 언제나 `datasetId` 로 들어와 `_target_in_lab` 을 지난 뒤 산출물에 닿는다.

## 5. 감추지 않고 적은 것 — 모든 자료에 서지는 않는다

다루는 형식 **여섯** 중 **`NumPy`·`GRIB` 는 굽는 경로가 없어 `지원 목록 밖` 으로 실패**하고,
**이미 COG 인 GeoTIFF 는 변환을 건너뛰어 자리에 파일을 두지 않는다**(`d5/pipeline.py` 실측).
자리 계수도 그 결이다 — **80건 11 MB 중 `.tif` 1건** · 지도형 산출물 **15건**.
**그 자료들로 넓히는 일은 이 회차가 정하지 않는다 — 범위를 늘리지 않았다.**
