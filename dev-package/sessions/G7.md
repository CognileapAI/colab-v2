## 5. G1 최신성 게이트(`check-package-freshness.py`) 영향 — **영향 없음**

`dev-package/tools/check-package-freshness.py` 를 읽었다. 검사 로직은:

- `정본루트/에픽/E-*/` 하위의 `package/*.html` 과 `documents/*.md` 만 순회한다(`check()` 함수, `epics_dir = os.path.join(root, EPICS_DIRNAME)`).
- 대상 파일은 `package/` 안의 HTML 1개, `documents/` 안의 `.md` 들뿐이고, 비교는 HTML 내부의 `<script type="text/markdown" id="md-(prd|policy)">` 임베드 블록과 원본 `PRD_*`/`Policy_*`/`DataModel_*` md 파일의 SHA-256 해시 일치 여부다.

G7이 만들 5개 파일(`README.md`·`에픽_목록.md`·`IA_사이트맵.md`(+html)·`백로그.md`·`사용자_핵심_시나리오.md`)은 전부 **정본 루트 최상위**에 놓이고, `에픽/` 하위도 `package/`·`documents/` 안도 아니다. 게이트의 `epics_dir` 순회 범위 밖이라 **새 파일을 추가해도 게이트 스캔 대상에 전혀 걸리지 않는다.** 즉 G7 실행이 `planning-freshness` 게이트의 pass/fail에 영향을 주지 않는다.
