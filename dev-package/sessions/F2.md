## 6. 함정

- `relative_path` 를 **쓰기만 하고 읽지 않았다**(0008 — `_FILES` SELECT 부재). 시험이 DB 행만 봤다. → 읽기 경로까지 시험(`UploadFileRef.relativePath` 왕복).
- `recompute_grid_metadata` 는 사람이 적은 `crs` 를 지운다 — 본체 경로에서 부르면 안 된다.
- `total_size_bytes` 를 앱 코드·시드가 손으로 쓰면 트리거와 **두 번 센다**(실측 200==100). 같은 기구 하나로.
- 다운로드 302 는 브라우저가 Bearer 를 못 실어 401 — 계약이 그렇게 적혀 있었어도 도달 불가.
- `security: []` 바이트 op 은 `scoped_db` 를 못 쓴다 — 티켓 클레임으로 `apply_scope`.
- S3 `put_stream` 은 SigV4 본문 해시 때문에 진짜 스트림이 아니다(read 폴백, ≤5 GiB).
- CI `contract-breaking` 이 기준 없이 돌아 구조적 green(HANDOFF §4 #39).
