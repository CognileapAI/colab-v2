## 1. ⑵ 읽는 경로 — **200 · 사전 확장 실동작**

**세는 기준** = 서빙 중 `colab_v2_staging_ai_service` 의 HTTP 표면에 **실제 요청 1회**.
**시점** = 2026-08-29T20:49:45+0900 · 20:50:23+0900.
**명령** — 일회용 컨테이너(`--rm`)를 스택 네트워크에 붙여 발신. 호스트 포트 미공개.

```
docker run --rm --network colab-v2-staging_default curlimages/curl:latest \
  -sS -w '\nHTTP=%{http_code}\n' -X POST http://ai-service:8200/searches \
  -H 'Content-Type: application/json' \
  -H 'X-CoLAB-Lab: <ULID>' -H 'X-CoLAB-Account: <ULID>' \

```

|---|---|---|
| 1 | `해수면 온도` | **HTTP 200** · `degraded:false` · `interpretation.terms=["해수면","온도"]` · `source:"literal"` |
| 2 | `25년도 낙동강 유역 강우데이터 찾아줘` | **HTTP 200** · `degraded:false` · `terms=["25년도","낙동강","유역","강우데이터","찾아줘","강우·강수","낙동강 유역"]` · **`topic:"강우·강수"`** |

### 1.1 ⚠ 완료 정의가 든 오라클이 실물과 다르다 — **그 자체가 green-by-skip 모양이다**

`R1-RESTORE-DRAFT §4.6-③-보` 는 *「`_UnavailableDictionaries` 면 여기서 **`RuntimeError`** 가 난다」* 로 적는다.
**실물은 그렇지 않다.** `services/ai-service/src/colab_ai/domains/d10_ai_services.py:146-153` 이
`self._dictionaries.expand(...)` 를 `try/except Exception` 으로 감싸 **사전이 죽어도 200 을 낸다** —
`degraded=true` ＋ `reason="온톨로지 사전을 읽지 못해 …"` 로 내려앉을 뿐이다.

**⟹ 이 꼬리의 옳은 오라클 = 「HTTP 200」이 아니라 「`degraded:false` ＋ 확장 산출」이다.**
상태코드만 보면 **사전이 끊겨도 통과**한다. 잰 값은 옳은 오라클로 쟀다.

| ㈑ | **P9** 사고 원인 미기재 | 1 | **의도 · fail-closed** — 리허설에 적으면 **지어낸 값**이 된다 |

`P8` 은 `--record-digests` 를 줘서 **기록 자체는 PASS** 했다. 다만 그 안에서 도는 대장 대조가 RED 다 → §3.

**⟹ 판정 = `preflight` 가 리허설 경로에서 GREEN 이 못 되는 것은 원칙적으로 「의도」다.**
P9 는 **사고가 나야 있는 값**을 요구하는 자리이고, 이것이 비어도 통과하면 그것이야말로 green-by-skip 이다.
**막는 것은 기구가 아니라 뜻이다** — 코드는 「비어 있지 않기만」 보므로, 리허설에서 통과시키는 것은 **거짓말을 적는 것**이다.

### 2.1 ⛔ 그러나 **의도만으로는 설명되지 않는 RED 가 둘 있다 — 새 결함이다**

```
FAIL P5-b 볼륨 uploads 의 짝(platform-20260829T033005.sql.gz) ≠ 되돌릴 원장(platform-20260829T100801.sql.gz)
FAIL P5-b 볼륨 previews 의 짝(platform-20260829T033005.sql.gz) ≠ 되돌릴 원장(platform-20260829T100801.sql.gz)
```

- **원인** — `preflight.sh:29-31` 의 `pick()` 이 **원장과 볼륨을 각각 독립으로 「최신」** 으로 고른다.
  원장 전용 백업이 한 번이라도 볼륨보다 뒤에 뜨면 짝이 깨진다. 이번에 그 일이 실제로 있었다 —
  **2026-08-29T10:08 배포전 백업**(원장 둘만 · `release-ledger.tsv` 의 green `deploy` 행과 같은 시각).
- **`--stamp` 가 우회로가 되지 못한다** (실측 2026-08-29T20:48:23+0900 · `--stamp 20260829T033005`):
  `P5-b uploads` 는 PASS 로 바뀌지만 **`P2 볼륨 previews 아카이브가 없다`** 로 새 RED 가 난다.
  `backup-full.sh` 가 **볼륨마다 다른 스탬프**를 찍기 때문이다(`vol-uploads-…T033005` vs `vol-previews-…T033040` · 35초 차).
- **⟹ 네 산출물을 한꺼번에 옳게 고르는 스탬프가 존재하지 않는다.** 즉 **입력을 다 줘도 GREEN 이 안 된다** —
  이것은 「사고가 나야 있는 값」과 성질이 다르다.
- **푸는 법(설계 선택지 둘 · 이번에 고르지 않았다)** — ⓐ `pick()` 이 볼륨의 `.pair` 를 읽어 **원장을 짝에서 역산**한다
  ⓑ `--stamp` 를 **회차 접두 매칭**으로 바꿔 한 회차의 볼륨 전부를 잡는다. **어느 쪽도 코드 변경이라 이 회차 밖이다.**

## 3. ⑷ `:i2` 태그 이동 이력 — **현재값은 닫히고 이력은 안 닫힌다**

**세는 기준** = `infra/staging/restore/check-image-digests.sh`(대장 대조 · 읽기 전용) **실행**.
**시점** = 2026-08-29T20:47:38+0900. **결과 = digest 대조 RED · 불일치 5건 / 8건.**

| 대상 | 결과 |
|---|---|
| `colab-v2/{core-api,pipeline-worker,ai-service,viz-render,frontend}:i2` | **5건 전부 불일치** |
| `postgres:16-alpine` · `nginx:1.27-alpine` · `cloudflare/cloudflared:latest` | **3건 일치** |

- **대장이 낡았다.** `reference/IMAGE-DIGESTS.md` 는 2026-08-27 값이고, 그 다섯 값은 **지금 `:prev` 태그가 가리키는 이미지**다.
  즉 **직전 세대 하나는 태그로 살아 있다** — 그러나 `:prev` 는 **스키마 정합 미보장**이라 되살릴 수 없다(`〈186〉-㉯`).
- **언제 움직였나 — 이번에 날짜가 붙었다.** `~/colab-v2-releases/release-ledger.tsv` 3행 실측:
  `2026-08-28T21:12:21 approve 0a3ea797dbb1` · `2026-08-28T21:34:18 deploy 0a3ea797dbb1 red`(롤 부트스트랩 실패) ·
  **`2026-08-29T10:08:36 deploy 30b3e0a7b3f3 green`**. 자체 5종 이미지 생성 시각 = **2026-08-28T21:34**,
  `:i2` 와 릴리스 태그 `30b3e0a7b3f3` 를 **같은 이미지가 함께** 달고 있다.
  ⟹ **`:i2` 는 2026-08-29T10:08:36 의 green 배포에서 지금 자리로 옮겨졌다.**
- ⛔ **그래도 닫히지 않는다.** 원장이 적는 것은 **릴리스 태그**이고 **digest 가 아니다.**
  그 이전 이동은 이미지가 덮이면서 사라졌고, **`:i2` 가 과거 어느 시점에 무엇을 가리켰는지는 복원되지 않는다.**
  요구된 것은 「현재값」이 아니라 **「이력」**이다(`R1-RESTORE-DRAFT §5-5`).
- **푸는 법(선행 회차 것을 그대로 잇는다)** — ⓐ `deploy.sh` 가 `:i2` 를 옮길 때 **digest 한 줄을 원장에 append**
  ⓑ `IMAGE-DIGESTS.md` 갱신을 배포 절차에 건다(대장 `§4-3` 이 이미 요구하는 것이고 **이번 배포에서 지켜지지 않았다**).
- ⚠ **대장을 이 회차에 갱신하지 않았다.** 갱신은 「무엇이 왜 바뀌었는지」를 아는 배포 회차의 일이고(`§4-3`),
  여기서 값만 덮으면 **대조 기준을 잃은 채 초록만 만드는 것**이다.
