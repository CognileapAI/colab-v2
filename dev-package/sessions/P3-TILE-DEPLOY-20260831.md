## 2. 타일이 실제로 사는가 — 배포된 스택에서 쟀다

「스택이 떴다」를 「타일이 산다」로 읽지 않았다. 공개 주소(`POST /api/v1/previews`)로
**렌더를 실제로 걸어** 완료 결과를 봤다.

| 무엇 | 실측 |
|---|---|
| 지도형 결과의 키 | `bounds`·`colorRangeStage`·`legend`·`precisionBadge`·`sidecarUrl`·`thumbnailUrl`·**`tileUrlTemplate`**·`valuePreviewUrl`·`worldFileUrl` — **`imageUrl` 없음**(`oneOf` 택일) |
| 표본 | 지도형 **3건**(`PV-1 실측 업로드 GK2A NDVI` · `HSR 레이더 견본` · `MODIS MOD15A2H 견본`) **전부 같은 모양** |
| 서명 | `exp`·`sig` 붙어 나온다 |
| 타일 조각 — **viz-render 직접** | `z=6·8·10` 세 자리 **200 ＋ `image/png`** (2,198 · 3,290 · 1,614 B · 매직 `89504e47`) |
| 타일 조각 — **공개 엣지** | 같은 세 자리 **200 ＋ `text/html` 409 B** = 프론트 **`index.html`** |

⛔ **그래서 갈림이 하나 남는다 — `03-HANDOFF §4` #51.**
`infra/staging/nginx.i2.conf` 의 `location` 은 `/healthz*` · `/api/v1/` · `/previews/` 뿐이고
**`/viz/` 가 없다.** 나머지가 `location /` 로 frontend 에 가고 frontend 의 nginx 는
SPA fallback(`try_files … /index.html`)이라 **404 도 아닌 200** 을 낸다.
**200 이 성공을 뜻하지 않는다** — 이 레포의 대표 실패형 그대로다.

⚠ **중계로 우회할 수 없다.** 타일은 **core-api 를 지나지 않는 유일한 경로**이고
(`services/viz-render/README.md`) 계약이 「**타일 URL 은 중계하지 않는다 — FE 가 직접 소비한다**」
(`fe-core.yaml createPreviewRender`)라고 못 박았다.

⚠ **사용자 관점의 회귀다** — 종전 지도형은 엣지가 실제로 내주는 `/previews/…` PNG 였다.

**손대지 않았다** — 엣지에 `/viz/` 를 여는 것은 운영 스택 변경이고, 계약이 「타일 경로만
CDN 뒤」라고 적어 둔 자리라 **어디에·어떤 캐시·어떤 인증으로 여는가가 판정 사항**이다.
**없는 결정을 지어내지 않는다.**

`imageUrl` 하나로 남고, 그 성질은 `services/viz-render/tests/test_render_result_tiles.py`
의 음성 시험이 잠근다(`tileUrlTemplate` 없음 · `bounds` 없음). ⚠ **배포된 스택의 등록

확인하지 못했고 **지어내지 않는다.** 잠그는 자리는 시험이다.
