## 2. 정본이 말한 것 · 말하지 않은 것

**말한 것 (그대로 따랐다) — `contracts/storage/layout.json`**

| 자리 | 축자 |
|---|---|
| `keys.미리보기 산출물` | 「**자리가 있어야 이미 구운 것을 찾아 쓴다.** 자리가 없으면 같은 그림을 매번 다시 굽는다.」 |
| 같은 절 ① | 「**같은 입력이면 같은 키**이므로 재사용이 성립하고, 입력이 하나라도 바뀌면 키가 갈려 무효화가 규율이 아니라 **키 자신**의 일이 된다.」 |
| `contentKeys.지도 타일.why` | 「같은 원본을 같은 설정으로 변환하면 같은 키이므로 **재사용이 성립하고** …」 |

키가 내용 주소라 별도의 표도, 계약 페이로드 확장도 필요 없다. 계약 동결을 열지 않았다.

**말하지 않은 것 (결정하지 않고 남긴다 · §6)** — 사건 ↔ 타일 파일의 **개별 대응**을 어디에 기록하는가.
지시가 이미 열린 것으로 지목한 둘(타일 서빙·확대 · 지점 클릭 값 조회)도 그대로 열려 있다 — **건드리지 않았다.**

## 4. `DATA-REFERENCE` 에서 **다시 재지 않고 가져다 쓴 값**

- **HSR 스펙 전량** — 헤더 1024 B · `NX=2305`·`NY=2881` · `<i2` · `/100` → dBZ · 파일 크기 13,282,434 B(§2). 픽스처를 이 스펙대로 지었다.
- **격자 파일 형상·dtype 16건**(§1) — HSR `(2881,2305)` `<f4` · HLS `(3660,3660)` `<f8` · MODIS `(2400,2400)` `<f8` · GK2A `(900,900)` `<f4`. 실데이터 시험의 짝 파일을 이 값으로 골랐다.
- **격자를 어디서 얻는가(§1.1)** — **밖에서 받아야 하는 것은 HSR 하나**, 나머지 4종은 파일 내부 계산. 실데이터 시험 3종을 이 갈래에 맞춰 짰다(bin·nc·hdf).
- **`M-8`(명세 ≠ 파일) · `M-4`(인용은 파일이 아니다)** — 그래서 게이트의 COG 판정을 **명세가 아니라 실제 산출 타일 바이트**로 대조했다(§5-끝).
- **§0 의 「여덟 중 일곱이 에러 없이 그럴듯한 값」** — 재사용 판정을 「파일이 있다」가 아니라 **구조(IFD)** 로 세운 근거다.

**다시 재지 않은 것 = 위 전부.** 이번에 새로 잰 것은 아래 §5 의 값뿐이다.

## 5. 무엇이 이미 있었고 무엇을 세웠나

**이미 있었다 (건드리지 않았다)** — 헤더 파싱 · 좌표계 정규화 · COG 변환 · 사건 ③④⑤ 발행 · 전용 타일 키 ·
산출물을 그 키 자리에 놓기. 즉 **「굽기」는 이미 서 있었다.**

**없었다 = 「찾아 쓰기」.** `run_file` 이 자리를 보지 않고 **매번 다시 구웠다.** 기존 시험은
「두 번 돌리면 **키가 같다**」까지만 단언하고 「**다시 굽지 않는다**」는 단언하지 않았다 —
키가 같다는 것과 굽지 않는다는 것은 다르다.

### 세운 것 ㉮ — 재사용 (`d5/pipeline.py`)

- 자리가 선언되면 키 자리를 **본다.** 쓸 수 있으면 굽지 않고 `reused=True` 로 돌려준다.
- **`artifact` 를 만들지 않는다** — 이번 회차가 만든 것이 없으므로 산출물 기록도 없다(`DR-2` 와 같은 결).
- ⚠ **「파일이 있다」를 「구워져 있다」로 읽지 않는다.** 0 바이트·중단된 쓰기·쓰레기 잔재가 그 자리에
  남을 수 있고, 그것을 재사용하면 **에러 없이 깨진 미리보기**가 나간다. 그래서 **구조로** 판정한다 —
  IFD 를 읽어 COG 층(타일 배치 ＋ 개관)이어야 재사용한다. 아니면 `rebuilt_unusable` 을 세우고 다시 굽는다.
- 자리를 선언하지 않으면 재사용 없이 임시 자리에 굽고, **그 사실을 `notes` 에 적는다.** 조용히 성공으로 세지 않는다.

### 세운 것 ㉯ — 게이트 `preview-tile-slot` ＋ `preview-tile-slot-selftest`

- 세는 단위 = **자리에 놓인 지도 타일 파일 1건.** 사건으로 세지 않는다 — 재사용이 성립하면
  사건 여럿이 타일 하나를 함께 쓰므로 사건 수와 파일 수는 애초에 같지 않다.
- 대조 둘 = ⑴ 발행됐는데 자리가 비었나 ⑵ 자리에 있는데 COG 층이 아니라 **재사용이 영원히 거절되나**.
- 세 상태 — 대상 있으면 검사 · `gates/config/preview-tile-slot.toml` 에 **파일 이름으로** 적히면 건수를
  드러낸 채 통과 · 아무 말 없으면 red. 적용 DB·자리 경로 미선언도 red, **대상 0건도 red**.
- **픽스처 TIFF 는 바이트로 지었다** — 라이브러리를 들이면 「무엇이 COG 인가」의 판정이 라이브러리로
  옮겨가고, 그러면 selftest 가 게이트의 기준을 증명하지 못한다.

### ⚠ 대상 0건 함정을 어떻게 피했나 — 이 자리가 특히 노출돼 있다

**이 게이트의 자연스러운 대상 수는 오늘 0 이다.** staging 미리보기 볼륨 실측 = 파일 **39건**
(`png` 16 · `webp` 9 · `json` 7 · `pgw` 7) 이고 **`tile-*` 는 0건**(2026-08-30 · `docker exec … ls`, 읽기 전용).
워커에 `COLAB_WORKER_STAGE2`·`COLAB_WORKER_PREVIEW_DIR` 이 **둘 다 미선언**(같은 시점 실측)이라 stage 2 가 돌지 않는다.
→ **0 을 통과로 세면 이 게이트는 아무것도 안 보면서 green 을 찍는다.** 그래서 `TOTAL=0` 을 red 로 못 박고,
selftest 케이스 ⓔ 가 그 red 를 **픽스처로** 증명한다(자리를 비우고 돌린다).

## 9. 멈춘 자리 — 사람이 고른다 (이번에 결정하지 않았다)

1. **배포에 `COLAB_WORKER_STAGE2=on` 과 `COLAB_WORKER_PREVIEW_DIR` 을 넣는 것** — 운영 접촉이라 하지 않았다.
   넣지 않으면 stage 2 는 계속 안 돌고, 이 항목의 공통 완료 조건 **`staging 배포 green` 이 닫히지 않는다.**
2. **`preview-tile-slot` 이 CI 에서 볼 적용 DB 와 미리보기 자리** — `autometa-loss`·`schema-diff` 와 같은 DB 변수를
   쓰되 자리 경로(`COLAB_PREVIEW_TILE_DIR`)는 새 값이다.
3. **사건 ↔ 타일 파일의 개별 대응을 어디에 기록하는가** — 오늘은 자리(내용 주소)만이 기록이라 게이트가
   **건수 수준**으로만 대조한다. 개별 대응을 원하면 갈래 셋 — ⓐ `preview.cog-built` 페이로드에 내용 키를
   싣는다(**계약 동결 해제 ㉯ · Ted 승인 필수**) ⓑ 장부에 열을 둔다(DDL) ⓒ 지금대로 자리만 기록으로 둔다.
   **정본이 이 물음에 답하지 않는다 — 지어내지 않았다.**
4. **타일 서빙·확대**(시각화 항목 `P3` 소유) · **지점 클릭 값 조회** — 둘 다 정본 무근거로 종전대로 열려 있다. 건드리지 않았다.
