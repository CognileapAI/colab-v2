## 9. 회차 중 밟은 사고 하나 — **워크트리는 `git stash` 스택을 공유한다**

- **무엇이 일어났나** — 기준선을 재려고 `git stash -u` 로 변경분을 잠시 치웠는데, **같은 시각 병렬 레인
  (`lane-p5`)도 stash 를 밀어 넣어** 스택 꼭대기가 바뀌었고 `git stash pop` 이 **남의 작업분을 이 워크트리에
  꺼냈다.** `.git` 이 하나이므로 stash 는 워크트리별이 아니다.
- **회수** — `git fsck` 의 dangling 커밋에서 이 레인의 stash(`3896158` ＋ untracked 부모)를 찾아 되돌렸다.
  **되돌리기 전에 남의 작업분(tracked diff ＋ untracked 2파일)을 레포 밖에 따로 보존했다** — 남의 것을
  지우면서 회수하지 않는다. **잃은 것 0건**이고 회수 뒤 `tsc` 종료 0 · **329 passed / 0 failed** 로 재확인했다.
- **규칙** — **다중 워크트리 회차에서 `git stash` 를 쓰지 않는다.** 기준선은 별도 체크아웃이나 임시 커밋으로 잰다.
