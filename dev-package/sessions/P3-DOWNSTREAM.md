## 2. 이번에 세운 것 — 선언된 의존이 빠지면 **시험이 조용히 사라지던 자리**를 막았다

하류 넷이 전부 막힌 자리에서 **그 하류가 올라탈 바닥**을 봤다. 거기에 이 레포의 대표 실패형이 있었다.

### ㉮ 실물 — `pytest.importorskip` 6 자리

| 자리 | 이름 | 그 이름이 선언된 곳 |
|---|---|---|
| `tests/conftest.py:27` | `jsonschema` | `requirements-dev.in:5` · `requirements.txt:11` (`==4.26.0`) |
| `tests/test_grid_canonical_nc.py:28`·`:64` | `h5py` | `requirements.in:7` · `requirements.txt:8` (`==3.16.0`) |
| `tests/test_grid_combined_nc.py:19`·`:58` | `h5py` | 〃 |
| `tests/test_axis_detect.py:116` | `h5py` | 〃 |

**여섯 전부 「선언·핀된 의존」이다.** 이미지에서 그 의존이 빠지면 시험은 **red 가 아니라 skip** 이 되고
요약줄은 green 을 찍는다. **사라지는 시험 중 둘은 HSR 정본 격자 off-by-one 을 지키는 자리**이고,
그 결함은 그 파일 자신이 「그림은 멀쩡하고 값만 한 칸 옆으로 붙는다」로 적는 종류다.
그리고 `conftest.py:27` 은 **사건 봉투를 동결 계약으로 검증하는 픽스처** 자체다 — 그것이 조용히 빠지면
계약 검증이 통째로 사라진 채 green 이 난다.

**형제를 남기지 않았다** — `services/**`·`gates/**`·`eval/**` 전수 스윕에서 나온 `importorskip`·
`skipif`·`pytest.skip` 은 **이 여섯이 전부**였고(그 밖 0 건), 여섯을 다 고쳤다. 그리고 **잔존을 시험이 지킨다**
(`test_every_importorskip_on_a_declared_dependency_is_gone` — 파일을 직접 훑어 0 건을 단언).

### ㉯ 세 상태로 만들었다 (`tests/depgate.py` · `require_dep()`)

| 상태 | 동작 |
|---|---|
| **선언돼 있고 import 된다** | 모듈을 돌려준다 — **검사한다** |
| **선언돼 있고 없는데 `COLAB_TEST_ALLOW_MISSING_DEPS` 에 이름이 있다** | 건너뛰되 **건수를 세어 요약줄에 적는다** |
| **그 밖 전부** — 면제 없음 · 빈 값 · `*` · **선언 자체가 없음** | **실패한다** |

- 면제는 **이름으로만** 준다. `*` 는 이름이 아니라 걸리지 않고, `VAR=` 빈 값도 면제가 아니다
  (관대한 기본값 금지 · `CLAUDE.md §4`).
- **선언 목록은 파일에서 읽는다**(`requirements.in`·`requirements-dev.in`) — 코드에 다시 적지 않는다.
  **그 목록이 0 건이면 red** 다(모수를 세는 시험 1건).
- 건수는 세기만 하지 않는다 — `conftest.pytest_terminal_summary` 가 **요약줄에 찍는다.**
  세기만 하고 안 적으면 숨긴 것과 같다.

### ㉮ 팔레트 선택 서버측 재렌더 (`V-1`) — **정본이 말한다**

  저장하지 않는다** — 화면을 떠나면 기본값으로 돌아간다 ｜ **바꾸는 즉시 지도와 범례가 갱신된다**」

1. 팔레트를 바꾸면 **서버가 다시 그린 산출물**이 나온다 — 브라우저에서 색을 바꿔치기하지 않는다(`:207`).
2. 팔레트 선택지는 **정확히 3 개**, 구간 수는 **3~9 이고 기본 6** — **경계 밖 값(2·10)은 거부된다**(`:129`·`:163`).

  기본 팔레트가 무엇인지도 없다.

**그래서 제안 = 「완료 정의를 쓰지 말라」가 아니라, 그 앞의 질문이 먼저다.**
「타일 서빙·확대」와 **정확히 같은 자리**다 — 완료 정의를 요구하는 항목이 정본에 근거가 0 건이다.
정할 것 = ⓐ 지도에서 한 점의 값을 읽는 기능이 제품에 있는가 ⓑ 있다면 그것이 무엇을 답하는가
(범례로 읽는 것과 무엇이 다른가) ⓒ 정본에 그 행을 세울 것인가, **아니면 이 항목을 `VZ-1` 처럼
범위 밖으로 내릴 것인가.** **지어내지 않았다.**

> 조건부 초안 — **ⓐ 가 「있다」로 판정될 때만 뜻이 있다.** 그 경우에도 측정 가능한 것은
> 「좌표 하나로 물으면 그 격자 칸의 값과 단위가 돌아온다 · 자료 없는 칸은 **0 이 아니라 「없음」**으로
> 구분된다 · 격자 밖 좌표는 거부된다 · 대상 0 건이면 red」 정도이고, **화면 쪽(누르는 방식·표시 자리·
> 권한)은 정본 없이 한 줄도 쓸 수 없다.**

## 4. `[미확인]` 해소 ① — 시각화 렌더러 시험 전량 (직전 회차 범위 밖이었다)

직전 회차는 「`viz-render/.venv` 가 없어 재지 않았다」로 `[미확인]` 을 남겼다. **이번에 쟀다.**

| 조건 | 값 |
|---|---|
| 원천 마운트 **있음**(`COLAB_REFERENCE_DATA`) | **119 passed · 0 failed · 0 skipped** |
| 원천 마운트 **없음** | **111 passed · 8 failed** — 8 건 전부 실데이터 E2E |

**마운트 없을 때의 8 failed 는 옳은 동작이다.** 그 시험들이 스스로 「`COLAB_REFERENCE_DATA` 가 원천
디렉터리를 가리키지 않는다 — **E2E 는 skip 하지 않는다**」로 **fail-closed** 를 적는다. 세 상태 중
「아무 말도 없으면 실패한다」가 이미 서 있는 자리다.

⭑ **그 8 건이 `S3`(실데이터 4종 E2E)의 렌더 쪽 절반이다** — GeoTIFF · NetCDF · Binary(HSR) · HDF4
**4종 전건 완주 green**(＋격자 부재·변수 생략·격자 일치 3건). **`S3` 이 아직 못 닫는 이유는 렌더가
아니라 「시각화 **화면**에 그려지고」와 「계보가 확정 상태로 남는다」 쪽**이고, 그 앞을 `PV-1` 이 막는다.

## 5. `[미확인]` 해소 ② — 「가공됨」 표식의 계보 그래프 노드 구분(`LV-3` ⓑ)

대장이 「**ⓑ 의 실물은 미확인** — 계보 그래프 화면 자체가 아직 없다. 푸는 법 = `P3` 착수 시 노드 렌더
구현 자리에서 확인」으로 적었다. **화면이 직전 회차에 섰으므로 이번에 확인했다.**

| 갈래 | 실측 |
|---|---|
| 값 집합 | 계약·DB 양쪽에 **세 값이 열려 있다** — `contracts/schemas/common.json:151` `enum: ["ai","manual","processed"]` · `db/platform/schema.sql:487` `CHECK (origin IN ('ai','manual','processed'))` |
| 화면이 값을 **들고 있나** | **들고 있다** — 계보 화살표에 `data-origin` 이 값 그대로 붙는다(`LineageSection.tsx:291`) |
| 화면이 값을 **구분해 보이나** | **`ai` 만 구분된다**(`✦` 부착 · `:293`). **`processed` 는 `manual` 과 시각적으로 같다** — 경로 플래그 함수가 `ai`·`manual` 둘에만 문구를 준다(`:141`~`:152`) |
| 표시할 대상 | **0 건** — 계약 자신이 「`processed` 를 만드는 생산 경로는 아직 없다」고 적는다(`common.json:149`) |

**판정 = ⓑ 는 「자리는 있고 표식이 없다」.** 그리고 **이번에 만들지 않았다** — 이유 둘:
⑴ **정본이 `processed` 의 문구를 한 줄도 주지 않는다**(직전 회차에 이미 확인해 지어내지 않기로 한 자리)
⑵ **표시할 행이 0 건**이라 지금 만들면 **시험할 수 없는 기능**이 생긴다(`VZ-1` 을 범위 밖으로 내린 것과 같은 근거).
`LV-3` 은 `after_stage2` 이고 `DP-1` 이 열려야 대상이 생긴다. **`[미확인]` 은 「미확인」이 아니라
「확인했고, 남은 것은 정본 문구와 생산 경로다」로 바뀐다.**

## 7. `PLAN-SoT §9` 등재 문안 (번호는 오케스트레이터가 발급)

> **〈NNN〉 계보 그래프 하류 7건을 재고, 「지을 수 있는 것이 0 건」임을 값으로 못 박은 뒤 바닥의 green-by-skip 여섯을 고쳤다.**
> **하류 = 정확히 7 건**(대장에서 `depends_on` 에 계보 그래프를 든 항목 전건 실측).
> **완료 정의 유무 = 있다 4**(렌더 산출물 자동 무효화 · 승인 처리 · 실데이터 4종 E2E · 「가공됨」 표식)
> **· 없다 3**(팔레트 서버측 재렌더 · 지도 값 조회 — 둘 다 `〈213〉` 으로 **의도적 미작성** · 경계·점 표현 — **범위 밖이라 없는 것이 옳다**).
> **막는 것 = staging 배포만이 아니다.** 정의가 있는 넷이 **전부 다른 것에도 막힌다** — 자동 무효화·실데이터 E2E 는
> **미리보기 뒷단**(`open`)이, 승인 처리는 **검색 화면(`open`)·프로젝트 화면(`partial`)**이, 「가공됨」 표식은
> **데이터 프로세스(`open`)와 표시 대상 0 건**이 막는다. **따라서 이번 회차에 짓기로 넘어간 하류 항목은 0 건이고, 대장 상태 변경도 0 건이다.**
> **완료 정의는 한 건도 세우지 않았다** — 두 지도 항목의 제안 초안은 **세션 파일에만** 있고 대장은 무편집이다(실측).
> **제안의 핵심 = 둘의 성격이 다르다.** 팔레트 재렌더는 **정본이 축자로 말한다**(재렌더 트리거 · 팔레트 3종 ·
> 구간 3~9 기본 6 · 설정 미저장 · 범례 동기 · 편집 권한자 한정 · 서버 렌더) — 침묵은 **팔레트 이름·색값과
> 재렌더 실패 처리**뿐이다. **지도 값 조회는 정본 근거가 0 건이다** — 상호작용 표 열넷에 해당 행이 없고,
> 정본의 「값」은 전부 **그릴 변수 선택**을 뜻하며, 지도에서 값을 읽는 수단으로 정본이 주는 것은 **범례 하나**다.
> **「타일 서빙·확대」와 같은 자리이므로 같이 판정받아야 한다.**
> **집행 = 하류가 올라탈 바닥의 green-by-skip 6 자리를 세 상태로 고쳤다.** 선언·핀된 의존
> (`h5py` 5 · `jsonschema` 1)에 `pytest.importorskip` 이 걸려 있어 **의존이 빠지면 시험이 red 가 아니라
> skip 이 되고 요약줄이 green 을 찍고 있었다.** 사라지는 시험 둘은 **격자 off-by-one**(그림은 멀쩡하고 값만
> 한 칸 밀리는 오류)을 지키는 자리이고, 하나는 **사건 봉투를 동결 계약으로 검증하는 픽스처 자체**다.
> 세 상태 = **선언＋import 되면 검사 · 이름으로 명시 면제하면 건수를 요약줄에 드러낸 채 통과 ·
> 그 밖 전부(면제 없음 · 빈 값 · `*` · 선언 자체 없음) 실패.** 선언 목록은 파일에서 읽고 **0 건이면 red** 다.
> **형제 전수 스윕 = `services/**`·`gates/**`·`eval/**` 에서 나온 것이 이 여섯뿐이었고 여섯을 다 고쳤으며, 잔존 0 건을 시험이 지킨다.**
> **red 실측(주장 아님) = 의존을 실제로 지우고 out-of-process 로 쟀다** — 개정 전 **15 passed / 6 skipped
> (red 0)**, 개정 후 **7 failed**, 명시 면제 시 **6 skipped ＋ 요약줄 「면제로 건너뛴 의존 검사 6건 — h5py×6」**.
> 구현 전 red 도 실측했다(수집 error → 형제 스윕만 1 failed / 10 passed → 11 passed).
> **`[미확인]` 둘 해소 = ⓐ 시각화 렌더러 시험 전량 119 passed / 0 failed**(원천 마운트 없이는 **111 / 8 failed**
> 이고 그 8 은 fail-closed 라 옳다) — **그 8 이 실데이터 4종 렌더 완주이고, 4종 전건 green 이다**
> **ⓑ 「가공됨」 표식의 그래프 노드 구분 = 「자리는 있고 표식이 없다」**(값은 계약·DB·화면 `data-origin`
> 까지 세 값 그대로 흐르나 화면은 `ai` 만 구분한다). **만들지 않았다 — 정본이 문구를 주지 않고 표시 대상이 0 건이다.**
> **실측 = `pipeline-worker` 188 passed / 0 failed / 0 skipped**(신설 11 · 기점 177) ·
> **`viz-render` 119 passed / 0 failed** · **게이트 `all -j 2` green 27 / red 2 — 기점과 동일하고 이번 변경이 만든 red 는 0 건이다.**
> red 둘은 전부 적용 DB 부재이고 red 가 옳다(`schema-diff` · `autometa-loss`).
> **범위 밖 = staging 배포(운영 접촉) · 목업 대비 화면 검증 · `core-api`·`frontend`·`ai-service` 재측정 ·
