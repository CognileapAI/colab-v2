## 2. 멈춤 규칙 (사람이 없는 동안 미리 못 박는다)

1. **게이트 red 는 우회하지 않는다.** red 면 그 WU 를 🟧 로 남기고 다음으로 넘어간다. 검사 대상을 줄여 green 을 만드는 것은 금지다 (`CLAUDE.md §4`)
2. **정본이 값을 주지 않는 자리는 만들어 채우지 않는다.** `[정본 무근거]` 로 남기고 보고한다 (`§9-㊴-②`)
3. **경계를 넘어야 하면 멈추고 기록한다** — Port 추가 / 도메인 재분할 / 기획 확인 중 어느 것인지 (`CLAUDE.md §4`)
4. **`contracts/` 는 동결이다.** 계약을 고쳐야 green 이 되는 상황은 **보고 대상**이지 작업이 아니다
5. **AWS 는 건드리지 않는다.** staging 까지가 자율선이다 (`㊵`)
6. 커밋은 메인 세션이 WU 단위로 한다 — 레인 에이전트는 커밋하지 않는다(같은 작업트리 병렬 충돌 회피)
7. `03-HANDOFF.md` · `PLAN-SoT.md` 는 **메인 세션만** 쓴다. 레인은 자기 `sessions/`·`reports/` 문서에 적는다
