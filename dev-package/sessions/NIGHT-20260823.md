## 2. 멈춤 규칙 (사람이 없는 동안 미리 못 박는다)

1. **게이트 red 는 우회하지 않는다.** red 면 그 WU 를 🟧 로 남기고 다음으로 넘어간다. 검사 대상을 줄여 green 을 만드는 것은 금지다 (`CLAUDE.md §4`)
2. **정본이 값을 주지 않는 자리는 만들어 채우지 않는다.** `[정본 무근거]` 로 남기고 보고한다 (`§9-㊴-②`)
3. **경계를 넘어야 하면 멈추고 기록한다** — Port 추가 / 도메인 재분할 / 기획 확인 중 어느 것인지 (`CLAUDE.md §4`)
4. **`contracts/` 는 동결이다.** 계약을 고쳐야 green 이 되는 상황은 **보고 대상**이지 작업이 아니다
5. **AWS 는 건드리지 않는다.** staging 까지가 자율선이다 (`㊵`)
6. 커밋은 메인 세션이 WU 단위로 한다 — 레인 에이전트는 커밋하지 않는다(같은 작업트리 병렬 충돌 회피)
7. `03-HANDOFF.md` · `PLAN-SoT.md` 는 **메인 세션만** 쓴다. 레인은 자기 `sessions/`·`reports/` 문서에 적는다

| 항목 | 확정 | 근거 |
|---|---|---|
| 라우트 | fe-core.yaml **34개 전부** 등록 | 계약 동결분. op 수는 34 다 (27 이라 적은 중간 보고가 있었으나 yaml 발췌 절단이었다) |
| 실질의 | **5개만** — `getCurrentAccount` `getLab` `listDatasets` `listDatasetFiles` `createProject` | 이 5개가 음성 4종(읽기·자식·미스코프·쓰기 WITH CHECK)을 HTTP 층에서도 덮는다. 더 붙이면 P1 을 앞당겨 먹는다 |
| 나머지 29개 | **501** + `ErrorEnvelope.code` 두 종 — `NOT_IMPLEMENTED_NO_STORE`(저장처 자체가 없다: access-request 4 · verification-request 2 · downloadDataset) / `NOT_IMPLEMENTED_P1`(로직 미착수) | "저장처 없는 7건만 501" 로 하면 **나머지 27건이 200 으로 거짓말**한다. P1 이 하나 구현할 때마다 501 목록이 줄어드는 것이 진척 계측이 된다 |
| 404 | **쓰지 않는다** | `§9-㊱` 이 404 를 「경계 밖」으로 못 박았다. 미구현에 404 를 쓰면 거짓말이다 |
| 계약 수정 | **없다** | 501 은 계약이 아니라 **배포 상태**다. 계약에 박으면 P6 이 구현한 뒤 지울 때 oasdiff 가 breaking 을 낸다. `contract-lint` 는 yaml 만 보므로 충돌하지 않는다 |
| 스코프 커널 | 트랜잭션 스코프 **`SET LOCAL`** + 요청 경계 commit/rollback | 풀 커넥션에 비-LOCAL `SET` 을 쓰면 다음 요청으로 lab_id 가 샌다 |
| 앱 DB 롤 | **NOBYPASSRLS · 비소유자** | 앱 롤이 superuser/BYPASSRLS 면 FORCE RLS 가 무력이고 음성 테스트가 **거짓 green** 이 된다 |
| 인증 | 계약이 이미 답했다 — `sessionSubject` bearer, 「개발자가 계정을 심어 제공한다」(P-17), 실제 수단은 P1 | `labId` 를 요청 파라미터로 받지 않는다. 헤더로 lab_id 를 주입하는 임시 경로를 만들지 않는다 |
| 정규 ID 코드측 | `colab_core` 의 `Ulid` 타입을 여기서 만든다 | DB DOMAIN 만 있고 파이썬 측이 없다 (`산출물 #3` 의 코드 쪽) |
| 스택 | Python 3.12 + FastAPI + SQLAlchemy 2.x | `PLAN-SoT §9-㊳` |
