## 1. 결함 — 실물로 확인한 선택 로직

`infra/staging/restore/preflight.sh:27-31`(수정 전 · 축자):

```bash
FAILED=0; SKIPPED=0
pick() { # $1=글로브 접두  $2=확장자
  if [ -n "$STAMP" ]; then ls -1 "$1-$STAMP$2" 2>/dev/null | head -1
  else ls -1t "$1"-*"$2" 2>/dev/null | head -1; fi
}
```

P2 가 이 `pick()` 을 **산출물마다 따로** 부른다(`:39`·`:43`) — 원장 프로파일 둘과 볼륨 둘이 **각각 독립으로 「최신」**이다.
그 다음 P5-b(`:97`)가 볼륨의 `.pair` 를 **그렇게 따로 고른 `ART[platform]`** 과 대조한다.

```bash
WANT="$(basename "${ART[platform]:-}")"
if [ "$(cat "$PF")" = "$WANT" ]; then pass ... else fail "P5-b 볼륨 $V 의 짝(...) ≠ 되돌릴 원장($WANT)"; fi
```

- **터진 조건** — 원장 전용 백업이 볼륨보다 뒤에 뜬 회차가 실제로 있었다: 2026-08-29T10:08 배포전 백업
  (`platform-20260829T100801.sql.gz` · `ai-20260829T100801.sql.gz` 만 있고 볼륨 없음).
  최신 원장 = `…T100801`, 최신 볼륨 = `…T033005`/`…T033040` ⟹ 짝 불일치 **2건**.
- **`--stamp` 가 우회로가 아니었다** — `backup-full.sh` 가 **볼륨마다 다른 스탬프**를 찍는다
  (실측 `vol-uploads-…T033005` vs `vol-previews-…T033040` · **35초 차**). 네 산출물을 한꺼번에 옳게 고르는 스탬프가 없다.
- ⟹ **입력을 다 줘도 사전조건이 통과할 수 없는 상태.** 이것이 P9(사고 원인) 같은 「값이 없어서 못 통과」와 성질이 다르다.
- **회차 부재는 조용했다** — 수정 전 P5-b 는 `ART[vol-$V]` 가 비면 `|| continue` 로 **아무 줄도 안 찍고** 넘어갔다.
  실측 픽스처(볼륨 아카이브 0건)에서 P5-b 구획이 **완전히 비어 있다.** green-by-skip 모양이 이미 거기 있었다.

## 2. 고침 — 회차 이름으로 한 벌을 고른다 (Ted 판정)

**회차의 이름 = 그 회차의 platform 원장 덤프 파일명.** 볼륨 아카이브는 이미 `.pair` 에 그 이름을 적고 있다
(`backup-full.sh:40-46`). 없던 것은 값이 아니라 **그 값으로 고르는 기구**였다. **백업이 뜨는 방식은 바꾸지 않았다.**

`infra/staging/backup/volume-lib.sh` 에 회차 절 신설:

| 함수 | 하는 일 |
|---|---|
| `backup_rounds <보관처>` | 회차 이름을 **새것부터** 나열 (platform 덤프 basename) |
| `round_stamp <회차이름>` | `platform-20260829T033005.sql.gz` → `20260829T033005` |
| `round_volume_archive <보관처> <볼륨> <회차>` | `.pair` 가 그 회차인 볼륨 아카이브. 없으면 비출력 ＋ 1 |
| `round_profile_dump <보관처> <프로파일> <회차>` | platform 은 회차 그 자체 · 그 밖은 회차 스탬프에 **가장 가까운** 것(30분 창 · P5 와 같은 창) |
| `volume_pairing <볼륨>` | **세 상태** 선언. `volume_oracle`·`volume_min_files` 와 같은 모양 |
| `select_backup_round <보관처> [스탬프]` | 회차 **하나**. 성립 = platform 덤프가 있고 `round` 선언 볼륨 **전부**의 아카이브가 그 회차에 있다 |

기본 선언(`load_volume_config`) — `COLAB_VOLBACKUP_PAIRING_uploads=round` · `COLAB_VOLBACKUP_PAIRING_previews=round`.
**값은 레포 안 코드가 쥔다** — 홈 env 파일에 의존시키면 `〈170〉-㉮`(설정 부재로 조용히 SKIP)가 재발한다.

### 2.1 세 상태 (green-by-skip 방지)

| 상태 | 값 | preflight 거동 |
|---|---|---|
| 짝이 맞는 회차를 찾음 | `PAIRING_<볼륨>=round` ＋ 아카이브 있음 | **검사한다** — P2 `회차 = …` · P5-b 짝 대조 |
| 명시 면제 | `PAIRING_<볼륨>=none` | **통과하되 `SKIP` 줄 ＋ 요약줄 건수를 드러낸다** (P2·P3·P5-b 각각) |
| 선언 없음 / 회차 없음 | 빈 값·미설정 · 성립 회차 0 | **RED.** 「모르는 것을 최신으로 읽지 않는다」 |

`--stamp` 의 뜻이 바뀌었다 — **산출물 스탬프**가 아니라 **회차 지목**이다. 볼륨 스탬프가 35초 어긋나도 잡힌다.

### 2.2 「대상 0건」을 통과로 세지 않게 한 자리 넷

- `P3` 원장 — `|| continue` → `fail "검사할 산출물을 고르지 못했다(P2 참조)"`
- `P3` 볼륨 — 같음 ＋ 명시 면제는 `skip_ack`
- `P4` — `[ "${#ART[@]}" -gt 0 ] || fail "대조할 산출물이 0건이다"`
- `P5-b` — 회차가 없으면 `fail "회차가 없어 짝을 대조하지 못했다 — 대상 0 건을 통과로 세지 않는다"`
- 요약줄 — **RED 줄에도 승인된 SKIP 건수를 찍는다**(종전엔 GREEN 줄에만 있었다)
