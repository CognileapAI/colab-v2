# X-6 형제 2건 — 되돌리기·리허설 쪽의 같은 무늬 (2026-08-29)

직전 회차(`X6-ALIAS.md`)가 **찾아 놓고 완료 정의 밖이라 남긴 둘**을 닫는다.
경계 = 배포·롤백·파이프라인 **미실행** · 운영 스택 무접촉(읽기 전용 조회도 이번엔 하지 않았다) ·
이미지 태그 무변경 · `gates/**` 읽기만 · 대장 문서 무접촉.

## 1. 형제① — `rollback.sh` 가 되돌린 뒤 `:i2` 를 재부착하지 않았다

`deploy.sh` ⑫ 만 `:i2` 를 옮긴다. 그래서 되돌린 뒤에도 `:i2` 는 **방금 걷어낸(새) 이미지**를
가리킨 채 남고, 복원 리허설은 그 이름으로 이미지를 찾으므로 **되돌린 뒤 리허설하면
되돌리기 전 이미지를 리허설한다.** 배포 쪽에서 막은 것과 같은 무늬가 되돌리기 쪽에 남아 있었다.

**고친 방법 = 직전 회차와 같다.** 새 함수를 만들지 않고 **`alias_reattach()` 를 그대로 재사용**한다
(두 벌을 두면 한쪽만 고쳐지는 날이 온다). `rollback.sh` 의 판정 뒤·**원장 green 앞**에 세 상태를 둔다.

- 요구되면 **검사한다** — 붙인 뒤 `docker image inspect -f '{{.Id}}'` 로 `:i2` 와 `:$TAG` 대조
- **명시 면제** — `--skip-alias-reattach` 일 때만 넘어가고 원장에 `별칭재부착SKIP(6종)` 로 건수가 남는다
- **아무 말도 없으면 실패한다** — 원장 red · `mark_failed` · `exit 70`
- `--to-placeholder` 는 재부착 대상 이미지 자체가 없다. **붙일 것이 없는 것**이지 검사를 건너뛴 것이
  아니며, 그 사실을 원장 비고(`별칭재부착없음(대상이미지없음)`)에 남긴다.

## 2. 형제② — 복원 리허설이 `:i2` 의 신선도를 재지 않았다

`compose.throwaway.yml` 은 6종을 전부 `colab-v2/*:i2` 로 띄운다. 그 이름이 **언제 것인지**를
아무도 묻지 않았다 — 별칭이 옛 이미지를 가리켜도 리허설은 그대로 서고 통과를 낸다.

### 「신선도」를 무엇과 무엇의 대조로 정의했나 (이름이 아니라 코드를 열어 정했다)

> **신선도 = 「`:i2` 의 이미지 ID」 = 「지금 서빙 중인 릴리스 태그의 이미지 ID」.**

- **왜 이미지 ID 인가** — 태그는 옮겨 붙고 생성 시각은 재빌드로 흔들린다. 직전 회차의 사후 대조
  (`pipeline/lib.sh:alias_reattach`)가 이미 ID 를 잣대로 삼았다. **같은 잣대를 쓴다**(`alias_id`).
- **왜 「서빙 중인 태그」가 기준인가** — 리허설이 재현해야 하는 것은 **지금 서빙되는 것**이다.
  근거 = `compose.i2.yml:149`(및 229·270·301·337·352) 이 6종을 전부
  `colab-v2/<단위>:${COLAB_RELEASE_TAG}` 한 변수로 띄운다 → 살아 있는 `colab_v2_staging_core_api` 의
  `.Config.Image` 태그가 곧 이번 릴리스 태그이고 6종에 공통이다.
- **왜 원장이 아닌가** — 원장 마지막 줄은 **마지막으로 적은 값**이지 최근에 잰 값이 아니다
  (`CLAUDE.md §0`). 실물은 컨테이너가 물고 있는 이미지 참조다. `rollback.sh` 도 현재 태그(`CUR`)를
  같은 자리에서 읽는다 — 잣대를 갈라 두지 않는다.
- **별칭이 서빙 중이면 「모른다」** — `.Config.Image` 태그가 `i2`·`prev` 면 신원을 답할 수 없으므로
  실패다. 기본값으로 떨어지지 않는다.

새 함수 둘을 `pipeline/lib.sh` 에 세웠다 — `serving_release_tag()`(읽기 전용 `docker inspect` 1회) ·
`alias_fresh()`(붙이지 않고 6종 ID 대조). `restore/throwaway-stack.sh` 는 **기동 전 0단**에서 세 상태로 판정한다.

- 잴 수 있으면 **잰다** / `--skip-alias-freshness` 로 **명시** 면제하면 `skip_ack` 로 건수가 요약줄에 남는다 /
  못 재거나(서빙 태그 미상) 불일치면 **시작하지 않는다.**
- ⚠ 이 자리에서 `:i2` 의 **부재는 red 다.** 재부착 자리(⑫)와 달리 여기는 붙이는 자리가 아니라 쓰는 자리다.
