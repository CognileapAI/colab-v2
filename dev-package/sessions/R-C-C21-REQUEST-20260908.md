## 2. 왜 ㉯ 인가 — 등급 사유 (X2 §5-㉯ 축자 적용)

- **op 신설** — X2 §5-㉯ 「op 신설 — 501 표·op 총계가 움직인다」. ⑴ 2 op ＋ ⑷ 2 op = **4 op 신설**(fe-core 66 → 69 · core-viz 6 → 7 · `services/core-api/tests/test_route_table.py:111` 의 `== 66` 이 움직인다).
- **설계 판단이 섞였다** — §6 에 기각 대안 3건. X2 §5-㉯ 「기각한 대안이 하나라도 있으면 여기다」.
- **소비자 ≥ 1 표면에 붙는다** — 첨가 대상 스키마의 소비자 88줄(§3 ㉱-3). 첨가는 형태 변경이 아니지만 ㉮ 조건 3(소비자 0)은 미충족이다.
- ㉮ 5조건 대조 = 조건 1 `contract-breaking` ERR 0 **충족 전망** · 조건 2 마이그레이션 0 **충족**(§4) · 조건 3 소비자 0 **미충족** · 조건 4 설계 판단 0 **미충족** · 조건 5 정본 무개정 **충족**. ⟹ **둘 미충족 → ㉯**.
- 파괴 여부와 등급을 분리해 적는다 — **파괴 = 아니오(전망) · 등급 = ㉯.** `contract-breaking` 이 집행 뒤 ERR ≥1 을 내면 멈추고 보고한다(spec 우려 3).
