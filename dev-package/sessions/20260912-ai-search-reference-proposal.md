## 확인된 자료와 검색 상황 제안

### 1. 식생의 기간·지역·가공 단계에 맞는 자료 선택

- 근거: `01.level-data/02.vegetation/02.vegetation/#readme/#processing_description_NDVI.docx`.
- 2023년 5월 GK-2A 일별 원자료 31파일, 월평균 GeoTIFF 1파일, 일별 모델 예측 31파일이 있다.
- 월평균은 경기 남부~충청권 추출·WGS84 변환·품질 처리·2km→100m 균등 분할 산출이다.
- 보조입력·검증 폴더에는 DEM, Aspect, LULC_2023, HLS_S30_NDVI_mean_202305가 있다.
- 대표 상황: 지역 식생 연구자가 목적에 맞는 월평균 자료를 찾고 원자료·모델 예측과 구분한다.
- 질문: “2023년 5월 경기 남부와 충청권의 식생 상태를 살펴볼 수 있는 월평균 위성 자료 찾아줘.”
- 주 정답: `Lv.1/GK2A_NDVI_mean_202305.tif` — 기존 SEARCH-GOLD-001 유지.
- 추가 후보 질문: “2023년 5월 일별 식생지수 예측 결과 찾아줘.” → `Lv.2/Prediction_202305*.npy`.
- 주의: 월평균 100m 격자를 100m 직접 관측으로, 예측장을 관측으로 설명하지 않는다.

### 2. 강우 추정의 입력·검증·예측 결과 찾기

- 근거: `01.level-data/01.precipitation/01.precipitation/#readme/#processing_description_Precipitation.docx`.
- HSR 반사도와 RN15 15분 누적 강수 원자료가 각각 10개 있다. Lv.1은 WGS84 변환·대상지 crop 표본, Lv.2는 U-Net 계열 강우 추정 예측장이다.
- 대표 상황: 강우 추정 연구자가 모델에 넣은 반사도, 비교할 강수 자료, 예측 결과를 구분해 찾는다.
- 질문 후보: “레이더 반사도로 만든 강우 추정 결과와 검증에 쓴 강수 자료 찾아줘.”
- 기대 후보: `Lv.2/pred_sample.npy`, `Lv.1/rn15_sample.npy`; 입력은 `Lv.1/hsr_sample.npy`.
- 별도 단일 검색 질문 후보: “WGS84로 맞추고 연구대상지만 자른 15분 누적 강수 표본 찾아줘.” → `Lv.1/rn15_sample.npy`.
- 주의: crop의 지명을 임의 지정하지 않는다. 예측을 관측으로, RN15를 레이더 직접 관측으로 설명하지 않는다. 샘플 축을 연속 시계열로 단정하지 않는다.

### 3. 장기간 시군구 가뭄 자료 찾기

- 근거: `01.level-data/03.drought-20260518T233626Z-3-001/03.drought/#readme/[Data Info]SPI-4weeks.docx` 및 SPEI 설명서.
- 자료: `Lv.1/SPI_4weeks_sig_wide.gpkg`, `Lv.1/SPEI_4weeks_sig_wide.gpkg`.
- 설명서는 대한민국 시군구, 주 1회, 2000~2025년, 관측소 기반 시군구 대표값을 설명한다.
- SQL 확인: 각 250행, 날짜형 지수 열 1356개, 첫 날짜 20000101·마지막 20251220. 설명서의 2025-12-31 종료 문구를 실제 마지막 관측일로 쓰지 않는다.
- 대표 상황: 가뭄 연구자가 시군구별 장기 변화를 비교할 수 있는 지수 자료를 찾는다.
- 질문 후보: “2000년부터 2025년까지 대한민국 시군구의 4주 가뭄지수를 주간으로 비교할 자료 찾아줘.”
- 기대 후보: 위 SPI·SPEI 두 파일. 서로 다른 지표로 구분해서 표시한다.
- 주의: 4주 지수와 주간 갱신을 구분한다. 시군구 전역의 모든 지점 또는 1km 격자를 직접 관측했다고 설명하지 않는다.

### 4. 변수·포맷에 맞는 자료 선택 — 확장 후보

- 근거: `02.File-format` 각 하위 폴더의 `01.Code` 처리 코드와 실제 파일.
- 예: GK-2A LST(지표면온도), HLS B02·B03·B04 RGB 구성 밴드, MODIS LAI·FPAR, ERA5 복사 변수 예제가 있다.
- 질문 후보: “RGB 영상을 만들 수 있게 청색·녹색·적색 밴드가 있는 위성 자료 찾아줘.” → HLS 밴드 자료.
- 코드의 변수 설명과 산출 파일명이 다를 수 있어 바이너리 메타데이터와 대조한 뒤 정답을 확정한다.

### 5. 가공 방법으로 자료 찾기 — 확장 후보

- 근거: `03_KWRA_conference-20260517T141236Z-3-001/3_KWRA_conference/3_해상도변경/README.md`.
- README는 2024-06-15~24 GK-2A NDVI 2km 자료에서 충청권을 추출해 1km로 바꾸는 Nearest·Bilinear·IDW·Regression Kriging을 설명한다.
- 질문 후보: “2024년 6월 충청권 식생 자료 중 고도 정보를 반영해 1km로 가공한 자료 찾아줘.”
- 기대 후보: README가 DEM을 보조 변수로 설명하는 Regression Kriging 결과. `cokriging` 폴더 이름만으로 방법을 재정의하지 않는다.
- 주의: 재격자화가 새 직접 관측을 만들었다고 설명하지 않는다. 가공 방법별 성능 우열은 이번에 검증하지 않았다.
- 발표 사진·자료 소개 그림을 측정 데이터와 혼동하지 않는다. 이 묶음은 기존 제품 적재 범위 밖이라 먼저 등록 범위를 결정한다.

## intent 제안 — 아직 사용자 확정 전

- 사용자 가설: 공유받은 기상·환경·위성 자료에서 연구에 필요한 자료를 선택하는 연구자. 자료의 이름·폴더 구조·전문 용어를 모두 알고 있다고 가정하지 않는다.
- 문제 가설: 원자료·전처리·모델 결과·보조입력이 섞여 있고, 기간·지역·변수·가공 설명이 파일명만으로 드러나지 않아 후보 선택과 의미 확인이 어렵다.
- 원하는 변화 제안: 연구자가 목적과 조건을 자연어로 표현하면 해당 데이터셋을 찾고, 추천 이유·자료의 역할·확인 가능한 한계를 이해한 뒤 상세 화면으로 이동할 수 있다.
- 첫 범위 권고: 강수·식생·가뭄 자료를 중심으로 조건·의미·가공 단계에 맞는 자료 찾기. 이미 합의한 식생 질문을 첫 기준으로 유지한다.
- 후속 범위 후보: 포맷·변수 선택, 가공 방법별 자료 탐색. 연구 성능 보장·수치 분석 실행·새 가공물 생성·채팅형 UI는 이 제안에 포함하지 않는다.
- 기대 답변은 이후 보강한다. 이번 질문 후보를 사용자 승인 없이 기존 골든셋의 확정 문항으로 추가하지 않는다.
