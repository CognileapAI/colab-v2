# WU-P0 — 공통 기반 (에픽 0단계)

> 화면이 없는 단계다. 그러나 **여기서 저장 형태를 틀리면 뒤 단계가 전부 소급된다** — 정본 E-00이 직접 그렇게 적어뒀다.
> 개발자가 가장 먼저 읽는 문서가 E-00이고, 이 WU가 그것을 코드로 옮긴다.

---

## 1. 진입조건 (충족 확인 후 시작)

| 조건 | 확인 방법 |
|---|---|
| **G1** E-00 전달 패키지가 DataModel v1.8 · Policy v1.4를 반영 | 패키지 HTML 내용이 최신 md와 일치 |
| **G5** DataModel v1.8 ↔ 설계 스키마 대조 완료 | diff 표 존재, 소급 항목 0 |
| **D3** 경계 강제 장치 동작 | 게이트 self-test 전부 fail-closed 증명 |
| (권장) **G3** E-01 권한 원칙 확정 | 원칙 문서 존재 — 없으면 권한 게이트 틀을 임의로 붙이게 된다 |
| (권장) **G4** 권한 편집 화면 단계 배정 | 권한 값의 원천이므로 0~1단계여야 한다 |

하나라도 미충족이면 **구현하지 말고 보고한다.**

## 2. 범위

### 건드리는 것

| 도메인 | 이 WU에서 만드는 것 |
|---|---|
| **D1** Identity & Lab | 연구실(테넌트 루트) — 이름·소속 대학·학부/학과·책임교수·연구 분야·한 줄 소개·**데이터 공개 범위(기본값)**. 계정. 정규 ID 타입 |
| **D2** Access & Policy | 역할 2값 · 권한 스위치 4종의 **저장 자리와 게이트 틀**. 규칙 본체는 P6 |
| **D3** Catalog | 데이터셋 · **파일(본체 N + 기준 격자 0~1)** · 자동 추출 메타 · 사람 기입 메타 · 가공 단계(Lv) |
| **D4** Lineage | 계보 관계(**부모 여럿**, 주/보조 입력) · 가공 방식은 **관계에 부착** · 계보 상태 4값은 **파생 계산**(저장 아님) |
| **D6** Project | 프로젝트 · **데이터셋 N:N 연결** + 활용 의미 문장 |
| 공통 | 활동 기록(바꾼 일만) · 다운로드 이력 · **레코드 시점 3종**(올린 날 · 마지막 수정 · 계보 확정일) |
| FE 셸 | GNB(**첫 탭 = `연구실`**) · 페이지 이동 · 권한 게이트 틀 |

### 비워 두는 자리 3곳 (정본이 지정)

화면에 자리만 만들고 내용은 뒤 단계가 채운다 — Verified 배지 · 잠금 표시 · 할 일 함.

### 건드리지 않는 것

- 화면 로직 일체 (P1 이후)
- AI 관련 (K 트랙). **D9·D10 테이블을 이 마이그레이션 체인에 넣지 않는다**
- 승인 규칙 본체 (P6), 시각화 (P3), 검색 (P4)

## 3. 반드시 지킬 저장 형태 (정본 확정분)

| 항목 | 확정 내용 | 출처 |
|---|---|---|
| 데이터셋 : 파일 | **1 : N** (본체 N + 기준 격자 0~1) | DataModel v1.8 (08-18) |
| 계보 | 부모 **여럿** 가능. 가공 방식은 **관계에 붙는다**. **사람이 확인한 것만 저장** | DataModel · E-04 |
| 파일 | **파일에는 계보가 없다** — 계보는 데이터셋 단위 | DataModel v1.8 |
| 소유자 / 올린 사람 | **분리.** 소유자 NOT NULL, 올린 사람 불변 | DataModel |
| Lv | **자동 계산** — 주입력 부모의 최대 + 1. 원자료 Lv0 | E-00 |
| 프로젝트 연결 | **N:N 확정.** 같은 데이터가 논문 두 편에 쓰인다 | E-00 |
| 다시 올리기(버전) | **자리를 만들지 않는다.** 고친 데이터는 새 데이터셋으로 올려 계보로 잇는다 | 08-07 인터뷰 |
| 활동 기록 | **바꾼 일만** 서버에 쌓는다. **열람은 서버에 남기지 않는다**(브라우저에만) | 08-07 인터뷰 |
| 다운로드 이력 | 쌓되 1차 화면에 노출 안 함 | 08-07 인터뷰 |
| 연구실 경계 | **모든 조회의 기본 필터** | E-00 |
| 접근 상태 | 열림/잠김 + 허용자 목록. 데이터셋 값이 연구실 기본값을 **이긴다** | E-00 · E-06 |
| 삭제 | **묘비 방식** — 파일만 삭제, 메타·계보·연결 유지 | E-03 (08-12) |

> 이 표와 정본이 어긋나면 **정본이 이긴다.** 어긋남을 발견하면 구현 전에 보고한다.

## 6. 함정 (PoC·v1에서 같은 자리에서 터진 것)

| 함정 | 어떻게 터졌나 | 이번에 막는 법 |
|---|---|---|
| **God Object** | PoC Dataset이 112 컬럼으로 자람 | 데이터셋·파일·변수·시간·계보를 처음부터 분리. 컬럼이 늘면 도메인 경계를 의심 |
| **ID 타입 드리프트** | `users.id`를 String(20/30/36)으로 제각각 선언 | shared kernel 1곳에서만 정의, 전 계층이 거기서 생성 |
| **RLS green-by-skip** | CI가 DB 없이 돌아 RLS 테스트를 조용히 건너뜀 | DB 미설정 시 **fail-loud**. skip을 green으로 세지 않는다 |
| **스코프 누락** | 한 줄 누락으로 타 연구실 데이터 노출 | 스코프 자동 주입 + un-scoped 쿼리 lint + RLS 이중 방어 |
| **마이그레이션 다중 head** | 병렬 작업이 head를 갈라놓음 | single-head 게이트, 마이그레이션은 직렬 정리 |
| **AI 테이블 혼입** | — (v2에서 새로 생길 수 있는 함정) | **D9·D10은 별도 스키마·별도 마이그레이션 head.** 여기 섞으면 온톨로지 한 줄 추가가 플랫폼 마이그레이션을 기다린다 |
