### 1.2 「PNG + BBOX 데모」가 증명한 것과 증명하지 않은 것 `[EVIDENCE]`

**증명한 것 (강하다).**
- **지오레퍼런싱은 400 B 로 끝난다.** `…-01 §7장` — 위경도 배열 2장 53 MB ↔ bbox JSON 약 400 B = **13만 배**. 브라우저 파싱 부담이 사라진다.
- **`.pgw` 월드 파일이 함께 나와** GIS 도구가 PNG 를 그대로 연다(실물 4개, 각 96~98 B).
- **곡선 격자(HSR)조차 warp 하는 순간에만 위경도 배열이 필요하고, 그 뒤로는 bbox 만 쓴다.**
- **썸네일은 정말 싸다.** 128 px 생성 **25–207 ms · 2–7 KB**, 데이터셋 **229장 전량이 4워커 5.2 s · 2.6 MB**(PNG 는 6.0 MB).

**증명하지 않은 것.**
- **「가공하지 않고도 된다」를 증명하지 않는다.** 6장 표의 생성 시간에는 **읽기가 포함**되고, 결측 판정·2–98 % 스트레치·다운샘플·컬러맵 LUT 가 전부 들어 있다.
- **업로드 시점에 되는지를 증명하지 않는다** — §1.3-㉢ 참조(공통 스케일은 데이터셋 단위 산출물이다).
- **콜드 캐시 `[미측정]`**, **GB 급 파일 `[미측정]`**(견본 최대는 tif 24.9 MB), **값 조회 경로 `[미측정]`**(「PNG 는 픽셀 RGB 라 원값이 남지 않는다」 — 보고서 자신의 문장).

### 1.3 `hsr_bad_*` vs `hsr_good_*` 이 인코딩한 실패 모드 `[EVIDENCE]`

실물 6장(`hsr_bad_fillcut.png` · `hsr_bad_stride.png` · `hsr_bad_perframe_{0,1,2}.png` ↔ `hsr_detail_1024.png` · `hsr_detail_blockavg.png` · `hsr_good_common_{0,1,2}.png`)이 **세 가지 서로 다른 실패**를 나란히 세워 놨다.

### 질문 1 — 「파일의 내용을 읽어 값을 만들어 내는가?(헤더·좌표·격자·픽셀)」

**답 = 예. 여기서 멈춘다. → 밖(㉠).** 근거는 셋이고 전부 실측이다.

1. **픽셀을 읽는다.** 썸네일조차 전량 디코딩을 거친다 — `…-01 §2장` 이 명시: **「부분 읽기는 tif 에서 성립한다 (…) bin · nc · hdf 는 전량 디코딩을 거친다」.**
2. **값을 만들어 낸다.** 2–98 % 스트레치 범위 · 결측 3값 판정 · 블록평균 · 컬러맵 LUT 256엔트리. 실측 스케일 범위가 산출물로 남는다(HSR `−27,768 … 4,611`, nc `287.3 … 303.7 K`, tif `21 … 10,432`, hdf `0 … 42.8 LAI`).
3. **좌표를 만들어 낸다.** bbox 4값은 CRS 를 세우고 warp 한 결과다. `S1-PLAN §1.3-㉠` 의 열거에 **「좌표계 변환」이 문자 그대로 들어 있다.**

> **매직바이트 예외에 기대지 못한다.** `§1.4` 의 예외 문장은 **「파일의 머리 몇 바이트를 보고 종류를 말하는 것이지 값을 만들어 내지 않는다」** 로 한정돼 있다.
> 썸네일은 **머리 몇 바이트가 아니라 배열 전체**를 읽고, **종류가 아니라 값**을 낸다.
> **`〈71〉-㉮` 가 「초판이 남겨 뒀던 격자 축 판별 예외」조차 지웠다** — 이 규칙에는 지금 예외가 **0 개**다.

### 질문 2 — 「파일 데이터에서 유도한 렌더를 화면에 내는가?」

**답 = 예 (도달하지 않지만, 도달해도 예).** 지도·타일·팔레트가 전부 해당한다. `§1.4` 규칙 2 의 좁힘 근거(「검색 결과의 막대는 파일을 안 연다」)는 여기에 안 걸린다 — **미리보기는 파일을 연다.**

### 질문 3 — 「이 값이 맞는지 되짚는 화면·경로인가?」

**「optional 위경도 입력요청」이 여기 걸린다. → 밖(㉢).**
`S1-PLAN §1.3-㉢` 의 정의 = **「기준 격자 파일 개념 전체(후주입·교체·삭제 포함) · 렌더 가능 판정(`renderable`) · 좌표 정합 확인 화면」.**
Ted 의 「기준(위경도데이터) 입력요청」은 **기준 격자 파일 후주입 그 자체**다.

> **stage 2 착수 시 설계에 드는 시간이 사실상 0 이 된다.** 지금 급히 넣는 것보다 이 편이 크다.
>
> **⚠ `§1.0` 의 브랜치 갈라짐은 미리보기 판정과 무관하게 지금 닫아야 한다** — main 의 `DATA-PIPELINE-MEASUREMENT.md`(538행)를 이 브랜치로 들여오지 않으면
