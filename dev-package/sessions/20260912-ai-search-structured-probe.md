# AI 검색 — 조건 결합 후보 실험 (2026-09-12)

사용자 승인 “그래 그렇게해”: 제품 변경 없이 표현 정규화·파일명 주제 오인·조건 결합을 실험한다. LLM 호출 0건.

## 방법과 범위

- 입력은 기존 dev 9묶음 snapshot의 이름·설명·파일명·직접 부모 관계다. 새 메타데이터 수작업 주입이나 DB 변경은 없다.
- 파일명이 정확히 있고 원천/직접 입력을 요청하면 실제 부모 간선을 따라간다. 확장자를 주제 필터로 사용하지 않는다.
- 주제·U-Net 표기·예측/보조/검증 역할을 결합한다. 예측과 검증을 함께 요청하면 역할별 후보를 합친다.
- 월평균·좌표변환은 설명, 숫자로 표현한 년월은 파일명으로 후보를 제한한다. 기간 전체 충족 검증이 아니다.
- 지역·관측 해상도·결측 보증·자료 주기·파일 제외 조건은 `unverified`로 남긴다. 출력 `ids`는 후보이며 완전 일치 판정이 아니다. 조건 해석기가 범용으로 완성됐다는 의미도 아니다.
- 현행 SQL 검색 전체25개와 달리 이 실험은 고정9개 안에서 직접 조회한다. 순위·응답시간·실서비스 권한·동일 검색엔진 개선율 비교에 사용하지 않는다.

추가6개는 후보 포함/빈 결과 검사 6통과다. 원문과 기대 키는 [추가 질문](../../eval/k4-search/structured-extra-cases.json)에 고정했다. 다른 조사자가 코드 작성 전에 독립 설계했으나 **구현자가 구현 전에 질문을 읽었으므로 blind holdout이 아니다**. 오월→5월 정규화, 일자 정확성, SPI 제외, 실제 파일 역할 설명, 모든 지역·주기 조건 충족을 이 결과로 주장할 수 없다. 추가6개의 의미 판정도 미실행이다.

추가 질문의 근거는 기존 [레퍼런스 조사](20260912-ai-search-reference-proposal.md) 및 [자료 대조](20260912-ai-search-data-readiness.md)다. N3 직접 부모는 VEG-LV1 주입력과 VEG-LV1-MODELIN 보조입력이며 VEG-LV0는 직접 부모가 아니다. P3 가뭄 실제 마지막 날짜 열은 20251220이다. P1의 100m는 2km 균등분할이다.

## 검증과 재현

- 실험 도구 테스트는 모듈 부재로 실패를 확인한 뒤 6개 통과했다. 기존 기준선 8개와 함께 최종 14개 통과했다.
- 결과: [structured-probe-01.json](../reports/stage3-ai-search-plan/structured-probe-01.json). 실행 코드·snapshot·질문 파일 SHA-256 포함, 출력 덮어쓰기 거부.
- 실행: `python3 eval/k4-search/structured_probe.py --output <새 결과 경로>`.
- 질문ID·정답ID를 검색 함수에 전달하지 않는다. 기대값은 실행 후 후보 포함 검사에서만 사용한다.
- `git diff --check` 통과. `structured-gate/gate-summary.json`의 work-item-consistency는 exit 0, green 1 / 판정 실패 0 / 준비 실패 0이다. 기존 파싱 제외 9건은 검사하지 않았으며 통과 근거에 포함하지 않는다.
- 독립 읽기 전용 검토에서 포함 검사와 의미 판정의 구분을 확인했다. 추가 한계: 여러 주제를 함께 요청하면 현재 AND 처리가 후보를 없애므로 복수 주제 질의는 미지원이다. 보고서 hash에는 시험 파일이 포함되지 않아 당시 시험 코드까지 결박하는 증거는 아니다. 다음 실험에서 보강한다.
