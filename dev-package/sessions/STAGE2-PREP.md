## 3. 재기동에서 반드시 지킬 것

- **이미지 재빌드를 빠뜨리지 않는다.** `〈153〉` 때 배선만 바꾸고 옛 이미지로 올렸더니
  **ai-service 만 healthy** 였고 그게 제일 나빴다 — **사전 DB 가 `None` 으로 조용히 비어** 온톨로지가
  통째로 사라진 채 **헬스 200** 을 냈다. **죽은 쪽은 바로 보이고 살아 있는 쪽이 속인다**
- `RESTART.md §2` 의 `COLAB_STAGING_*_DB_URL_FILE` **5키**가 없으면 `:?` 로 죽는다
- **`-f compose.i2.yml` 을 빼면 조용히 I2 이전으로 롤백된다.** 그 상태에서도 루트 헬스는 200 이다
- 회전 음성 확인은 **네트워크 경유로** 잰다 — pg 컨테이너 안 루프백은 `pg_hba` 가 `trust` 라
  **엉터리 비밀번호도 통과한다**

## 4. `admin` 계정 — 무엇이고 무엇이 아닌가

- 계정 `admin` · 연구실 `00000000000000000000HYMETS` · 계정 ID `000000000000000000HYMETSA1` · 역할 **`교수`**
- ⚠ **시스템 권한이 아니다.** 역할 enum 은 `교수`·`연구원` 둘뿐이고 `admin` 은 **일반 교수-역할 계정**이다.
  이 이름을 특수 취급하는 코드를 만들지 않는다
- ⚠ **비밀번호가 약하고 staging 은 외부에 열려 있다. prod 를 열기 전 회전이 필수다**
- 계정을 더 심으려면 — `ops/set-password.py` 로 `credentials.json` ＋ `d1_account`·`d2_member_role` **2행**.
  **자격 파일만 채우면 로그인은 되는데 권한이 0 이다**(스코프는 토큰이, 권한은 DB 역할이 정한다)
- 마운트가 읽기 전용이라 **호스트 파일 제자리 덮어쓰기(inode 유지) ＋ core-api 재기동**이다
