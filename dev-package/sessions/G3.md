## 2. 의도적으로 뺀 것 (P8·G4의 몫)

- **화면별 적용 지점 표** — 정본 자체가 `가. 원칙 / 나. 화면별 적용 지점 표`로 나누고 나. 부를 "E-07 완료 후"로 유보했다. WU 표의 **P8**이 그 자리다. 여기서 미리 쓰면 P2~P7에서 화면이 움직일 때마다 다시 써야 한다
- **잠긴 데이터의 화면별 노출 깊이 값** — E-01 정본이 명시적으로 자기 관할이 아니라고 선언(§4 말미, 변경 이력 v1.2). 값의 정본은 `Policy_승인_처리` §8
- **`연구실 설정 > 구성원·권한` 화면의 단계 배정** — **G4**
- **권한 판정의 코드 배치** (스코프 커널 · RLS 정책문 · Port) — **D3**. §9에 정본 무언급 구간임을 표시만 하고 결정하지 않았다

## 3. [Ted 판단 필요] 9건 (상세는 PERMISSION-PRINCIPLES.md §10)

① 접근 승인 회수(만료 전 강제 철회) 규칙 미결 — E-06 정본이 "회수 규칙 미결" 명시
② 거절 후 재요청 가능 여부가 `[가정]` — 횟수·쿨다운 없음
③ 행 단위 접근 잠금을 RLS로 강제할지 애플리케이션 판정으로 둘지 정본에 없음
④ 접근 상태 기본값이 `[가정] 열림` · 연구실 `데이터 공개 범위`의 값 집합 미정의
⑤ 한 계정의 다중 연구실 소속 여부 미정 (`연구실 전환기 ▾`는 있으나 근거 서술 없음, P1 미결)
⑥ 소유자 승계 경로 부재 — 자리만 있고 값을 바꿀 화면·API 없음
⑦ `연구실 설정` 위임자가 타인의 위임 스위치를 켤 수 있는지(권한 상승) 미정
⑧ 권한 변경 감사 기록 항목이 데이터 모델에 없음
⑨ 판본 명칭 정정 — E-01 정본은 **v1.3**. v1.4는 E-00 공통 기반 정책의 판본이다
