### 2.2 모듈 경계 — 교체 지점 (★ 이 설계의 핵심)

```
요청 ─ app/deps.py::current_subject ─→ AuthenticatorChain ─┬─ StaticTokenAuthenticator (주체 표 · P-17)
        (수단을 모른다. Subject 만 안다)                     └─ SignedSessionAuthenticator (서명 세션)

로그인 ─ app/routes/session.py ──────→ CredentialIssuer ───── PlantedCodeIssuer (접속 코드 → 세션)
        (수단을 모른다. 결과만 옮겨 적는다)
```

- **교체 지점 = `services/core-api/src/colab_core/kernel/authn.py` 의 `build()` 한 함수**
- 두 축을 가른다 — `Authenticator`(자격→주체, 매 요청) · `CredentialIssuer`(입력→세션, 로그인 op).
  섞으면 「판정만 바꾸고 싶다」와 「발급만 바꾸고 싶다」가 같은 코드를 건드린다
- **빈 사슬은 모두 거부한다** — 「검사할 것이 없으니 통과」를 만들지 않는다 (`CLAUDE.md §4`)
- FE 대칭 — 인증 세부는 `frontend/src/auth/` 안에만 있다. 다른 화면은 토큰을 읽지 않는다

### 2.3 세션 표현 · 수명 · 갱신

- ★ **무상태 HMAC 서명 토큰** — payload = `sub`·`lab`·`exp` **셋뿐**. `[정본 무근거]`
- **권한을 담지 않는다** — 권한은 언제나 `GET /me` 가 DB 에서 읽는다 (P-6·P-7).
  토큰에 담으면 값이 두 곳으로 갈라진다
- **세션 표 대안은 기각** — 표를 두면 마이그레이션이 붙고 이 회차가 중단 조건에 걸린다
- 수명 = **720 분**, `[정본 무근거]` → **운영 설정**(`COLAB_CORE_SESSION_TTL_MINUTES`)
- 갱신(슬라이딩 만료) = **두지 않는다.** `[정본 무근거]` 이고 없어도 화면이 성립한다
- 보관 위치 = FE `localStorage`. 정적 배포라 서버가 쿠키를 심을 자리가 없다.
  쿠키로 옮기려면 `frontend/src/auth/store.ts` 와 `api/client.ts` 미들웨어만 바뀐다

### 2.4 로그아웃

- `DELETE /sessions/current` → **204**. 화면이 토큰을 버린다
- ⚠ **만료 전 조기 회수는 불가능하다.** 무상태라 「이 토큰은 죽었다」를 적을 자리가 없다.
  **해소되지 않은 결손으로 남긴다** — 필요해지면 세션 표를 별도 WU 로 연다

### 2.5 FE 요청 첨부

- `frontend/src/api/client.ts` 에 **미들웨어 한 곳**. 화면이 헤더를 손으로 붙이지 않는다
- 로그인 op 만 예외 — 계약이 그 op 에만 `security: []` 를 적었고 붙일 토큰도 없다
- 미인증 처리 = **로그인 화면**. 401 이면 토큰을 버리고 다시 로그인. **가짜 진행을 그리지 않는다**

### 2.6 계약 개정 범위 — **5차 동결 해제에 해당한다**

- 신설 **2 op** — `createSession`(`POST /sessions`) · `endSession`(`DELETE /sessions/current`)
- 신설 스키마 2 — `SessionCredentials`(칸 1개) · `Session`(`token`·`expiresAt`)
- `security` 선언은 **기존 `sessionSubject` 를 그대로 쓴다.** 새 스킴을 만들지 않았다.
  전역 `security` 도 그대로이고, 로그인 op 하나만 `security: []` 로 벗는다
- **기존 50 op 의 요청·응답·`security` 는 한 글자도 바뀌지 않는다** — `contract-breaking` green
- op 총계 **50 → 52** · **501 표 23 유지**(신설과 동시에 구현 — `〈80〉-㉯ 5` 규칙 그대로)

### 2.7 스키마 변경 — **없다**

마이그레이션 **0**. 세션 표를 세우지 않아 성립했다 (`〈107〉-㉯`).
**필요해졌다면 그 시점에 중단·보고할 사안이었다** — 그 지점에 닿지 않았다.

### 2.8 기존 주체 표와의 관계 — **병존**

- 판정 사슬이 `주체 표 → 서명 세션` 순으로 훑는다. 하나라도 맞으면 그 주체다
- **대체하지 않는다** — 도구·시험·staging 설정이 전부 그 토큰을 쓰고 있다. 동시에 끊으면 되돌릴 수 없다
- **이행 절차는 세우지 않는다** — 끊을 시점을 정본이 주지 않았다 (`〈107〉-㉶-ⓐ` 판정 대기)

- 잠긴 데이터 표시 규칙(P-13·P-34) — 이번 회차에서 건드리지 않았다. `rls-effect` 로 회귀 확인

## 7. 추가 회차 — 어드민 계정 (Ted 2026-08-26 · `PLAN-SoT §9 〈108〉`)

### 7.1 ⚠ 정본 충돌 — 먼저 적는다

**정본은 비밀번호 로그인을 명시적으로 뺐다.**

> 「구글 외의 로그인 방법 (비밀번호 · 다른 소셜 계정)」 — `PRD_계정과_연구실_소속.md:86` (§5.2 **이번에 빼는 것**)
> 「로그인은 구글 계정 하나로만 해요. 비밀번호를 따로 만들지 않아요.」 — `:101` (POL-001)

지시는 **이 조사 결과가 전달되기 전에** 내려졌다. 구현은 했으나 어긋남은
`〈108〉-㉮` 에 **Ted 판정 사안**으로 남겼다. 승인되지 않으면 `authn.build` 에서
비밀번호 어댑터 한 줄을 걷으면 원상복구된다.

### 7.2 필수 취급 조건 대조

| 조건 | 처리 | 근거 |
|---|---|---|
| 평문 저장 금지 | **scrypt 해시만.** 소금 16 B · 파라미터 동봉. 평문 칸이 파일 형식에 없다 | `kernel/password.py` · `kernel/credentials.py` |
| 로그·오류·보고에 값 미출력 | 오류 메시지에 입력값을 담지 않는다. 회전 스크립트도 값을 되비치지 않는다 | 시험 `test_응답에_비밀번호가_되비치지_않는다` |
| 회전 절차 | `ops/set-password.py` — argv 아닌 **표준입력**, `0600`, 임시 파일 → rename | 시험 `test_회전하면_구_비밀번호가_401_이다` |
| 회전값 파일 관리 | `0600` + 실행 사용자 소유 (`〈93〉`) | 시험 `test_회전_후_파일_권한이_0600_이다` |
| 강도 보완 = 시도 제한 | **구현 범위에 포함했다.** 창 900 초 / 실패 5 회 → **429** | `kernel/throttle.py` |
| 시도 제한의 한계 | **프로세스 안에서만 센다.** 분산 시행은 공유 저장처가 필요 → 범위 밖, `〈108〉-㉲-ⓒ` 로 등재 | 감추지 않는다 |
| 계정 존재 여부 미노출 | 없는 계정과 틀린 비밀번호가 **같은 401 · 같은 본문**. 없는 계정에도 해시 한 번을 태운다 | 시험 `test_없는_계정도_같은_401_이다` |
| 회원가입 금지 | 생성 경로 0건. 자격 파일에 없는 이름은 그냥 401 | P-17 |
| 계정 생성 수단 | `ops/provision-account.sql` **작성만.** 실행하지 않았다 | Ted 지시 |

### 7.3 역할 배정 — `[정본 무근거]`

- **정본에 관리자 역할이 없다.** 역할은 **교수 · 연구원 두 층뿐**
  (P-2 · `Policy_역할과_권한 §2` · `db/platform/schema.sql` `d2_member_role.role CHECK`)
- **관리자 전용 권한을 지어내지 않는다** (`PLAN-SoT §9-㊴-②`)
- 스크립트 기본값 = **최소 권한** — `연구원` ＋ 스위치 4종 중 위임 성격 둘 꺼짐 (P-4)
- 연구실 귀속도 `[정본 무근거]` — 스크립트가 `--lab-id` 로 받는다. **확정은 `〈108〉-㉲-ⓑ`**
- P-17 과의 정합 — **개발자가 심는다**는 성질이 유지된다. 자격도 계정도 제품 밖에서 들어온다

### 7.4 비밀번호 강도

**지정된 부트스트랩 값은 사전 추측 범위이고 staging 은 공개 도메인이다.**
⚠ **그 값을 여기에 옮겨 적지 않는다** — 문서에 적는 순간 회전해도 기록이 남는다.
**최소 보완(시도 제한)은 구현했고**, 잔여 위험은 **회전으로만 해소된다** — `〈108〉-㉲-ⓓ`.
⚠ **지정값은 이 레포 어디에도 적지 않았다** (`〈93〉` 비밀 취급).

|---|---|
