## 1. 붙인 자리와 판단 근거

- **자리 = `gates/tools/autometa-loss.sh`** — 설계 회차가 지목한 자리가 맞다. **실측으로 확인했다**(믿고 간 것이 아니다).
  - URL 미선언 → `red_undeclared` **참**(§2 `COLAB_AUTOMETA_STAGING_DB_URL` 없으면 red(준비)).
  - 읽기 전용까지 검사 **참**(§2-1 — `default_transaction_read_only` 선언 확인 ＋ **쓰기 탐침**을 매 회차 던진다).
  - **롤은 검사하지 않았다** **참** — `current_user`·`rolsuper`·`rolbypassrls` 를 어디서도 읽지 않았다.
- **원장(`d5_pipeline_event`·`d3_file`·`d3_dataset_autometa`)을 실제로 세는 게이트가 이것뿐**이라 사고 재발면과 정확히 겹친다.
- 선례를 따랐다 — `rls-effect` 가 이미 `pg_roles` 로 롤 성질을 판정하고 틀리면 red 를 낸다. **방향만 반대다**
  (`rls-effect` 는 경계에 걸리는 롤을 요구하고, 이 게이트는 경계 **밖** 롤을 요구한다).

## 2. 더한 검사 셋

| | 무엇을 | 어떻게 |
|---|---|---|
| **㉮** | 관리자 롤이 아니면 **red** | `BEGIN READ ONLY` 안에서 `current_user`·`rolsuper`·`rolbypassrls` ＋ **`FORCE RLS` 표 개수**를 한 트랜잭션에 찍는다. `rolsuper`·`rolbypassrls` 둘 다 거짓이면 red. `FORCE RLS` 표가 **0개**여도 red(대조가 아무 말도 못 하는 DB 다) |
| **㉯** | 경계 롤 값이 관리자 롤 값과 **같으면 red** | 본 질의를 **두 번** 돌린다 — 한 번은 그대로, 한 번은 `SET LOCAL ROLE "<경계 롤>"` 뒤에. 숫자 넷짜리 줄이 **두 줄이 아니어도 red**(대조를 못 한 것은 통과가 아니다). 두 줄이 완전히 같으면 red |
| **㉰** | 접속 재료가 없으면 **red(준비)** | 경계 롤 이름 미선언 → `readiness_undeclared_input`(`cause=입력미선언` · 종료코드 78). 롤 이름이 식별자 모양이 아니어도 red |

- **검사 대상을 줄이지 않았고 면제·스위치를 만들지 않았다.** 건너뛰는 경로가 **0개**다.
- 판정 순서 = 읽기 전용 증명 → **㉮·㉰** → 계수 → 「대상 0건」 → **㉯** → 미반영. 「대상 0건」이 더 앞선 진단이라 그 뒤에 두었다.
- 부수 정정 — `psql` 이 boolean 을 `t/f` 로도 `true/false` 로도 낸다. 한쪽만 보면 **관리자 롤을 관리자가 아니라고 읽는다**(실측으로 밟았다). 둘 다 참으로 센다.

## 3. red 로 먼저 확인한 것

새 selftest 케이스를 **구현 전 게이트**에 걸어 먼저 red 를 봤다 — 실패 **6건**:
`ⓛ 경계 롤 미선언`·`ⓛ 원인 표식`·`ⓜ 사유`·`ⓝ 경계 롤 = 관리자 롤`·`ⓝ 사유`·`ⓞ 변이③ 오라클`.

## 4. selftest — 케이스 증가와 변이 증명

- **검사 17건 → 25건**(케이스 12 → 17 · 사유 대조 4 → 7 · 면제 건수 노출 1 유지). 새 케이스 다섯:
  - `ⓛ` 경계 롤 미선언 → **red(준비)** ＋ `cause=입력미선언` 표식 대조
  - `ⓜ` **경계 롤로 붙은 접속** → red(사유 「관리자 롤이 아니다」). 읽기 전용 선언은 그대로 달려 있어 **종전 검사로는 안 걸리던 상태**다
  - `ⓝ` 경계 롤 선언이 **관리자 롤 자신** → red(사유 「관리자 롤 값과 같다」)
  - `ⓞ` **변이③** — 롤 판정 절(2-2)을 통째로 제거 → 사유가 「대상 0건」으로 **바뀐다**. ⚠ green 이 되지는 않는다(경계 롤은 아무것도 못 보므로 「대상 0건」이 겹쳐 잡는다 · 의도된 이중 방어). 그래서 오라클을 **사유의 소멸**로 잰다
  - `ⓟ` **변이④** — ㉯ 대조만 무력화 → `ⓝ` 상태가 **green 이 된다**. ㉮ 는 그대로 두었으므로 ㉮ 가 대신 잡아 준 것이 아니다
- 재료 = 정본 그대로. 경계 롤은 `services/core-api/ops/app-role.sql` 로 세운다(시드를 두 벌로 두지 않는다).
- 일회용 postgres 안에서만 돈다 — 포트 미공개 · 레포 파일 무접촉.

## 5. 새 선언

- 이름 = **`COLAB_AUTOMETA_BOUNDARY_ROLE`** (경계 롤 **이름 하나** · 접속 URL 아님 · 비밀 아님).
- 값이 사는 자리 = 홈의 `0600` env 파일(`~/.colab-v2-test.env`) **하나뿐**. **레포에 값·절대경로 0건**(확인: `grep -rn 'COLAB_AUTOMETA_BOUNDARY_ROLE=' gates/ dev-package/` → 값 대입 0건).
- 기록 자리 = **`dev-package/RESTART.md §2-④-㉱`** (신설).
- **`COLAB_AUTOMETA_STAGING_DB_URL` 과 겹쳐 쓰지 않는다** — `㉰` 은 「누구로 붙어 어느 DB 를 세는가」, `㉱` 은 「무엇과 대조하는가」다. 합치면 게이트가 어느 DB 를 보는지 다시 모르게 된다.

## 6. 형제 게이트의 같은 사각지대 — **보고만 한다(범위 밖 · 판정 사항)**

| 게이트 | 같은 방식으로 속는가 | 근거(실측) |
|---|---|---|
| **`preview-tile-slot`** | **속는다** | `d5_pipeline_event` 를 **롤 확인 없이** 센다(`COLAB_APPLIED_DB_URL_PLATFORM`). 경계 롤이면 발행이 0 이 되고, 그러면 판정 `[ "$EMITTED" -gt 0 ] && [ "$USABLE" -eq 0 ]` 이 **통째로 건너뛰어져** 게이트가 green 을 낼 수 있다. ⚠ 지금 배선은 스키마 전용 DB 라 발행이 **구조적으로 0** 이기도 하다 — 두 결함이 겹쳐 있다 |
| **`schema-diff`** | **속지 않는다** | 판정 대상이 행이 아니라 **`pg_dump` 산출 스키마**다. 경계는 행을 거르지 값을 0 으로 만들지 않는다 — 권한이 모자라면 조용한 0 이 아니라 실패가 난다 |
| **`rls-coverage`** | **속지 않는다** | 일회용 postgres 에 선언 스키마를 적용해 `pg_class`·`pg_policies` 를 본다. 카탈로그는 경계 대상이 아니다 |
| **`rls-effect`** | **이미 롤을 본다(선례)** | `rolsuper`·`rolbypassrls`·`public` 소유 표 수를 판정 전에 확인하고 **우회 롤이면 red**. 방향만 반대다 |
| **`autometa-loss`** | **닫혔다** | 이 회차 |

## 7. 게이트 before / after

- **before(실측 · 이 워크트리 · `bash gates/run.sh all`)** — **green 34 / red(판정) 0 / red(준비) 1.**
  ⚠ **지시문의 「green 35 / red 0」과 갈린다 — 지시문이 아니라 실측을 적는다.**
  red(준비) 1건 = `rls-effect-selftest`(일회용 postgres 준비 실패 · 케이스 1~5건). **판정부가 아니라 환경이다** —
  병렬도를 낮춰(`COLAB_PG_MAX_CONCURRENT=1`·상한 180초) 재현해도 케이스 1건이 남았다. **이 회차 변경과 무관하고(`main` 에서도 같다) 손대지 않았다.**
- **after(실측 · 같은 명령)** — **green 34 / red(판정) 0 / red(준비) 1 — before 와 동일.**
  같은 `rls-effect-selftest` 한 건이고 사유도 같다(케이스 수만 회차마다 1~5건으로 흔들린다 = 환경 신호).
  **새 검사를 더한 뒤에도 판정 red 는 0 건이다.**
