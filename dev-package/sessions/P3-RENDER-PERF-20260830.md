### 5.1 새 차단 `#48` — 「타일 서빙」이 화면에 도달하지 않는다 (EVIDENCE)

**쟀다.** 실원천 GeoTIFF 한 건을 그리고 완료된 결과의 키를 전수로 봤다.

```
status = 완료
result 키 = bounds · colorRangeStage · imageUrl · legend · precisionBadge
            · sidecarUrl · thumbnailUrl · valuePreviewUrl · worldFileUrl   (아홉)
tileUrlTemplate 있음? = False
타일 직접 조회 GET /viz/v1/renders/{id}/tiles/6/54/25.png = 200 · b'\x89PNG\r\n\x1a\n'
```

**타일이 없는 것이 아니다** — 타일 표면은 서고, 서명도 발급된다(`jobs.py::_tile_url`).
**결과에 싣지 않을 뿐**이고, 그것은 의도였다 — `jobs.py:92` 가 「stage 1 은 이미지 갈래만
낸다」를 코드로 적어 두었다(`〈74〉-㉳` · 계약 `RenderResult` 가 `oneOf` 다).
화면 쪽 소비 코드(`frontend/src/components/preview/tiles.ts`)는 서 있으나 **받을 값이 오지 않는다.**

**해석 (INTERPRETATION).** `P3.completion_def` 는 **타일 서빙을 이름으로** 들고 있다
(`WORK-UNITS §7` 말미 — 「각주로만 있던 것을 완료 정의로 올린다」). 이음매에 있는 것과
제품에 있는 것은 다르다. **확대는 이 차단과 별개다** — 타일 없이 클라이언트 변환으로 섰고
정본 v2.6 §8 조건 ⑴~⑺ 을 충족한다.

**푸는 법** — 산출물 자리를 `PV-1` 이 내주면(게이트 `preview-tile-slot` 이 지금 그 자리를
기다리는 red(준비)다) 결과에 타일 갈래를 싣는 회차를 `P3` 안에 세운다.
**사람 판정 대기가 아니라 할 일이다.**
