## 4. 스크린샷 — 화면이 중계 op 에 닿는다

- **편집 권한자 컨트롤**(`§6`·`§3.2`) — `PermissionGate requires="업로드·편집"`. 꺼지면 **자리째 없다**(비활성 버튼 0).
- 보내는 것 = `layers: [{renderId, opacity: 1}]` ＋ `viewport{width, height, bounds}` —
  **`core-viz.yaml#ScreenshotRequest` 를 생성 타입 그대로 쓴다**(재선언 0 · 손수정 0).
- **「확대한 자리와 배율도 지금 장면에 포함된다」**(정본 `§8` 축자) — 보이는 자리의 비율로 결과 경계를 잘라 보낸다.
  배율 1 · 이동 0 이면 결과 경계 그대로다.
- **좌표가 없는 결과(②비지도형)에는 버튼을 세우지 않는다** — 계약이 `bounds` 를 요구하는데 없는 좌표를
  지어내면 남의 자리를 찍는다(`〈85〉`·`DR-9`). 갈 곳 없는 버튼도 두지 않는다.
- 받은 PNG 를 **그대로** 내려 준다 — 화면이 캔버스로 다시 그리지 않는다(서버가 그린 것과 다른 그림이 저장된다).
- 못 닿으면 정본 문구로 말한다. **빈 이미지를 지어내지 않는다**(계약 503 설명 축자).
