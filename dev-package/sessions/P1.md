## 2. 확정된 설계 (레인이 임의로 바꾸지 않는다)

| # | 값 | 근거 |
|---|---|---|
| 1 | **조각 수는 메타다.** `d3_dataset` 에 조각 수 열을 두고 트리거로 유지한다. `d3_file` 을 `count(*)` 하지 않는다 | `PLAN-SoT §9-㊼`. `body_access` RESTRICTIVE 아래서 본체 테이블을 세면 잠긴 행이 0 을 낸다 — 실측됨 |
| 2 | 열 이름 = **`file_count`** (`d3_dataset`) | 아래 레인들이 같은 이름을 전제한다 |
| 3 | 잠긴 카탈로그 행 = **`조각 N` 칩 뜬다** · 파일 이름·종류·본체는 잠긴 채 | `㊼-①②` |
| 4 | 잠긴 상세 = **`기본 정보` 통째로 비운다**(`basicInfo` null) | 정본 S-05 §7. 카탈로그와 달라 보이는 것은 의도 |
| 5 | 미구현은 **501 + `code` 두 종** 유지. P1 이 구현한 op 은 501 표에서 **뺀다** | `§9-㊹`. 501 목록이 줄어드는 것이 진척 계측이다 |
| 6 | 계약은 **고치지 않는다**. 34 op·필드·enum 전부 동결 | 고쳐야 할 것 같으면 **멈추고 보고**한다 |
| 7 | 도메인 간 직접 참조 금지 — cross-domain 은 **Port 경유**. 기존 `catalog.py` 의 `_compose` 패턴을 따른다 | `CLAUDE.md §3-1` · `import-boundary` 게이트 |
| 8 | 권한 스위치는 **정확히 4개**: `업로드·편집` · `프로젝트 생성` · `승인 위임` · `연구실 설정` | 정본 E-01 §1. 새 스위치를 만들지 않는다 |
| 9 | 재위임 금지는 **서버가 강제**한다 — 행별 `editablePermissions` + 위반 시 403 | 정본 E-01 §6 · `P-31` |
| 10 | 권한 없는 기능은 **숨긴다**. 비활성 + 툴팁이 아니다 | 정본 E-01 §4 · `P-7`·`P-12` |

## 5. 멈춤 규칙

1. **게이트를 우회하거나 끄지 않는다.** 검사 대상을 줄여서 green 을 만들지 않는다
2. **정본이 값을 주지 않으면 만들지 않는다** — `[정본 무근거]` 로 남기고 보고한다
3. **계약을 고치지 않는다**
4. **서브에이전트는 커밋하지 않는다.** 커밋과 `03-HANDOFF`·`PLAN-SoT` 갱신은 메인 세션만
5. 컨테이너는 레인 접두사(`p1db_`·`p1api_`)로 짓고 **호스트 포트를 공개하지 않는다**
