## 5. 닫지 않는 이유 — 하나 남았다

`PV-1` 의 산문 완료 조건은 **전부 실측으로 섰다**(위 §3). 남은 것은 공통 완료 조건
「전 게이트 green」 한 줄이고, 그것을 막는 것은 **`autometa-loss` 가 어느 DB 를 대조하는가**다.
스키마만 적용된 일회용 DB 를 계속 보게 두면 이 게이트는 **영원히 red** 이고,
staging 을 전역으로 물리면 `db-selftest` 가 뒤집힌다(`RESTART §2-④-㉮` 실측).
**둘 중 하나를 이 회차가 고르지 않는다** — `03-HANDOFF §4` **#50** 으로 올린다.
