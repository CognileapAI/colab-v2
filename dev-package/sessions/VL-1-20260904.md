| ㈎ | **D7 안의 단계별 시간** | `docker exec colab_v2_staging_viz_render`(읽기 전용 · 수명 조작 0) 안에서 `value_lookup` 의 각 단계를 `time.perf_counter` 로 감쌌다. **찬 상태**는 대상 파일마다 `posix_fadvise(POSIX_FADV_DONTNEED)` 로 페이지 캐시를 **그 파일만** 버려 만들었다 — 호스트 전역 `drop_caches` 는 쓰지 않았다(경계 밖) |
