## 5. 되돌림 경로

- ⑴⑷⑸ **신설** — 계약에서 열쇠를 빼고 컬럼을 `DROP` 하지 않은 채 두면 종전 동작으로 돌아간다(서버 수용 목록에서 제외하면 즉시 무효).
- ⑵ **`variables` 형태 변경** — 원본 `d3_dataset_autometa.variables text[]`(`db/platform/schema.sql:414`)를 **지우지 않는다**. `M-10` 의 미러 트리거가 새 표를 옛 배열로 되쓰므로, 계약을 되돌리면 옛 경로가 그대로 산다.
- ⑶ **`accessState` 3값** — `enum` 을 2값으로 되돌리면 3번째 값을 가진 행이 계약 위반이 된다 ⟹ **되돌리려면 데이터 정리가 선행**한다. 이 한 갈래만 순수 되돌림이 아니다.
- ⑴ `processingLevelUserSet` — `0011` 의 삭제 근거 주석이 **남아 있으므로** 반전을 다시 되돌리는 근거가 문서에 보존된다.

## 6. 기각한 대안 (설계 판단이 섞였다는 증거)

- **PRD-16 ⓑ** — `variables` 를 문자열 배열 그대로 두고 표시층에서 쪼개는 안. **기각.** 변수마다 단위·설명·대표 여부가 붙어야 하는데 문자열 배열은 그 자리를 못 만든다. ⟹ 표 신설(`M-5`).
- **PRD-27 판정식** — 자동 `mark_unknown`(`services/core-api/src/colab_core/app/routes/ingestion.py:614`)을 유지하고 화면에서만 갈라 보이는 안. **기각.** 저장 시점에 플래그를 찍으면 부모를 나중에 붙이는 흐름에서 값이 굳는다. ⟹ `lineage_state()`(`services/core-api/src/colab_core/domains/d3_catalog.py:988`)를 6항 판정식으로 대체하고 자동 표시를 걷는다.
- **미결-2 ⓐ(`〈194〉` 반전)** — 「레벨은 언제나 계보에서 나온다 — 예외 없음」 유지안. **기각(Ted 2026-09-05).** 부모를 나중에 붙이는 흐름에서 불일치는 정상 중간 상태이고, 차단하면 등록을 못 끝내며 덮어쓰면 고른 값이 사라져 선택 칸이 무의미해진다.
