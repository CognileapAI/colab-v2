# P3 — 「한 장」과 「타일」을 A/B 로 켜고 끌 수 있게 했다 (2026-08-31 · 워크트리 `lane-ab`)

> **한 줄** — 정본은 타일을 **명시로 배제**하고 있었고, 타일 전환은 **대장에만 있던 문구**를
> 근거로 한 것이었다. 되돌리지 않는 대신 **두 갈래를 선택 가능하게** 만들었다.
> **기본값은 「한 장」**(정본 문면)이고 타일은 **명시로 켰을 때만**이다.
> **배포하지 않았다.** `P3` 를 닫지 않는다.

값·근거의 정본은 `PLAN-SoT §9 〈240〉` 하나다. 정본 근거는 `Policy_데이터셋_상세` **v2.7 §8**.
여기는 **Ted 가 A/B 를 어떻게 켜고 끄고 무엇을 보고 판단하는가**와 계수만 적는다.

---

## 1. Ted 가 켜고 끄는 법 — 세 줄

1. **끄기(기본값)** — 아무것도 하지 않는다. 홈 env(`~/.colab-v2-staging.env`)에
   `COLAB_VIZ_TILE_BRANCH` 가 **없으면 「한 장」**이다. 지도는 종전처럼 PNG 한 장 + 경계 4값.
2. **켜기** — 홈 env 에 `COLAB_VIZ_TILE_BRANCH=1` 한 줄을 넣고 viz-render 를 다시 띄운다.
   (`on`·`true`·`yes` 도 같다. **그 밖의 모든 값과 오타는 꺼짐**이다 — 오타가 몰래 켜지 않는다.)
3. **지금 어느 쪽인지 확인** — `/healthz/viz-render` 본문의 `tileBranch` 가 **`켜짐`/`꺼짐`**을 말한다.
   화면 쪽 증거는 미리보기 결과 본문이다 — `imageUrl` 이면 한 장, `tileUrlTemplate` 이면 타일.

> ⚠ **켜도 넘지 않는 경계 셋** (정본 v2.7 `§8`) — 좌표 없는 자료 · 미등록 업로드는 **언제나 한 장**,
> 서명 비밀이 없으면 **아예 그리지 않는다**(표면 503). 스위치는 없는 것을 지어내지 않는다.

## 2. 무엇을 보고 판단하나 — 새 눈금을 만들지 않았다

정본 v2.7 `§8` 의 A/B 판정표 그대로다. 아래 여섯을 **같은 데이터셋에서 두 갈래로 각각** 본다.

| 볼 것 | 눈금 | 어디서 |
|---|---|---|
| 처음 지도가 보일 때까지 | **p95 10초 · 상한 60초** | 정본 §8 렌더 성능·상한 |
| 확대·축소·이동 한 번의 반응 | **100 ms** | 확대 조건 ⑺ |
| 확대해도 값·팔레트·구간 수·범례가 그대로인가 | 확대 전후 범례 대조 | 확대 조건 ⑵ |
| 확대가 렌더를 다시 걸지 않는가 | **새 렌더 작업 생성 0건** | 확대 조건 ⑶ |
| 데이터 해상도 너머로 들어가지 않는가 | 한계 배율 안내 표시 | 확대 조건 ⑷ |
| 겹쳐 보기에서 층이 함께 움직이는가 | 겹쳐 보기 상태 확인 | 확대 조건 ⑸ |

**그리고 눈으로 보는 것 하나** — 같은 자리를 키웠을 때 **칸이 뭉개지는가**. 이것이 애초에
확대를 넣은 이유이고(정본 §8 「왜 넣는가」), 수치가 아니라 Ted 의 판단 사항이다.

## 3. 엣지 — 합쳤고 배포하지 않았다

`lane-edge` 를 fast-forward 로 합쳤다(`infra/staging/nginx.i2.conf` 1파일 · 그 회차 기록 동반).
**켜짐/꺼짐 양쪽에서 회귀가 없는지 임시 엣지로 실측했다** — 운영 스택 무접촉(8/8 healthy 유지),
임시 컨테이너는 회수했다. 비교군은 지금 도는 엣지다.

| 갈래 | 무엇을 쟀나 | 새 엣지 | 도는 엣지 |
|---|---|---|---|
| **꺼짐** | `/previews/<해시>.png` **실파일 2건** | **200 · `image/png` · 40,142 B / 1,468,068 B · 매직 `89504e47`** | 같음 · **본문 바이트 동일** |
| **꺼짐** | `/` · SPA 깊은 경로 · 없는 경로 · `/healthz` · `/healthz/viz-render` · `/previews/nope.png` | 6경로 | 6경로 **전부 본문 바이트 동일** |
| **켜짐** | 타일 모양 경로(서명 없음) | **401 ＋ JSON** — 뒷단에 닿는다(라우팅이 산다) | **200 ＋ SPA html** — `#51` 재현 |
| **켜짐** | `/viz/v1/renders` · `/screenshots` · 접두사만 · `z=999` · traversal | **5건 전부 404** | 5건 전부 200 SPA |

**꺼진 갈래는 이 설정이 있어도 종전과 한 바이트도 다르지 않다 — 회귀 0건.**

## 4. 앞 회차의 `[미확인]` — 해소했고, 우회가 아니라 절차를 고쳤다

**물음** — `nginx.i2.conf` 는 바인드 마운트인데 `deploy.sh` ⑩ 이 `up -d` 뿐이라
**nginx 가 재생성되지 않아 옛 설정이 계속 돌 수 있다**(`P3-EDGE-TILE-20260831.md §3`).

**실측** — 격리된 일회용 compose 프로젝트로 재현했다(운영 무접촉).

| 회차 | 결과 |
|---|---|
| 설정 파일만 고치고 `up -d` | **컨테이너 ID 동일 = 재생성 없음** → **`[미확인]` 은 실재하는 결함이었다** |
| 설정 해시를 환경에 실은 뒤 `up -d` | **컨테이너 교체 = 재생성됨** |

**고친 자리 둘.**

1. `infra/staging/compose.i2.yml` — nginx 에 `COLAB_EDGE_CONF_SHA` 환경 신설(안 넣으면 `미배선`).
   설정이 바뀐 회차에만 컨테이너가 다시 만들어진다.
2. `infra/staging/deploy.sh` ⑩ — 배포가 `sha256sum nginx.i2.conf` 를 계산해 export 한 뒤 `up -d`.
   그리고 **⑩-b 신설**: 도는 컨테이너 안의 설정을 읽어 레포 판과 **바이트로 대조**하고,
   다르거나 읽지 못하면 **abort**. **「고쳤다」를 「돌고 있다」로 읽지 않는다** — `:i2` 재부착이
   검증 없이 단언되던 그 모양(`X-6`)을 반복하지 않는다.

## 5. 배포할 때 밟을 절차와 확인 항목 — **승인 사항이라 이 회차는 하지 않았다**

```
approve.sh Ted "<본 것>"
deploy.sh --target staging
```

| # | 확인 항목 | 합격선 |
|---|---|---|
| 1 | 갈래 선언 | 홈 env 의 `COLAB_VIZ_TILE_BRANCH` 가 **의도한 값**인가. 없으면 「한 장」이다 |
| 2 | **엣지 설정 반영** (⑩-b) | 도는 컨테이너 안의 설정 해시 = 레포 판 해시. **다르면 배포가 스스로 멈춘다** |
| 3 | 배포 판정 | **GREEN · 통과 15건 · SKIP 0** · 컨테이너 **8개 healthy** · 호스트 노출 `0.0.0.0` **0건** |
| 4 | 헬스 | **6종 200 ＋ 본문 대조.** **루트 200 으로 판정하지 않는다** |
| 5 | **갈래 관측** | `/healthz/viz-render` 의 `tileBranch` 가 **의도한 값**인가 |
| 6 | 실렌더 대조 | 지도형 결과 본문이 **의도한 갈래의 키**를 내는가(`imageUrl` ↔ `tileUrlTemplate`) |
| 7 | **꺼진 갈래 회귀** | `/previews/…` PNG 가 **200 ＋ `image/png`** 인가 |
| 8 | **켠 갈래 도달** | 타일 조각 세 배율이 **200 ＋ `image/png`** 인가. `text/html` 이면 `#51` 이다 |
| 9 | 서명 음성 | 서명 없음·변조·만료가 전부 **401** 인가 |
| 10 | 체인 head | 마이그레이션 **0건** — 이 변경분에 스키마 변경이 없다 |
| 11 | 성능 | 미리보기 최초 표시 **p95 10초 이내** · 확대 1회 **100 ms 이내** |

⚠ **로그에 토큰·서명을 출력하지 않는다.** 지난 회차에 유출 사례가 있다.
