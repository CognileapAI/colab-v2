### ㈎ 가공 단계(헤더 읽기·좌표계 변환·미리보기용 영상 변환)의 완료 기준

- **현재 상태** — 변환 코드는 다 있고 시험도 돈다. 켜는 스위치가 꺼져 있다. 완료 기준만 비어 있다.
- **선택지의 뜻** — ⓐ 앞단과 같은 형태로 넷을 세운다(자기 증명 시험 · 실데이터 전건 완주 · 게이트 통과 · 실서버 배포 통과)
  ⓑ 「실데이터 123건 중 몇 건이 미리보기 영상까지 간다」를 수치로 못 박는다 ⓒ 지금은 안 정하고 착수만 한다.
- **고르면 달라지는 것** — ⓒ 를 고르면 **닫지 못한다.** 앞단에서 이미 그 값을 치렀다(범위가 걸쳐 있어 상태 기호가 하나로 안 잡혔다).
- **권고 = ⓐ ＋ ⓑ 의 수치 한 줄.** 되돌리는 비용 = 문서 두 줄 수정.

### ㈏ 파일에서 읽은 정보(포맷·변수·기간·좌표계·격자)를 누가 원장에 적는가

- **배경** — 카탈로그 화면이 읽는 「자동으로 읽은 정보」 칸이 **적재된 12건 전건 비어 있다**(실측).
  값을 만드는 쪽은 파일을 여는 처리 서버이고, 표를 소유한 쪽은 API 서버다. **둘 사이 경로가 없다.**
- **현재 상태** — API 서버 코드가 자기 주석에 「새 값은 파일을 읽는 쪽이 채운다」라고 적어 뒀는데, 그 쪽에 쓰는 코드가 0건이다.
- **선택지의 뜻** — ⓐ 처리 서버가 알림을 내고 API 서버가 받아서 적는다(경계 유지 · 수신 창구를 새로 만든다)
  ⓑ 처리 서버에 그 표의 쓰기 권한을 준다(빠름 · 도메인 경계를 뚫는다).
- **고르면 달라지는 것** — ⓑ 는 「API 서버는 파일을 못 읽는다」와 짝인 「처리 서버는 카탈로그 표를 안 쓴다」를 깬다.
  한 번 뚫으면 다음 항목도 같은 길로 온다.
- **권고 = ⓐ.** 되돌리는 비용 = 수신 창구 하나 폐기.

### ㈐ 우리가 만든 미리보기용 영상 파일을 어디에 두고 원장에 어떻게 남기는가
