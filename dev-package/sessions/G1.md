# WU-G1 — E-00 전달 패키지 재빌드 (DataModel v1.8 · Policy v1.4 반영)

> **P0을 막는 나머지 하나.** G5가 저장 형태를 못박았다면, G1은 **개발자가 0단계에서 실제로 읽는 물건**이
> 그 저장 형태와 같은 판인지를 보장한다.
> E-00 패키지는 목업이 없다 — 담긴 것이 문서뿐이라, 문서가 낡으면 패키지 전체가 낡은 것이다.

---

## 0. 착수 전에 알아야 할 사실 — 이 WU는 "재빌드"가 아니라 "검증과 기록 정정"일 수 있다

세션 지시서를 쓰며 실물을 먼저 확인했다 (2026-08-22). **E-00 패키지 HTML에 박힌 문서 본문은
현행 `DataModel v1.8` · `Policy v1.4` 원본과 공백 한 줄을 빼고 완전히 같다.**

| 확인 항목 | 실측 결과 |
|---|---|
| 패키지 임베드 `md-prd` front matter | `version: 1.8` · `updated: 2026-08-18` |
| 패키지 임베드 `md-policy` front matter | `version: 1.4` · `updated: 2026-08-17` |
| 임베드 본문 ↔ 원본 md 본문 | **동일** (말미 개행 1줄 차이뿐) |
| 여덟 에픽 전수 | **8/8 전부 임베드 == 원본** |

즉 `planning/README.md §3`의 "🔴 v1.7·v1.8 두 판 미반영"과
정본 `E-00 README §4`의 "패키지를 다시 만들어야 한다"는 **모두 낡은 서술이다.**
누군가 이미 재빌드했고, 그 사실이 어느 기록에도 반영되지 않았다.

> **그래서 G1의 본체가 바뀐다.** 손으로 다시 만드는 일이 아니라,
> **"일치한다"를 기계가 말하게 만들고**(이게 완료 판정이다) 어긋난 기록을 바로잡는 일이다.
> 이 WU가 닫히는 순간부터 같은 착각이 다시 생기지 않아야 한다.

## 4. 범위

### 건드리는 것

| 대상 | 내용 |
|---|---|
| **최신성 검사기** | 패키지 HTML 임베드 md ↔ 원본 md 를 기계 대조. red/green을 낸다 |
| **E-00 패키지** | 검사 red일 때만 재빌드. green이면 손대지 않는다 |
| `planning/README.md` | §3 상태표를 실측으로 정정 (Δ1·Δ2·Δ3) |
| 결정 기록 | `PLAN-SoT §9` 확정 항목 추가 |

### 건드리지 않는 것

- **문서 내용 자체** — DataModel·Policy 본문은 기획 소관이다. G1은 **옮기기만** 한다
- **목업·화면 부분의 최신성** — E-02·E-04의 08-17 리뉴얼 반영은 **G1b**다. G1은 E-00(목업 없음)만 닫는다
- **패키지 파일명 변경 · 정본 폴더 재편** — 링크가 깨진다. 폴더 통합은 **G7**
- **정본 md 수정** — Δ4는 보고까지. 기획 문서 개정은 Ted 결정
- **스키마·DDL** — G5/P0 소관

## 5. 산출물

1. **`dev-package/tools/check-package-freshness.py`** — 최신성 검사기 (Δ3)
   - 정본 루트를 **인자 또는 환경변수로 받는다.** 경로를 소스에 박지 않는다(`CLAUDE.md §5` 절대경로 금지)
   - 에픽별로 `package/*.html`의 `<script type="text/markdown" id="md-*">` 본문을 뽑아
     `documents/*.md` 원문과 **정규화 후 완전 일치**를 판정 (말미 개행·BOM만 정규화. 그 외 관대해지지 않는다)
   - 어느 원본과도 짝지어지지 않는 임베드 블록, 임베드되지 않은 원본 문서 — **둘 다 red**
   - 원본 front matter의 `version`을 함께 출력한다
   - **정본 폴더가 안 보이면 skip이 아니라 red** (`CLAUDE.md §4` — green-by-skip 금지)
   - `--selftest` : 임베드 한 글자를 바꾼 fixture로 **자신이 fail-closed임을 증명**한다
2. **`gates/run.sh` 에 `planning-freshness` 게이트 등록** — `gates/README.md` 목록 갱신
3. **`dev-package/PACKAGE-FRESHNESS.md`** — 실행 결과 스냅샷. 에픽 8행 × (패키지 파일 · 임베드 문서 · 버전 · 판정 · 마지막 확인일)
4. `PLAN-SoT §9` 결정 기록 · `03-HANDOFF §1` G1 행 갱신 · `planning/README §3` 정정

| # | 조건 |
|---|---|
| **1** | `./gates/run.sh planning-freshness` 가 **green** — E-00 패키지의 `md-prd` · `md-policy` 임베드 본문이 `DataModel_공통_기반.md`(v1.8) · `Policy_공통_기반.md`(v1.4) 원문과 **정규화 후 완전 일치**하고, 임베드/원본 어느 쪽에도 짝 없는 문서가 0건이다 |
| **2** | 임베드 front matter가 `version: 1.8` · `version: 1.4` 이고, §3의 v1.7→v1.8 · v1.3→v1.4 신설 항목(레코드 시점 3종 · 계보 상태 4값 · 파일 1:N · 프로젝트 N:N · 권한 스위치 4종 · GNB 첫 탭 `연구실` · 업로드 전체 화면 모달)이 임베드 본문에 **문자열로 존재**한다 |
| **3** | `--selftest` 가 **red를 낸다** — 검사기가 fail-closed임이 증명된다. green이 나오면 검사기가 오라클이 아니다 |
| **4** | 게이트가 **정본 폴더 부재 시 red** 임이 확인된다 (마운트 해제 상태로 1회 실행) |
| **5** | `planning/README §3` 표가 실측과 일치한다 — 실물과 모순되는 행 0 |

> **1·3번이 짝이다.** "일치한다"만으로는 부족하다 — v1의 RLS 테스트가 DB 없이 green-by-skip 했던 자리가 정확히 여기다.
> 검사기가 **틀린 것을 틀렸다고 말할 수 있음**을 먼저 보이고, 그 다음에 green을 받는다.
