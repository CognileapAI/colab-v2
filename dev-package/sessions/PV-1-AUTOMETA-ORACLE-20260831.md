## 2. 판정과 배선

**Ted 판정 ⑨ = 대조 정본은 staging 실물 DB.** 질문이 「실제로 접수한 것 중 메타가 빠진 것이
있는가」이므로 정답지가 실물이어야 한다.

| 축 | 값 |
|---|---|
| 새 선언 | **`COLAB_AUTOMETA_STAGING_DB_URL`** — 옛 변수에 **겹쳐 쓰지 않았다** |
| 옛 변수 | `schema-diff`·`preview-tile-slot` 이 **그대로** 쓴다(무접촉) |
| 옛 변수만 있을 때 | 게이트가 **그 사실을 이름으로 지적하며** red — 조용한 폴백 없음 |
| 값이 사는 자리 | 홈의 `0600` env 파일 하나(`RESTART §2-④-㉰`). 레포·문서에 값·절대경로 **0건** |
| 망 | `COLAB_PG_NETWORK` 전역을 쓰지 않았다(`db-selftest` 를 뒤집는다) — 호스트에서 직접 닿는다 |

## 3. 읽기 전용 — 주장하지 않고 집행하고, 집행을 다시 증명한다

| 층 | 무엇 | 어기면 |
|---|---|---|
| ⑴ 선언 | URL 이 `default_transaction_read_only=on` 을 달아야 한다 | **red** |
| ⑵ 집행 | 모든 SQL 이 `BEGIN READ ONLY … ROLLBACK` — 스크립트에 `COMMIT` **0건** | — |
| ⑶ 증명 | 매 회차 **쓰기 탐침**(임시 테이블 생성)을 던진다. 거부당해야 한다 | **red** |

탐침은 세이브포인트로 되감고 트랜잭션 전체를 ROLLBACK 하므로 **남는 흔적이 0** 이다.
즉 증거가 「읽기 전용이라고 적어 두었다」가 아니라 **「이 회차에 실제로 쓰지 못했다」**다.

⚠ **롤이 `postgres` 인 이유를 감추지 않는다** — 플랫폼 테이블이 `FORCE ROW LEVEL SECURITY` 라
**소유자도 걸러진다**(실측 = `colab_owner` 로 붙으면 `d5_pipeline_event` **0행**). 감사자는 연구실
경계 **밖에서 전수**를 봐야 한다. 쓰기는 위 세 겹이 봉한다.
