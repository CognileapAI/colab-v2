# 엣지 타일 경로 — 설정을 고치고 임시 엣지로 실측했다, **배포하지 않았다** (2026-08-31 · 워크트리 `lane-edge`)

> **한 줄** — `#51` 을 닫는 설정은 서 있고 보안 4종이 전부 실측으로 거부를 냈다.
> 그러나 **타일 전환(〈238〉) 자체의 필요성이 재검토로 올라가 배포 직전에서 멈췄다.**
> **판정은 Ted 가 한다. 이 회차는 대장·정본·`03-HANDOFF`·`PLAN-SoT` 를 한 글자도 고치지 않았다.**

## 1. 무엇을 고쳤나 — 파일 하나

`infra/staging/nginx.i2.conf` 에 두 개의 `location` 을 더했다. **레포의 정본 설정만 고쳤고
서버에 손으로 바르지 않았다.** 운영 스택은 이 회차 내내 **무접촉**이다(8/8 healthy 유지).

| 무엇 | 어떻게 |
|---|---|
| 타일 경로 | **정규식 location** — `^/viz/v1/renders/[0-9A-HJKMNP-TV-Z]{26}/tiles/[0-9]{1,2}/[0-9]{1,10}/[0-9]{1,10}\.png$` → `viz-render:8100`. **접두사로 열지 않는다** — 뚫는 것은 `getRenderTile` 한 자리다 |
| 나머지 `/viz/` | `return 404`. SPA fallback 으로 흘려보내지 않는다 — 「없는 표면이 200 을 낸다」가 `#51` 의 실물이다 |
| `Authorization` | **엣지에서 비운다.** 뒷단은 「서비스 토큰 **또는** 서명」을 받는데(`app/deps.py:require_caller_or_tile_signature`), 공개 면에서 토큰 갈래를 살려 두면 엣지가 서비스 자격 증명의 입구가 된다. **공개 면은 서명 전용이다** |

## 2. 실측 — **임시 엣지**로 쟀다 (운영 무접촉)

같은 정본 설정 파일을 `nginx:1.27-alpine` 일회용 컨테이너에 물려 staging 망에 붙이고
`127.0.0.1:3099` 로 쟀다. 비교군은 **지금 도는 엣지**(`127.0.0.1:3000`)다.
표본 = 등록 지도형 데이터셋 두 건의 실렌더(`01M1B6…9KP` · `01M1B6…ZVQ`) · 서명 각각 발급.

### ㉮ 타일이 실제로 나오는가 — 배율 3자리

| 배율 | 새 엣지 | 지금 도는 엣지 |
|---|---|---|
| `z=6` | **200 ＋ `image/png` · 1,580 B · 매직 `89504e47`** | 200 ＋ `text/html` **409 B**(＝ SPA `index.html`) |
| `z=8` | **200 ＋ `image/png` · 334 B · 매직 `89504e47`** | 〃 |
| `z=10` | **200 ＋ `image/png` · 334 B · 매직 `89504e47`** | 〃 |

⚠ `z=8·10` 의 334 B 는 **빈 타일**이다(범위 밖 조각 — 뒷단이 의도적으로 200 을 낸다).
매직은 셋 다 PNG 다. **`#51` 은 지금 도는 엣지에서 다시 재현됐다.**

### ㉯ 서명 검증이 실제로 걸리는가 — **4건 전부 거부**

| 요청 | 결과 |
|---|---|
| 서명 **없음** | **401** ＋ `application/json` |
| `sig` **변조**(한 글자) | **401** |
| `exp` **연장**(서명은 그대로) | **401** — 서명이 만료 시각을 덮으므로 늘려도 안 선다 |
| **만료된 `exp` ＋ 유효한 서명** | **401** · 본문 「타일 주소의 서명이 만료됐다」 — 만료와 불일치를 갈라 답한다 |

**엣지가 검증을 우회시키지 않는다** — 검증은 뒷단(`kernel/signing.verify`)이 하고
엣지는 `exp`·`sig` 를 그대로 넘긴다. 그리고 **엣지가 토큰 갈래를 닫는다**:

| 같은 주소·서명 없음·서비스 토큰만 | 결과 |
|---|---|
| **새 엣지** | **401** — `Authorization` 을 비웠다 |
| viz-render **직접**(망 안) | 200 ＋ `image/png` |

### ㉰ 연구실 경계 — **음성 3건 거부. 다만 표본의 한계를 적는다**

이 이음매에서 경계를 긋는 것은 **`renderId` ＋ 그 `renderId` 를 덮는 서명**이다.
연구실 판정은 **렌더 생성 시점**에 core-api 가 한다(`routes/preview.py:_target_in_lab`
— 「그릴 대상이 없거나 연구실 경계 밖이다」). 타일 조회에는 연구실 인자가 없다.

| 요청 | 결과 |
|---|---|
| 렌더 **A 의 서명**으로 렌더 **B** 요청 | **401** |
| 렌더 **B 의 서명**으로 렌더 **A** 요청 | **401** |
| **없는 `renderId`** ＋ A 의 서명 | **401**(작업 조회보다 인증이 먼저 서서 존재 여부를 흘리지 않는다) |

⚠ **다른 연구실의 실표본은 0건이다 — 지어내지 않는다.** 배포된 스택의 등록
데이터셋 13건이 **전부 같은 연구실**(`00000000000000000000HYMETS`)이다. 위 셋은
「다른 렌더의 자격으로는 못 넘어온다」를 실측한 것이고, **다른 연구실의 렌더가
실제로 존재하는 상태에서의 확인은 하지 못했다.**

### ㉱ traversal · 상위 디렉터리 탈출 · 표면 확대 — **전부 막힌다**

| 요청 | 결과 |
|---|---|
| `…/tiles/../../../../healthz` | **404** |
| `…/tiles/../../renders` (`--path-as-is`) | **404** |
| `…/tiles/%2e%2e/%2e%2e/renders` | **404** |
| `/viz/v1/renders` (생성 표면) | **404** |
| `/viz/v1/screenshots` | **404** |
| `/viz/v1/palettes` | **404** |
| `/viz/v1/renders/{id}/tiles/` (접두사만) | **404** |
| `z=999`(범위 밖) | **404** |

정규식이 경로 **모양**을 못 박으므로 위 여덟은 **뒷단에 닿지도 않는다.**

### ㉲ SPA fallback 회귀 — **다른 경로는 바이트까지 같다**

새 엣지와 지금 도는 엣지에 같은 요청을 넣고 **본문을 바이트로 대조**했다.

| 경로 | 새 엣지 | 지금 엣지 | 본문 |
|---|---|---|---|
| `/` | 200 `text/html` 409 B | 같음 | **동일** |
| `/datasets/abc`(SPA 깊은 경로) | 200 `text/html` 409 B | 같음 | **동일** |
| `/nope-not-a-route` | 200 `text/html` 409 B | 같음 | **동일** |
| `/healthz` | 200 `text/plain` 3 B | 같음 | **동일** |
| `/healthz/viz-render` · `/healthz/core-api` | 200 `application/json` | 같음 | **동일** |
| `/api/v1/datasets`(무세션) | **401** | 같음 | **동일** |
| `/previews/nope.png` | 404 | 같음 | **동일** |

**SPA fallback 은 타일 경로만 놓았고 나머지는 종전 그대로다 — 회귀 0건.**

## 3. 배포하지 않았다 — 그리고 배포한다면 확인해야 할 자리 하나

⛔ **재배포는 하지 않았다.** 조정자 지시(타일 전환의 필요성 재검토)로 배포 직전에서 멈췄다.

⚠ **[미확인 · 배포 시 확인 필요]** `nginx.i2.conf` 는 compose 의 **바인드 마운트**다
(`compose.i2.yml:33`). `deploy.sh` ⑩ 은 `dc up -d --remove-orphans` 이고 nginx 는
이미지·환경이 안 바뀌면 **재생성 대상이 아닐 수 있다** — 그러면 **파일은 고쳤는데
도는 설정은 옛것**이 된다. 이 회차는 배포를 하지 않아 **실측하지 못했다.**
배포한다면 `nginx` 강제 재생성(또는 설정 해시 배선)을 확인하고 **루트 200 으로
판정하지 않는다.** 지어내지 않는다.
