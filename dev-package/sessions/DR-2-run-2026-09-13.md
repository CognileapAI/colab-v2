- `app-grants` exit 0 · 축자 「`app role grants: ok (colab_app@platform · colab_ai_app@ai · SELECT only)`」.
- `account-admin` **exit 3** — 실패 문장 = `services/core-api/ops/account-admin-role.sql` 의 `ALTER ROLE %I NOSUPERUSER NOCREATEDB NOCREATEROLE NOINHERIT BYPASSRLS PASSWORD %L`.
- 원인 = RDS 마스터가 `rds_superuser` 이고 진짜 SUPERUSER 가 아니다. PostgreSQL 은 `NOSUPERUSER` 를 **명시한 것만으로** SUPERUSER 속성 변경으로 판정해 슈퍼유저를 요구한다(현재 값이 이미 `NOSUPERUSER` 여도 같다).
- 성격 = 이번 초기화가 만든 결함이 아니라 **RDS 경로에서 이 스크립트가 통과할 수 없는 구조**다. `infra/dev/db-bootstrap.sh` 의 `account-admin` 은 `infra/staging/db-bootstrap.sh` 로 위임되고 원격 갈래는 마스터 URL 로만 붙는다.
- 실패 위치가 GRANT 앞이라 **GRANT 문 전건 미실행**이다.
