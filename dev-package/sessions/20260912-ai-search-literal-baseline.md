# AI 검색 — 12문항 낱말 검색 기준선

2026-09-12. [전체 계획](../prd/rounds/R-STAGE3-AI-SEARCH.md) 작업 3의 실행 형식과 작업 4의 첫 측정.
모델·사전·그래프를 제외한 진단 기준선이다. 현재 제품 전체 검색 성능이나 Astra 성능을 뜻하지 않는다.

## 실행 조건

- 질문·정답: `eval/k4-search/golden-set.md`, 기계 입력 `golden-cases.json`.
- 로컬의 실제 LiteralInterpreter로 질문을 낱말화하고 dev의 실제 `d3_catalog.search_datasets` 함수를 호출했다.
- 기존 연구실 A·연구원 A1 스코프, READ ONLY 트랜잭션, REPEATABLE READ. 모델 호출·제품 데이터 수정 0건.
- 전체 후보 25건에서 매치가 잘리지 않았음을 확인한 뒤 ID로 제한했다. 001은 식생4묶음, 나머지는 LD9묶음.
- 이것은 독립된 9건 DB 검색과 같지 않다. 이름 유사도 폴백 발동 여부는 전체 스코프의 결과에 따르며, 제한 후보에 맞춰 알고리즘을 바꾸지 않았다.
- 정답 없는 후보·잘림·중복·문항 누락은 준비 실패로 처리한다. 기존 결과 파일은 덮어쓰지 않는다.

- 자동 검사: 통과7 / 실패3 / 해당 없음2. 추천 근거·조건 충족의 의미 판정은 **12건 전부 미실행**.
- 자동 통과는 정답이 목록에 포함됐다는 의미다. 순위·오답 후보·근거가 모두 맞았다는 의미가 아니다.
- 첫 실행 `literal-baseline-01.json` exit1. 후보의 검색 벡터 보존이 빠진 것을 보완해 `literal-baseline-02.json`으로 한 번 더 실행했고 계수는 동일, exit1이다.
- 기준 결과: [literal-baseline-02.json](../reports/stage3-ai-search-plan/literal-baseline-02.json). 원시 검색어·결과·순위·코드 hash·후보 설명/벡터를 포함한다.

## 검증과 다음 순서

- 판정 도구 시험은 도구 부재로 RED를 확인한 뒤 구현했다. 잘림·중복·복수 정답·범위·미판정 관련 5개 시험 GREEN.
- 독립 내용 검토에서 선언된 포함 검사 범위의 차단 오류는 없었다. 공유 사본 변경으로 조사자의 H6 종료 검증은 exit2이므로 독립 게이트 통과로 세지 않는다.
- 검토에서 실행기·의미 정본 hash 누락을 발견해 측정 때 사용한 파일 hash를 `literal-baseline-02-receipt.json`에 보존했다. 이후 실행기는 두 hash를 결과에 직접 기록한다. 증거 보완을 위해 원격 검색을 세 번째 반복하지 않았다.
- 후속: 현재 사전·그래프 포함 체인의 기준선을 같은 문항으로 추가 측정해, 이번 단순 낱말 기준선과 분리한다.
- 그다음 질문 해석, 기간·지역·가공 역할의 조건 처리, 사실 기반 추천 근거를 각각 비교한다. 모델·새 검색 기술을 아직 선택하지 않았다.
- 권한·장애 E2E, 실제 모델 호출 평가, 응답 의미 판정, 속도·비용 합격선은 남아 있다.
- 모델 평가가 필요한 단계에서는 로컬의 실제 사용 모델과 프롬프트를 고정한다. 이 무모델 측정을 모델 평가로 재사용하지 않는다.
