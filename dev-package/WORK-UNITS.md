# WORK-UNITS — 작업 단위와 의존 그래프

> **일정(주차)으로 표현하지 않는다.** AI가 개발하므로 사람 기준의 소요 시간 산정은 의미가 없고, 지배 변수는 시간이 아니라 **의존과 게이트**다.
> 진행은 "몇 주차"가 아니라 **"어떤 작업 단위가 닫혔는가"**로 센다.

---

## 1. 작업 단위(WU)의 정의

**한 에이전트 세션이 계약 동결 → 구현 → 게이트 green까지 통째로 닫을 수 있는 최소 단위.**

WU 하나는 반드시 아래 넷을 가진다. 넷이 다 없으면 WU가 아니라 할 일 목록이다.

| 항목 | 뜻 |
|---|---|
| **진입조건** | 이것이 없으면 시작해도 헛일이 되는 선행 산출물 |
| **산출물** | 파일·커밋·결정 기록 중 무엇이 남는가 |
| **완료 판정(오라클)** | 사람 의견이 아니라 **기계가 green/red를 말하는 것**. 없으면 WU를 더 쪼갠다 |
| **병렬성** | 어떤 WU와 동시에 돌 수 있는가 |

WU가 한 컨텍스트에 안 들어가면 쪼갠다. 쪼갤 수 없으면 그건 도메인 경계가 잘못 그어진 것이다(→ `DOMAINS.md`).

**v2는 전체가 끝나야 한다.** 일부 화면만 나온 상태, 로컬에서만 도는 상태, AI 두 지점이 빠진 상태는 전부 미완이다.

| 2 | **화면 전부** — S-01 연구실 · S-02/S-02b 프로젝트 · S-03 카탈로그 · S-04 업로드 모달 · S-05 데이터셋 상세 3섹션 · S-06 검색 결과 · S-08 미등록 미리보기 · `연구실 설정 > 구성원·권한` | 목업 대비 검증 |

### 범위 밖 (정본이 이미 뺀 것)

아래는 **미완이 아니다.** 260818 정본이 1차 범위에서 명시적으로 제외했다.

- **P1 계정과 연구실 소속** (A-01~A-06) — 에픽 자체 보류
- **백로그 B-01~B-09** — 데이터·사이트 추천 / 플로팅 검색 / 활용 역할 태그 / 계보 그래프 한계선 / 연구실 밖 검색 / 보조입력 부모 표기 등
- **대화 입구 · 의도 라우터 · 협업 프로젝트** — v3 영역

> 이 경계가 흔들리면 "전체 완료"가 정의되지 않는다. 범위를 늘리려면 정본을 먼저 고치고, 그 다음에 WU를 추가한다.

### 유예 금지 규칙

- WU는 **부분 완료로 닫지 않는다.** 오라클이 green이 아니면 `🟧 부분(사유)` 로 남긴다
- 차단이 생기면 **차단 해제 자체를 WU로 만든다.** "나중에"는 상태가 아니다
- 각 WU의 완료 판정에 **staging 배포 green이 포함된다**(I2 이후)

```

T-G  게이트   사람 결정 · 기획 패키지 재빌드     ─┼─ 서로 병렬, 지금 착수 가능
T-I  인프라   AWS 계정 · IaC · 배포 경로        ─┘
                        │
                        ▼
T-D  도메인   경계 확정 · 계약 동결 · 게이트 구축
                        │
        ┌───────────────┴───────────────┐
        ▼                               ▼
T-P  플랫폼   D1~D8 구현              T-K  지식·AI   D9·D10 구현
      (에픽 0~7단계)                       (온톨로지 → KG → 두 지점)
        └───────────────┬───────────────┘
                        ▼
              T-I 계속 (모든 WU가 배포까지 포함)
```

- **T-P와 T-K는 계약 동결 후 완전 병렬.** 만나는 지점은 두 곳뿐 — E-04 계보 제안, E-02 검색.
- **T-I는 처음부터 끝까지 흐른다.** 배포는 마지막 단계가 아니라 P0 직후부터 모든 WU의 완료 조건이다.
- **감사 트랙이 없다.** 코드 기반 결정이 "신규 구축"으로 닫혀(PLAN-SoT §9-①) Launch 코드 감사가 불필요해졌다. 그 자리를 **지식 추출(C3·C4)**이 대신한다.

| **D2b** | **이벤트 계약 게이트** — `contracts/events/**` 는 지금 **어떤 게이트도 보지 않는다.** `contract-lint`(spectral)는 `contracts/seams/**` 만 훑고, `contract-breaking`(oasdiff)은 OpenAPI 전용이라 이벤트의 파괴적 변경을 아무도 못 잡는다. 필요한 것 = `event-lint`(ajv 로 스키마 유효성 + 인스턴스 fixture) · `$defs` 단위 diff 규칙 · red fixture selftest | D2 | 게이트 self-test green + 이벤트 계약 변경이 실제로 red 를 냄 |
| **D3** | 경계 강제 장치 — import-linter 계약, banned-import(geo), **D10→D4 쓰기 금지 음성 테스트**, RLS 커버리지 게이트, 스키마 diff, alembic single-head | D2 | 게이트 self-test 전부 fail-closed 증명 |

> **D3이 이 프로젝트의 보험이다.** v1에서 실제로 터진 버그 — ID 타입 드리프트, FE-BE 타입 수동 동기화, 스코프 누락 노출 — 는 전부 "관례로 지키기로 했던 것"이었다.
