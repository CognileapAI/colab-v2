## 총괄·실행·검토 운영 — 사용자 합의 2026-09-12

- 사용자 확인 원문: “그래 그렇게해보자”. 확인 대상은 총괄 유지 → intent 확정 → 자료 조사 위임 → 결과를 받아 골든셋 범위 결정의 운영 제안이다.
- 현재 작업은 총괄로 유지한다. 사용자와 목적·범위를 결정하고, 산출물을 수용하며, 이 계획의 현재 위치와 다음 행동을 갱신한다.
- 실행은 독립적으로 완료·검증할 산출물 단위로 위임한다. 7단계마다 새 작업을 일괄 생성하지 않는다. 사용자가 직접 이어갈 별도 작업 생성은 명시 요청 시 수행한다.
- intent 논의는 여기서 진행한다. 자료 조사는 필요한 범위를 지정해 위임하고 이미 확인한 사실은 재조사하지 않는다.
- 주요 사양·실험 결론·구현 산출물은 별도 검토자가 근거와 누락을 확인한다. 작은 기록 수정에는 검토자를 상시 투입하지 않는다.
- 역할 모델은 현행 프로젝트 설정을 따른다: 총괄·검토 Astra, 조사·구현 Sol. 독립적인 작업만 병렬로 수행하고 쓰기 작업은 작업 사본을 격리한다.
- 위임 입력은 목표 1개, 출처·기준 버전, 수정 소유 범위·범위 밖, 완료 검사, 결과 기록 위치를 포함한다.
- 회수 항목은 산출물 경로, 실제 검증 결과, 미결 사항, 다음 행동이다. 총괄이 근거를 대조한 뒤 상태를 갱신한다.
- 이 운영 합의는 미응답 제품 정책·intent·사양이나 커밋·배포 승인을 대신하지 않는다.
