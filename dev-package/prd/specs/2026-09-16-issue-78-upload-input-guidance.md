# #78 입력 안내·필수 조건 정렬

Intent: `dev-package/intent/2026-09-16-issue-78-upload-input-guidance.md` (승인).

## 동작 계약
- 신규 DatasetCreate에 observationInterval 숫자/단위가 필요하다. 기존 양수·단위 유효성 검사를 재사용한다.
- 등록 가공 단계가 Lv0이면 trim 후 빈 sourceUrl/sourceDownloadedOn을 거절한다. 날짜의 기존 형식 검증을 유지한다.
- 비Lv0에서 출처는 선택이고 숨은 값은 기존처럼 전송하지 않는다. Dataset PATCH와 기존 저장 데이터는 새 필수 조건의 대상이 아니다.
- 프런트 누락 검사는 API 호출 전에 해당 단계와 입력칸으로 이동하며 토스트/인라인 안내를 제공한다. 서버 우회 요청도 저장 이전에 거절한다.

## 화면 문면
- 분류 부제: `어떤 자료인지 고르고, 가공 단계에 맞는 데이터를 연결해요.`
- 메타데이터 부제: `확장자·용량을 확인하고 아래 정보를 입력해 주세요.`
- 자동 정보 제목: `파일 정보`; `사람이 적어요` 제목 제거.
- 기간 도움말: `자료가 다루는 시작과 종료 시점이에요. 한 시점이면 종료는 비워 두세요.`
- 관측 간격: 필수 배지, 예시 `예: 10`, 도움말 `숫자를 입력하고 단위를 선택해주세요`. 누락 또는 반쪽이면 오류로도 안내.
- 좌표계 예시 `예: EPSG:5179`.
- 변수 예시: 이름 `예: tp`, 단위 `mm`, 범위 `0 ~ 240`, 결측률 `2.4 %`. 변수 선택 입력 유지.
- 대표 변수 도움말: `변수마다 단위·값 범위·결측률을 적고, 자료를 대표할 변수 하나를 골라요.`
- 원천 도움말: `연구실의 가공 전 데이터는 위에서 연결하고, 연구실 밖 출처는 아래에 적어요.`
- Lv0 출처 주소·날짜에 필수 배지. 비Lv0 출처 주소 및 출처 이름은 선택 배지. 기존 노출 조건 유지.
- 세 단계 순서·입력칸 폭·기존 레이아웃 유지. #77과 겹치는 제목 제거는 #78 안내 개선에 포함하지만 이슈 자동 종결은 별도.

## 수용과 검증
- 필수 누락·null·빈값·공백·반쪽 값/단위는 서버 시험으로 거절을 확인한다. 정상 및 비Lv0 선택 출처, 기존 PATCH 회귀를 확인한다.
- 프런트 시험에서 누락 시 요청0회·단계 이동·초점/안내 및 정상 제출 payload를 검증한다.
- 실제 브라우저: #79 선택 부재, 등록 진입 후 기간/설명 등 입력, 관측 간격 누락→메타데이터 이동, Lv0 출처 누락→연결 이동, 정상 보완→등록→재조회 확인.
- 타입·전체 프런트·core-api 관련 게이트·계약 lint/생성타입 정합·실화면 검사. 선언 대상과 실행 계수를 남긴다.
