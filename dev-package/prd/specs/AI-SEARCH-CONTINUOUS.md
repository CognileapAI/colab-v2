# 지속 갱신과 검색 연결

출처: 사용자 “한건한건 멈추지말고 전체 계획을 말하고 실행을 해라”; 기존 AI 검색 intent와 AI-SEARCH-TOOLS 사양의 후속.

## 목표와 범위

개념 내용 조회, Sonnet 제안 실행, 일일 증분 처리/재시도/상태, 현재 근거의 검색 연결을 하나의 실행 범위로 개발한다. 단계 완료 후 다음 실행 가능한 단계로 계속한다. 실제 모델 평가 보류는 유지한다. 실제 배포/운영 스케줄 활성화는 이 로컬 개발 완료 주장에 포함하지 않는다.

- 매일 공통 D9 사전의 내용 버전을 한 번 수신한다. 제품 원본 전체를 매번 다시 읽지 않고 변경 원장과 무효화된 의존만 처리한다.
- D9는 읽기 전용. 신규 개념/관계 자동 확정이나 원본 삭제 권한을 모델에 주지 않는다. 이 범위의 자동 갱신은 D3의 출처 있는 파생 KG다.
- 개념 조회는 버전 고정, 입력/출력 상한, 1홉이며 내용 해시를 검증한다. 전체 제품 본문/파일 경로/SQL을 모델 도구에 노출하지 않는다.
- Sonnet은 제공된 개념 후보와 자료 속 인용을 선택한다. 임의 사실·순위·데이터셋 ID·DDL은 받지 않는다. 모델 출력은 서버에서 형태·허용 후보·출처 인용을 검증한다.
- 일일 실행은 신뢰된 설정에서 주체를 도출하고 연구실/본문 권한을 유지한다. 작업 lease, 제한된 재시도, 실행 한도, 중복 실행 방지와 상태 기록을 제공한다.
- 검색 시 원본과 권한 및 온톨로지 의존이 유효한 파생 연결만 사용한다. 기존 낱말/사전 검색은 유지한다. 모델 장애는 빈 검색 성공이나 사실 승격으로 처리하지 않는다.
- 실제 Sonnet 품질, 운영 배포, 일일 운영 실측은 미실행을 명시하고 K4 전체 완료로 과장하지 않는다.

## 수용 기준

1. 인증 실패/구버전/잘못된 해시/상한 초과를 거부하는 개념 HTTP 생산자와 소비자.
2. 도구의 읽기 증거와 모델 제안을 재검증하고 사실·의존·연결·ack를 원자적으로 저장.
3. 중복 실행/실패 재시도/무변경 재실행/자료 변경·삭제·권한 회수 음성 검사.
4. 실제 검색 라우트에서 현행 연결만 사용하고 모델 임의 순위·비공개 인용이 노출되지 않음.
5. 고정된 로컬 골든 회귀, 서비스 회귀와 변경 관련 계약/생성물/경계/마이그레이션 검사. 실제 모델 호출을 대체한 시험은 별도로 명시.
