## 6. 구현 결정

### ㉮ 대표 제목 규약

- 규약 = 화면당 `h1` **1개**(그 화면의 이름) · 탭 본체·카드 머리 제목은 `h2` · 그 아래 구역이 `h3`. 대화상자 안 제목은 대화상자 기준으로 세고 화면 단계에 포함하지 않는다.
- 규약 문서 자리 = **`frontend/README.md` `## 규칙`** 절에 한 줄. 별도 design-system 문서는 레포에 없다(§4-3 계수).
- 이번 회차 집행 범위 = **`/lab-settings` 한 화면**(카드 ⑦ 권고 = 규약 ⓑ ＋ 집행 ⓐ). `/lab` 등 나머지 화면은 후속 항목.
- 글자 크기 = 단계 변경(h3 → h2)이 시각 크기를 바꾸지 않도록 `members.css`·`lab` 계열 CSS 에서 해당 제목 크기를 고정한다. 판정은 CSS 원문 계측(주석 제거 후)로 한다.

### ㉯ 비활성 계정 상태 전달 경로 (ⓐ-1 = D1 투영)

- 제약 = 도메인은 자기 테이블 ＋ D1 만 참조한다(`CLAUDE.md §3` 규칙 1) · 생성물 손수정 금지(규칙 7). 상태 원본은 앱 롤 접근이 차단된 `account_admin.login_credential` 이다(§4-3).
- 결정 = 앱 롤이 `account_admin` 을 직접 읽지 않는다. core-api 가 **D1 투영**으로 상태를 얻어 응답에 싣는다 — 구성원 라우트가 계정 상태 조회 경로(`services/core-api/src/colab_core/kernel/db_credentials.py` 의 상태 조회 재사용 또는 Port 1개)를 거친다.
- 계약 = `contracts/seams/fe-core.yaml` 앵커 `LabMember:` 에 **선택 열쇠 1개** 추가 — `accountStatus: active|inactive`. `required` 에 넣지 않는다(넣으면 기존 소비자·시험 파괴).
- 생성물 = 계약 변경 뒤 타입·클라이언트를 **재생성**한다(`frontend` `npm run generate`). 손수정 0. 게이트 `generated-up-to-date`·`contract-lint`·`contract-breaking` 이 판정.
- 화면 = 상태 칩 ＋ 그 행의 편집 잠금. 화면 단독 판정은 두지 않는다 — `editablePermissions` 배열만 읽는 기존 규칙(`permissions.ts` 앵커 `export function isEditable(`)을 유지하고, **서버가 비활성 행의 `editablePermissions` 를 빈 배열로 내린다**. 저장 경로에도 상태 검사를 둔다(화면만 막으면 요청으로 우회된다).
- 마이그레이션 = **0건**. `d1_account` 에 상태 열을 신설하지 않는다 — 투영은 조회 시점에 한다. ⚠ 투영 구현에 롤 권한 한 칸이 필요한지 `[미확인]` — 해소 = `db_credentials.py` 의 현 조회가 쓰는 롤과 `GET /lab/members` 의 `scoped_db` 롤 대조 ＋ `ops/account-admin-role.sql` 적용 상태 확인(선례 실패 이력 `PLAN-SoT` 앵커 `〈384〉` ⑨ⓐ).

### ㉰ 검색 범위 정합

- 결정 = `searched_count` 를 **결과와 같은 유효 스코프**에서 계산한다. 두 갈래 중 하나 — ㈎ 계산을 `with read_only_scope(...)` 블록 **안(또는 뒤)** 으로 옮긴다 ㈏ 세기용으로 읽기 전용 스코프를 한 번 더 연다. ㈎ 를 기본으로 하고 `isDataQuery` 가 거짓인 갈래에서도 값이 채워지도록 순서를 정리한다.
- 범위 줄 = `labName` 이 **유효 연구실 집합**을 말한다 — 운영자는 「전체 연구실 (읽기 전용)」, 일반 구성원은 소속 연구실 이름. 문면만 바뀌므로 계약 무변경(§4-7).
- `labId` = 필수 `Ulid` 로 **남는다**. 운영자 응답에서도 소속 연구실 id 가 실리고 `labName` 만 집합을 말한다 — 의미 불일치를 스펙에 명시하고 열쇠 신설(`scopeKind` 류)은 이번 범위 밖(`additionalProperties: false` 때문에 계약 개정이 필요).
- 화면 = 문장 구조 무변(`{labName} 데이터 {searchedCount}건을 뒤졌어요.`). 운영자 문면이 상단 칩과 같은 말이 된다.

### ㉱ 가공 단계 기본값

- 결정 = 확인된 부모가 **1건 이상이고 부모 Lv 를 모두 아는 경우** 기본 선택값 = 계산값(주입력 부모 중 최대 Lv ＋ 1).
- 부모 **0건**이면 기본값은 `Lv2` 로 **유지**하고 Lv0 경고를 세우지 않는다 — `derivedPreview` 를 0 으로 바꾸지 않는다(카드 ⑩ 권고가 ⑷′ 를 ⑵ 와 같은 판정으로 묶었고, 권고 ⓐ 는 기본값만 이번 회차다).
- 부모 Lv 를 하나라도 모르면 기본값은 `Lv2` 유지(현 미리보기 규칙 승계).
- 사람이 고른 값은 덮어쓰지 않는다 — 사용자가 한 번 고른 뒤 부모가 바뀌면 기본값 추종을 멈춘다(고른 값이 사라지면 선택 칸이 무의미해진다 · 미결-2 ⓐ 근거문과 같은 이유).
- 차단 0건 · 사유 입력 요구 0건 · 「경고만」 유지.
