# 디자인 누락 복구

사용자 승인: 2026-09-12 전체 디자인 검수 후 “그래 작업하자”.
근거: dev-package/sessions/design-review-20260912.md 및 보고서 findings.md.

기존 제품 기능·상태 판정·문구는 유지한다. 필터와 버튼의 글꼴·크기·여백, 모바일 넘침,
설정 화면과 모달 여백, 누락된 승인/지도 상태 스타일, 읽기용 작은 글자, 모달 키보드 동작을 수정한다.
카탈로그 잠긴 행도 키보드로 기존 상세에 진입할 수 있어야 한다.

375/768/1440px에서 화면 가로 넘침이 없어야 한다(표 내부 스크롤은 허용).
모달은 포커스 순환·Escape·복귀를 지원하고 처리 중 닫기를 막는다.
현재 소스 fixture 시각 검증과 실제 서비스 데이터 검증을 구분한다.
전역 CSS 소유권 재편(D17)은 제외한다. 승인 대기 취소선·비활성 상태는 유지한다.
배포·push·제품 데이터 변경은 이 작업의 범위가 아니다.
