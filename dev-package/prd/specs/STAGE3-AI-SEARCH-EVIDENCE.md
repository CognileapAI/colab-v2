# AI 검색 근거 연결 — 로컬 구현 범위

출처: 승인 intent `dev-package/intent/2026-09-12-ai-search.md` 및 사용자 “계획 리스트업하고 전부 실행하라”. 기존 LLM 평가 보류는 유지한다.

## 요구 동작

1. 실험은 고정9묶음/108파일과 출처 있는 수동 주석을 사용한다. 주석은 실제 파일이 현재 입력에 존재할 때만 적용한다. 다른 연구실·없는 파일의 사실을 주입하지 않는다.
2. 파일 역할은 모델 부모 관계로 추정하지 않는다. hsr/rn15, 예측장, DEM/Aspect/LULC/HLS, SPI/SPEI를 근거 표로 구분한다. 특정 파일 제외 요청은 선택 파일에 적용한다.
3. 기간·지역·품질·직접 관측의 근거 없음과 불일치를 혼동하지 않는다. 파일명 날짜 일치는 내용 전체의 연속기간 보증이 아니다. 가뭄 서술 끝과 실제 날짜 열의 차이를 보존한다.
4. 제품은 기존 `POST /dataset-searches`와 한 줄 `rationale`를 유지한다. 질문에서 요구했지만 확인하지 못한 기간·지역·품질·직접 관측·파일 역할을 구체적으로 알린다. 새 점수·확신도·응답 필드는 추가하지 않는다.
5. 제품 후보·순위·권한·Verified·이어보기·503/저하 동작은 현행 계약을 따른다. 실험용9묶음 주석을 제품 사실로 하드코딩하지 않는다.
6. 파일 역할 구조화 검색의 제품 투입은 근거 수집·갱신·권한 검증이 필요한 별도 단위다. 이번 최소 제품 연결이 이를 대체하거나 전체 검색 품질을 충족했다고 선언하지 않는다.

## 검증

- 역할·파일 부재·날짜 불일치·질문 조건 설명 시험, 기존 검색 회귀, 고정18질문 실험.
- 독립 새 질문은 코드 고정 후 공개해 최초 결과를 남긴다. 실패를 사유 없이 제외하지 않는다.
- 기존 A층 실행을 시도하고 실제 환경 부재는 준비 실패로 남긴다. 기존 기대값/기준선 변경 금지.
- 실제 화면 검증은 가용 환경에 한하며 로컬 미배포 변경을 원격 화면에서 검증했다고 하지 않는다.
- 배포/메인 반영/LLM 평가의 미수행을 별도 표시한다.

## 실측으로 확인한 추가 제품 수리

영문 기술명 뒤 조사를 정규화하되 일반 한국어를 자르지 않는다. 실제 파일명 확장자는 질의와 토큰 양쪽에서 주제 오인의 원인이 되므로 사전 판정에서 구분한다. 단독 포맷명 검색과 원 검색어는 유지한다. 실제 LiteralInterpreter+사전+검색 서비스 연결 시험으로 확인한다.
