# poc-deploy — 철거된 PoC 배포의 설정 스냅샷

2026-08-22 PoC 스택을 철거하기 직전에 뜬 설정 사본이다. `DEPLOY-CURRENT.md` 의 서술을 뒷받침하는 원자료이며,
v2 staging을 **같은 Cloudflare 터널에 붙일 때** 참고하려고 남겼다.

| 파일 | 무엇인가 |
|---|---|
| `compose-resolved.yml` | 실제로 돌던 compose 프로젝트 `colab-poc` 의 전개본(변수 치환 후). 컨테이너 구성·포트·의존 관계·볼륨 마운트의 사실 기록 |
| `nginx.conf` | 컨테이너 nginx의 실효 설정. `/api/`·`/viz/`·`/colab-data/`(MinIO presigned 프록시) 라우팅과 그 주변 주석 |

## 비밀값

두 파일 모두 **비밀값을 `<REDACTED>` 로 마스킹**했다. 원본 전개본에는 DB·Redis 접속 URL과 Cloudflare 터널 토큰이
평문으로 들어 있었고, 복사 시점에 마스킹했다. 살아 있는 시크릿은 이 폴더에 없다.

## 참조용 기록이지 계승 대상이 아니다

`CLAUDE.md §5` — 참조는 **지식**이지 코드가 아니다. 여기 있는 설정을 v2로 복사해 오지 않는다.
v2의 인프라 정의는 v2 기준으로 새로 쓰고, 이 폴더는 "PoC는 이렇게 되어 있었다"를 확인하는 용도로만 읽는다.

## 여기 없는 것

철거 시 함께 뜬 스냅샷 중 **PoC 스키마 덤프 · MinIO 버킷 목록 · crontab** 은 의도적으로 넣지 않았다.

- **스키마 덤프** — v1/PoC 스키마는 WU-G5에서 이미 `DATAMODEL-BASELINE.md` 기준표로 증류됐다.
  두 번째 사본을 레포에 두면 `CLAUDE.md §5` 가 금지하는 스키마 계승을 부른다.
- **버킷 목록 · crontab** — 한 줄 사실이라 `DEPLOY-CURRENT.md` 본문에 녹였다.

셋 다 세션 스크래치패드에만 있고 **세션 종료와 함께 소멸한다.** 다시 필요하면 이 문서의 서술로 재구성한다.
