- 잠긴 데이터셋 · 접근 요청 화면 · 거절 사유 입력 = 잠긴 대상 0건 · 쓰기 금지
- 업로드 3단계 표시기 · AI 계보 제안 카드 · 등록 결정 게이트 · 미등록 파일 미리보기(S-08) = 파일 투입이 쓰기 행위
- 역할별 홈 4종(교수 · 기본 연구원 · 위임 연구원 · 빈 연구실) = 로그인 가능한 계정이 `admin` 하나
- 권한 없음 상태의 버튼 숨김 = 같은 사유
