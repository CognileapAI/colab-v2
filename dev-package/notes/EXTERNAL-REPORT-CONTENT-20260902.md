## 1. 제품과 단계 구조

### 제품 한 줄 정의

- **수문학 연구 데이터 협업 플랫폼** — 연구실이 관측·모의 데이터를 등록하고, 찾고, 미리 보고, 계보(어느 원자료에서 어떻게 나왔는지)를 남기고, 연구실 간 접근을 승인으로 주고받는 웹 서비스
- 구축 방식 — 신규 구축(선행 시제품 코드 미계승, 도메인 지식·방법론만 참조), 클라우드 배포까지 포함
- 기능 영역 열 개 — 이용자·연구실 / 접근 권한 / 데이터 목록 / 계보 / 접수·처리 / 프로젝트 / 시각화 / 지표 / 온톨로지 / AI 보조

### 단계 구조

| 단계 | 목적 | 상태 |
|---|---|---|
| **1단계** | 기반 골격 — 규격 확정, 데이터 등록·미리보기·목록·프로젝트 화면의 최소 동작, 시험 환경 구성, 초기 데이터 적재 | 43항목 중 40 완료 |
| **2단계** | 실사용 가능한 제품 — 접근 승인, 연구실 대시보드, 계보 그래프·시각화, 원본 내려받기, 백업·복원, 시험 환경 배포 자동화 | 34항목 중 23 완료 |
| **3단계** | 확장 — 자연어·AI 검색 화면, AI 계보 제안, 데이터 가공, 선행 자산 정리 | 15항목 전건 미착수 |

- 진행은 주차 일정이 아니라 **작업 단위**로 계수
- 단계 밖으로 뺀 항목 5건 별도(운영 환경 전환·상용 인프라 등, 현 범위 밖)

## 5. 이번 주 진행 (2026-09-01 ~ 09-02)

- **승인 처리 시험 환경 반영** — 연구실 간 접근 요청과 검증 요청의 신청·목록·승인·거절이 배포된 환경에서 실제로 동작. 승인 권한은 기획대로 분리(접근 승인은 교수와 위임받은 연구원, 검증 승인은 교수 전용)
- **미리보기 자동 갱신** — 원본이 바뀌면 미리보기를 다시 만들도록 무효화 경로 연결
- **산출물 소유 판정과 회수 안전장치** — 저장 자리에 쌓인 미리보기 산출물의 주인을 가려 네 등급으로 판정하고, 회수 전 전수 기록을 남기도록 자동 검사 신설. 판정 실행에서 삭제 0건
- **연구실 대시보드** — 지표·데이터 지도·할 일·최근 활동 네 구획. 최근 활동이 실제로 쌓이도록 등록·계보 확정·검증 승인·프로젝트 생성/삭제 다섯 지점에 기록 추가. 다른 연구실 값이 숫자 안에도 새지 않음을 시험으로 확인
- **파일 형식 지원 확대** — 처리 가능 형식 4종 → 6종. 「지원 목록 밖」이라는 잘못된 안내 문구를 정정(실제 원인은 구현 결함)
- **원본 내려받기 개방** — 등록 데이터의 파일 저장처를 확정하고 내려받기 경로를 염. 미구현 응답 5건 → 4건
- **등록 화면 입력 칸 확장** — 등록 요청에서 서버가 받는 항목 7개 → 10개, 화면에 세 칸 개방
