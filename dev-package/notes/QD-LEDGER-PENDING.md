## 4. 곁가지 — 픽스처가 실서버와 어긋나 있었다

`detail/fixture.ts` 의 `NO_ACTIONS` 는 **열린 데이터에도 `canDownload: false`** 였다.
서버 축자는 `"canDownload": body_accessible` 이다. 상세에 다운로드 진입점이 **없던 동안에는
아무도 이 차이를 볼 수 없었다** — `canRequestAccess` 에서 이미 한 번 났던 어긋남과 같은 모양이다.
열린 데이터 자리를 `OPEN_ACTIONS` 로 바꾸고, **`canDownload === bodyAccessible` 을 시험이 전건 대조**한다.
