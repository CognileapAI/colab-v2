## 보강 문항의 공통 기준

- 002~012의 후보 범위는 dev 스냅샷의 LD 접두 **9개 묶음**이다. 실제 dev 전체 25건을 검색한 결과에 이 제한 범위의 ‘없음’ 기대를 그대로 적용하지 않는다.
- 정답은 파일을 포함하는 데이터셋을 추천하는 것이다. 파일명은 근거 대상이며 파일 검색 UI 신설 요구가 아니다.
- 모든 문항은 독립 질문이다. ‘이 자료’ 같은 대화 문맥이나 채팅형 UI를 전제하지 않는다.
- 결과 앞에 실제 검색 범위를 고지한다. 문항별 기대 설명을 결과 근거 한 줄에 담되 문장의 축자 일치는 평가하지 않는다.
- 필수 정답은 빠짐없이 포함해야 한다. 다른 후보를 함께 내면 관련성이 있어야 하며 주 정답과 역할을 구분한다. 잘못된 후보를 조건 충족 자료로 제시하면 실패다.
- ‘확인 불가’ 문항은 빈 결과만으로 충분하지 않다. 확인할 수 없는 조건을 명시하고 관련 후보를 내더라도 그 조건을 충족한다고 단정하지 않는다.
- 모델·실행 버전·전체 후보 고정은 실행 전 필요하다. 현재 제품이 이 기준을 충족한다고 주장하지 않는다.
- 권한 거부·장애 문항은 실제 격리 계정과 장애 시험 조건을 마련한 뒤 별도로 추가한다. 이번 문서에서 실행되지 않은 권한 시험을 만든 것으로 세지 않는다.

- 기대 응답: “확인한 9개 자료 묶음에는 U-Net 가뭄지수 예측 자료가 없어요. 가뭄 자료는 SPI·SPEI 지수이고, U-Net 결과는 강우와 식생 자료입니다.”
- 근거: 9묶음의 전체 파일·설명·계보에 해당 가뭄 예측장이 없음.
- 오답: 강우/식생 예측장을 가뭄 예측으로 제시, 이 제한 범위를 넘어 전 세계·전체 제품에 없다고 단정.

## SEARCH-GOLD-011 — 근거가 부족한 품질 조건

## SEARCH-GOLD-012 — 해상도 조건의 잘못된 전제

**질문:** 100m로 직접 관측한 천리안 월평균 NDVI 자료 찾아줘.
