## 결론: 합격선을 아무도 선언하지 않으면 이 검사는 사실상 아무것도 보장하지 않는다

**① 합격선이 1로 떨어진다 (`check-coverage.sh:5`)**
- `MIN_CASES="${COLAB_MIN_CASES:-1}"`는 `COLAB_MIN_CASES`가 선언되지 않았거나 비어 있으면 `1`을 쓴다.
- 그래서 검사는 "회귀 시험이 필요한 만큼 있는가"가 아니라 "`case ` 로 시작하는 줄이 한 줄이라도 있는가"로 바뀐다.
- 두 변수를 모두 지우고 실행하면 `check-coverage green — 시험 2건 (최소 1 · 상한 9999s)`, exit 0이 나온다. 합격선을 정한 사람이 없는데 green이 나온다.

**② 시험이 0건이어도 통과한다 (`check-coverage.sh:8`, `:10`)**
- `grep -c`는 일치하는 줄이 없으면 `0`을 출력하고 exit 1로 끝난다. 그러면 `|| echo 0`이 한 번 더 실행돼 `N`에 `"0\n0"`이 들어간다.
- 10행의 `[ "$N" -lt ... ]`는 정수가 아니라서 `integer expression expected` 오류를 낸다. `if`는 이 오류를 거짓으로 처리하므로 15행으로 넘어가 green이 나온다.
- 임시 디렉터리에 빈 `cases.txt`를 두고 실행한 결과: `green — 시험 0\n0건`, exit 0.
- `cases.txt`가 아예 없을 때만 grep이 아무것도 출력하지 않아 `N=0`이 되고 red가 나온다.

**③ 부수 사항 (`check-coverage.sh:6`)**
- `TIMEOUT_S`도 `9999`로 관대하게 떨어진다.
- 이 값은 어디서도 강제하지 않는데 green 메시지에 `상한 9999s`로 찍힌다. 검사하지 않은 제한을 보장하는 것처럼 보이게 한다.

**그래서 무언 환경에서 보장되는 것**은 "`cases.txt` 파일이 있다" 하나뿐이다. 시험 건수는 0건이어도 통과한다.

## 고칠 방향 (세 상태)

```bash
if [ ! -f cases.txt ]; then echo "::error::cases.txt 없음"; exit 1; fi
N="$(grep -c '^case ' cases.txt || true)"          # 0건이면 "0" 한 줄만

if [ -n "${COLAB_MIN_CASES:-}" ]; then              # 상태1
  [[ "$COLAB_MIN_CASES" =~ ^[1-9][0-9]*$ ]] || { echo "::error::COLAB_MIN_CASES 는 양의 정수"; exit 1; }
  [ "$N" -ge "$COLAB_MIN_CASES" ] || { echo "::error::시험 $N 건 < 최소 $COLAB_MIN_CASES 건"; exit 1; }
elif [ "${COLAB_MIN_CASES_WAIVED:-}" = "1" ]; then  # 상태2
  echo "::warning::합격선 면제 — 시험 ${N}건, 최소 건수 검사 안 함"
else                                                 # 상태3
  echo "::error::COLAB_MIN_CASES 미선언 — 선언하거나 COLAB_MIN_CASES_WAIVED=1 로 면제하라"; exit 1
fi
```

- `COLAB_MIN_CASES=0`은 선언처럼 보이지만 실제로는 조용한 면제가 된다. 그래서 막고, 면제는 반드시 상태2의 이름 있는 변수로만 하게 했다.
- `TIMEOUT_S`는 실제로 강제하든지, green 메시지에서 빼든지 둘 중 하나로 정리해야 한다.
- 파일은 고치지 않았다. 위 코드는 제안이다.

- 판정: 결함 있음
- 관대한 기본값: check-coverage.sh:5 · COLAB_MIN_CASES=1
- 상태1 선언: 정수인지 검증하고, `case` 건수가 선언값보다 적으면 exit 1, 이상이면 green
- 상태2 명시 면제: `COLAB_MIN_CASES_WAIVED=1`이면 `::warning::`으로 실제 `case` 건수를 찍고 exit 0
- 상태3 무언: `::error::`로 합격선 미선언을 알리고 exit 1
