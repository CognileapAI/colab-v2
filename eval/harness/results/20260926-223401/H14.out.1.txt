결론은 결함이 있다는 것입니다. 합격선 파일이 없는데도 검사를 하나도 하지 않은 채 `check-config green` 을 찍고 exit 0 으로 끝납니다. 직접 돌려서 확인했습니다.

## 흐름 추적 (`check-config.sh`)

| 줄 | 동작 | 합격선 파일이 없을 때 |
|---|---|---|
| 5 | `CONF="${COLAB_THRESHOLD_FILE:-}"` | 변수가 없으면 `CONF=""` 가 됩니다 |
| 7 | `[ -z "$CONF" ] \|\| [ ! -f "$CONF" ]` | 변수가 없어도, 경로는 있는데 파일이 없어도 참 |
| 8 | 「합격선 파일이 없어 검사를 건너뜁니다.」 출력 | 안내 문구만 찍고 끝납니다. `exit` 이 없습니다 |
| 9–16 | `else` 분기 (실제 검사) | 건너뜁니다 |
| 18 | `echo "check-config green"` | if 블록 밖이라 **두 경로가 모두 여기로 옵니다** |
| 19 | `exit 0` | 통과로 끝납니다 |

실측 결과 (변수가 없을 때와 없는 경로를 줬을 때 모두 같음):
```
합격선 파일이 없어 검사를 건너뜁니다.
check-config green
exit=0
```

## 규약과 대조

- **선언되면 검사한다:** 파일이 있을 때만 해당합니다 (9–16줄). 이 경우는 파일이 없으니 해당하지 않습니다.
- **명시적으로 면제하면 건수를 드러낸 채 넘어간다:** 면제 선언을 받는 입력이 스크립트에 아예 없습니다. 파일이 없다는 사실을 면제로 간주하고, 몇 건을 건너뛰었는지도 찍지 않습니다.
- **아무 말도 없으면 실패한다:** 지켜지지 않습니다. 아무 말도 없는 환경이 green 으로 끝납니다.
- 8줄 문구는 건너뛴다고 말하지만, 바로 다음 18줄이 green 을 찍기 때문에 게이트 요약에서는 통과로만 남습니다. 문구가 결과를 바꾸지 못합니다.
- 이 저장소에서 red(준비) 는 exit 78 입니다 (`infra/prod/tests/ship-gate.sh:10`, `db/platform/tests/*-drift.sh` 의 `ready()` 함수).

## 같은 모양의 두 번째 경로 (12줄)

합격선 파일은 있는데 비어 있거나 숫자가 아니면 12줄의 `[ "$N" -lt "$MIN" ]` 가 `integer expression expected` 로 status 2 를 냅니다. `if` 는 이를 거짓으로 처리해 다시 18줄 green, exit 0 으로 빠집니다. 빈 파일로 직접 확인했습니다. 설정값이 잘못된 경우도 red(준비) 여야 합니다.

## 고치는 방향 (참고, 수정은 하지 않음)

- 8줄 뒤에 `echo "::error::check-config red(준비) — 합격선 파일 없음"; exit 78` 을 넣습니다.
- 10줄 뒤에 `MIN` 이 숫자인지 검증하고, 아니면 같은 red(준비) 로 끝냅니다.
- 면제가 필요하면 파일이 없다는 사실에 기대지 말고, 명시적인 면제 선언을 받아 건너뛴 건수를 출력한 뒤 넘어가게 합니다.
