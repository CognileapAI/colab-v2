스크립트는 고치지 않았습니다. 실제 `curl` 대신 정해 둔 값을 돌려주는 가짜 `curl` 로 다섯 경우를 돌려 보고 답합니다.

## 지금 코드의 갈래 (`gate-render-latency.sh`)

| 줄 | 조건 | 지금 동작 | 문제 |
|---|---|---|---|
| 7–10 | `COLAB_RENDER_URL` 이 비어 있음 | "측정 생략" · exit 0 | 아무 선언이 없는데 통과한다. 명시 면제 갈래는 아예 없어서 면제와 무언이 한 갈래로 합쳐져 있다 |
| 12–16 | URL 은 있는데 응답이 비어 있음 | "측정 생략" · exit 0 | 재겠다고 선언해 놓고 못 잰 경우가 통과한다 |
| 12 | `curl -s` 에 `-f` 가 없음 | 502 같은 HTTP 오류의 본문이 그대로 `P95` 에 들어간다 | 타임아웃도 없어서 응답이 없으면 계속 기다린다 |
| 18 | `P95` 가 숫자가 아님 | `[` 가 오류 코드 2를 돌려주고 조건이 거짓이 되어 23행 green · exit 0 | 실측: `render-latency green — p95 <html>502 Bad Gateway</html>ms` · exit 0 |
| 18–24 | `P95` 가 숫자 | 1200 초과면 red · exit 1, 이하면 green · exit 0 | 이 경우만 제대로 판정한다 |

가짜 `curl` 로 돌린 결과:
- URL 없음 → exit 0
- 응답 없음 → exit 0
- HTML 오류 본문 → exit 0 (green 이라고 출력)
- 1500 → exit 1
- 800 → exit 0

"못 잼"으로 끝나는 세 경우가 모두 exit 0 입니다.

## 세 상태로 다시 세우면

1. **선언** (`COLAB_RENDER_URL` 있음, 면제 없음)
   - `curl -sf --max-time N` 으로 잰 뒤 값이 정수인지 먼저 확인한다.
   - p95 ≤ 1200 → green · exit 0
   - p95 > 1200 → red(판정) · exit 1
   - 응답 없음·HTTP 오류·숫자 아님 → red(준비) · exit 1. 선언은 재겠다는 약속이므로 못 쟀으면 실패다.
2. **명시 면제** (예: `COLAB_RENDER_LATENCY_WAIVE="<사유>"`, 변수 이름은 제안)
   - 재지 않는다.
   - 사유 문자열이 비어 있으면 면제로 인정하지 않고 무언과 똑같이 실패시킨다.
   - 출력은 green 이 아니라 따로 구별되는 한 줄로 낸다: `::warning::render-latency 면제 — 측정 안 함 · 사유: …`. 이렇게 하면 요약에서 "재서 통과"와 "안 재고 통과"가 따로 보인다.
   - exit 0
   - URL 과 면제가 둘 다 있으면 어느 쪽인지 알 수 없으므로 exit 1.
3. **무언** (둘 다 없음)
   - 재지 않고 통과시키지도 않는다.
   - `::error::render-latency — 선언 없음: COLAB_RENDER_URL 을 주거나 COLAB_RENDER_LATENCY_WAIVE 로 사유를 적으시오` 를 내고 exit 1.

- 판정: 결함 있음
- 지금 빠진 갈래: 명시 면제 갈래가 없어 무언(7–10행)이 exit 0 으로 통과하고, 선언했는데 못 잰 경우(12–16행 무응답, 18행 숫자 아님)도 exit 0 이 된다
- 상태1 선언: 재서 정수인지 확인하고 p95≤1200 이면 green, 1200 초과·무응답·숫자 아님이면 red · exit 0 / 1
- 상태2 명시 면제: 재지 않고, green 과 구별되는 면제 표식 줄과 사유(`::warning::`)를 드러내며, 사유가 비면 무언으로 처리 · exit 0
- 상태3 무언: 재지 않고 통과시키지도 않으며, 선언이 없다는 오류와 URL 또는 면제 사유를 넣으라는 안내를 낸다 · exit 1
