## 결론
이 게이트에는 결함이 있습니다. `exit 0`으로 끝나는 길이 네 개인데, 실제로 재서 통과한 경우는 그중 하나뿐입니다. 나머지 셋은 못 잰 것을 green으로 세고 있습니다.

## 지금 있는 갈래 (`gate-render-latency.sh`)

| 줄 | 조건 | 출력 | exit | 판정 |
|---|---|---|---|---|
| 7–10 | `COLAB_RENDER_URL`이 비어 있음 | 「측정 생략」 | 0 | 무언과 면제가 한 갈래로 합쳐져 green이 됨 |
| 12–16 | URL은 있으나 curl 실패, 응답이 비어 있음 | 「측정 생략」 | 0 | 선언했는데 못 잰 것을 통과로 셈 |
| 12 → 18 → 23 | `curl -s`에 `-f`가 없어 HTTP 5xx 본문이 `P95`에 들어감 | `[: integer expression expected` 뒤 「green — p95 `<html>…`ms」 | 0 | 숫자가 아닌 값인데 green. 직접 돌려 확인함 |
| 18–21 | p95 > 1200 | `::error::` red | 1 | 유일한 실제 실패 |
| 23–24 | p95 ≤ 1200 | green | 0 | 유일한 실제 통과 |

빠진 갈래는 세 가지입니다.
- **명시 면제 갈래**: 면제를 선언할 변수가 아예 없어서, 면제하려면 아무것도 설정하지 않는 수밖에 없습니다. 그래서 면제와 무언을 구분할 수 없습니다.
- **무언 → 실패 갈래**: 아무 선언이 없어도 green으로 끝납니다.
- **선언했는데 못 잰 경우 → 실패 갈래**: 응답이 없거나 숫자가 아니어도 green으로 끝납니다.

## 세 상태로 다시 세운 모양
저장소 규약(`gates/README.md`의 `frontend-visual`·`harness-eval` 줄)을 따릅니다. 무언은 red(준비 · 입력미선언 · 78)이고, 면제 값은 `=1` 하나만 인정합니다.

- **상태 1 — 선언** (`COLAB_RENDER_URL`이 있고 면제 변수는 없음)
  - `curl -fsS --max-time N`으로 잽니다.
  - 응답이 `^[0-9]+$`이고 1200 이하이면 green, exit 0입니다.
  - 1200을 넘으면 red(판정), exit 1입니다.
  - curl이 실패하거나, 응답이 비었거나, 숫자가 아니면 red(준비), exit 78입니다. 「측정 생략」으로 넘기지 않습니다.
- **상태 2 — 명시 면제** (`COLAB_RENDER_LATENCY_EXEMPT=1`)
  - 재지 않습니다.
  - `::warning::render-latency skipped — 명시 면제 · 측정 0/1건`을 찍습니다. 「green」이라는 말은 쓰지 않고, 건너뛴 건수가 요약줄에 남게 합니다.
  - exit 0입니다.
  - `true`·`yes` 같은 값은 면제로 치지 않고 무언으로 봅니다.
  - URL과 면제가 함께 있으면 서로 모순이므로 red(준비), exit 78입니다.
- **상태 3 — 무언** (URL도 면제도 없음)
  - 재지도 넘기지도 않습니다.
  - `::error::render-latency red(준비) — 입력미선언: COLAB_RENDER_URL 또는 COLAB_RENDER_LATENCY_EXEMPT=1`을 찍습니다.
  - exit 78입니다.
