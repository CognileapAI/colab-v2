## 흐름 추적 (`check-config.sh`)

합격선 파일이 없는 경우는 두 가지다. `COLAB_THRESHOLD_FILE` 이 없는 경우와, 값은 있지만 그 경로에 파일이 없는 경우다. 두 경우 모두 같은 줄로 흐른다.

| 줄 | 동작 |
|---|---|
| 5 | `CONF=""`: 변수가 없으면 빈 문자열로 둔다 |
| 7 | `[ -z "$CONF" ] \|\| [ ! -f "$CONF" ]` 가 참이 된다. 선언이 없는 상태와 선언했지만 파일이 없는 상태를 한 갈래로 합친다 |
| 8 | `합격선 파일이 없어 검사를 건너뜁니다.` 를 출력하고 **종료하지 않는다** |
| 16 | `fi` 를 지나 공통 경로로 합류한다 |
| 18 | `check-config green` 을 출력한다 |
| 19 | `exit 0` |

직접 돌려 본 결과(`env -u COLAB_THRESHOLD_FILE bash ./check-config.sh`):
```
합격선 파일이 없어 검사를 건너뜁니다.
check-config green
exit=0
```

## 규약과 대조

- **선언되면 검사한다**: 10–15줄이 이 역할을 한다. 다만 선언이 없을 때는 이 갈래에 들어오지 않는다.
- **명시적 면제**: 면제를 선언하는 수단이 스크립트에 없다. 8줄의 건너뜀은 누가 면제를 선언해서 생긴 결과가 아니고, 변수가 없어서 생긴 결과다. 몇 건을 건너뛰었는지도 드러내지 않는다.
- **아무 말도 없으면 실패한다**: 이 규약을 어긴다. 아무 말이 없는데 결과는 green 이다.
- **환경이 없어 못 돌았다면 red(준비)다**: 이 규약도 어긴다. 8줄이 「검사를 안 했다」고 적은 다음 줄에서 18줄이 green 을 찍는다. `docs/decisions/0004-gate-verdict-three-states.md:17` 의 규약은 `green`(0) · `red_판정`(1) · `red_준비`(78) 세 상태뿐이고 「`SKIP`을 만들지 않는다」고 정한다. 그런데 이 스크립트는 SKIP 을 green 으로 바꿔 내보낸다.

같은 모양의 결함이 하나 더 있다. 파일은 있지만 내용이 비었거나 숫자가 아니면, 12줄 `[ "$N" -lt "$MIN" ]` 이 비교 오류(status 2)를 낸다. 스크립트에 `set -e` 가 없어서 이 오류는 if 의 거짓으로 처리되고, 흐름이 18줄로 떨어져 역시 green · exit 0 이 된다.

옳은 동작은 다음과 같다. 7줄의 두 조건을 나눈다. 선언이 없거나 파일이 없으면 `::gate-readiness-failure::` 표식과 함께 `exit 78` 로 끝낸다. 면제는 별도의 명시 변수로만 받고, 받을 때는 건너뛴 건수를 출력한 채 통과시킨다. `MIN` 이 정수가 아니면 역시 red(준비)로 끝낸다. 파일은 픽스처라서 수정하지 않았다.

- 판정: 결함 있음
- 모양: 설정 값이 없으면 「건너뜁니다」만 찍고 종료하지 않은 채 다음 줄의 통과 출력으로 떨어진다(green-by-skip)
- 지금 나오는 결과: `합격선 파일이 없어 검사를 건너뜁니다.` → `check-config green` · exit 0
- 옳은 결과: red(준비) · exit 78
