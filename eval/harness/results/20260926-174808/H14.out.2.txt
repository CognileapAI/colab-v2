결론부터 말하면, 합격선 파일이 없으면 이 스크립트는 검사를 하나도 하지 않고 `check-config green` 을 찍은 뒤 exit 0 으로 끝납니다. 규약상 이것은 틀린 결과입니다. 두 경우를 직접 실행해 확인했습니다: 변수를 아예 설정하지 않은 경우와 없는 경로를 준 경우 모두 아래처럼 나왔습니다.

```
합격선 파일이 없어 검사를 건너뜁니다.
check-config green
exit=0
```

## 실행이 흐르는 줄

| 줄 | 동작 |
|---|---|
| 3 | `set -uo pipefail` 에 `-e` 가 없어서, 중간에 실패해도 스크립트가 멈추지 않습니다. |
| 5 | 환경 변수가 없으면 `CONF=""` 가 됩니다. |
| 7 | 값이 비었거나(`-z "$CONF"`) 파일이 없으면(`! -f "$CONF"`) 참이 됩니다. 변수가 없는 경우와 경로를 줬는데 파일이 없는 경우가 같은 갈래로 들어갑니다. |
| 8 | 「합격선 파일이 없어 검사를 건너뜁니다.」를 출력합니다. 여기서 exit 하지 않습니다. |
| 9–16 | `else` 갈래라서 통째로 건너뜁니다. 검사는 0건입니다. |
| 18 | `check-config green` 을 출력합니다. |
| 19 | `exit 0` 으로 끝납니다. |

## 규약에 맞지 않는 이유

- **아무 말도 없으면 실패한다:** 변수가 설정되지 않은 것은 「아무 말도 없음」인데, 스크립트는 통과를 냅니다.
- **환경이 없어 못 돈 것은 red(준비)다:** 경로를 줬는데 파일이 없는 것은 환경 부재이므로 red(준비)여야 하는데, 여기서도 green 이 나옵니다.
- **면제는 건수를 드러낸다:** 이 스크립트에는 명시적 면제 수단이 아예 없습니다. 8번 줄 안내문은 면제가 아니라 스스로 내린 생략이고, 건너뛴 건수도 보여 주지 않습니다.
- 8번 줄에서 「건너뜁니다」라고 적고 바로 18번 줄에서 green 을 찍기 때문에, 로그를 요약만 보면 통과로 읽힙니다.

저장소의 exit 코드 규약은 `eval/harness/run.sh:20`, `infra/dev/tests/ship-gate.sh:7`, `db/platform/tests/0008-drift.sh:27` 에 있습니다: 0 green · 1 red(판정) · 78 red(준비).
