**스크립트 판독** (`gate-render-latency.sh`)

| 행 | 지금 하는 일 | 상태 판정 |
|---|---|---|
| 5 | `COLAB_RENDER_URL` 하나만 읽는다. 면제 선언용 변수는 없다 | 선언 여부만 본다 |
| 7~10 | URL 이 비면 「측정 생략」 출력 후 `exit 0` | **무언을 통과로 셈** |
| 12~16 | curl 응답이 비면 「측정 생략」 출력 후 `exit 0` | **미측정을 통과로 셈** (URL 은 선언됐는데 잰 값이 없음) |
| 18~21 | p95 > 1200 이면 red `exit 1` | 판정 red |
| 23~24 | 그 외 green `exit 0` | 판정 green |

빠진 갈래 = **명시 면제**. 사람이 「이번엔 재지 않는다」고 말할 자리가 없어, 무언과 면제가 구분되지 않고 둘 다 `exit 0` 으로 합쳐진다. 행 13~16 도 같은 결함이다. URL 을 선언해 놓고 응답이 없으면 그것은 측정 실패이지 생략이 아니다.

**세 상태에서 해야 할 것**

1. **선언** (`COLAB_RENDER_URL` 있음)
   - 잰다. p95 ≤ 1200 → green `exit 0`. p95 > 1200 → red(판정) `exit 1`.
   - 응답 없음·숫자 아님 → **red(준비)** `exit 1`. 행 13~16 의 `exit 0` 을 red 로 바꾼다. 선언한 값으로 잴 수 없는 것은 환경 결함이며 통과가 아니다.
2. **명시 면제** (예: `COLAB_RENDER_LATENCY_SKIP=1` 처럼 사람이 붙인 별도 변수)
   - 잰 것이 없다는 사실을 **출력에 드러낸다**. 「skipped(명시 면제) — 측정값 없음 · 사유·선언자」 한 줄. 요약줄에서 green 과 다른 계수(skipped)로 집계돼야 한다.
   - `exit 0`. 단 「측정 안 함」 표기가 로그와 계수에 남아 「문제 없음」과 섞이지 않게 한다. URL 과 면제가 동시에 있으면 면제가 이기되 두 값이 같이 있음을 함께 찍는다.
3. **무언** (URL 도 없고 면제 선언도 없음)
   - **red(준비)** `exit 1`. 「렌더 URL 미설정 · 면제도 선언되지 않음 — 선언하거나 명시 면제하라」 출력. 지금 행 7~10 의 `exit 0` 이 이 자리다. 게이트 정책(「미구현·미준비 게이트는 red 를 낸다」, v1 의 green-by-skip 재발 방지)과 일치시킨다.

selftest 로 세 상태 각각의 종료 코드를 고정하면 fail-closed 가 증명된다.

- 판정: 결함 있음
- 지금 빠진 갈래: 명시 면제 상태가 없어 「무언」(행 7~10)과 「선언했으나 응답 없음」(행 13~16)이 모두 「측정 생략 · exit 0」으로 통과 처리된다
- 상태1 선언: 실제로 잰다 — p95 ≤ 1200 green, > 1200 red(판정) exit 1, 응답 없음·비숫자는 red(준비) · exit 0 (green) / exit 1 (red)
- 상태2 명시 면제: 재지 않고 「측정값 없음 · 명시 면제 · 사유」를 출력·계수(skipped)로 드러낸다, green 으로 합산하지 않는다 · exit 0
- 상태3 무언: 선언도 면제도 없음을 red(준비)로 알리고 선언 또는 면제를 요구한다 · exit 1
