**결론** — 결함 있음. 이 게이트는 「무언」과 「명시 면제」를 가르지 않고 둘 다 `exit 0` 으로 끝낸다. green-by-skip 정형.

**스크립트 실물** (`gate-render-latency.sh`)

| 행 | 내용 | 갈래 |
|---|---|---|
| 5 | `URL="${COLAB_RENDER_URL:-}"` | 미설정이면 빈 문자열로 관대하게 떨어짐 |
| 7~10 | URL 비어 있으면 「측정 생략」 출력 후 `exit 0` | **무언 → 통과** (결함 ①) |
| 12~16 | curl 실패·빈 응답이면 「측정 생략」 출력 후 `exit 0` | 측정 실패 → 통과 (결함 ②, 같은 모양의 형제) |
| 18~21 | p95 > 1200 이면 red `exit 1` | 선언·측정 성공 시 판정 |
| 23~24 | green `exit 0` | 선언·측정 성공 시 판정 |

**지금 빠진 갈래** — 「명시 면제」 갈래가 없다. 면제를 선언하는 변수가 존재하지 않으므로 사람이 「이번엔 안 잰다」고 말할 자리가 없고, 그 결과 「아무 말도 없음」이 면제와 같은 결과(`exit 0`)로 취급된다. 7행과 13행의 「측정 생략」 둘 다 건너뛴 사실을 종료 코드에 반영하지 않는다.

**세 상태 재설계**

1. **선언** (`COLAB_RENDER_URL` 설정됨) — 실제로 잰다. 12행에서 curl 실패·빈 응답·숫자 아님이면 **red(준비)** 로 `exit 1` 을 내고 「무엇이 없는가(URL·응답)」를 적는다. 응답이 숫자면 1200ms 기준으로 판정 — 초과 `exit 1`, 이하 `exit 0`. 못 잰 것을 「생략」으로 통과시키는 13~16행이 이 상태 안의 두 번째 결함이므로 같이 고친다.
2. **명시 면제** (예: `COLAB_RENDER_LATENCY_SKIP=1` 같은 별도 변수, 값 `1` 만 면제로 인정) — 재지 않고 넘어가되 요약줄에 **「skipped 1 · 측정 0건 · 면제 변수 이름」** 을 드러낸다. 요약 계수에서 green 이 아니라 **skip 으로 집계**되게 하고 `exit 0`. 「green」 문구는 출력하지 않는다.
3. **무언** (URL 도 면제 변수도 없음) — **red(준비)** `exit 1`. 메시지에 「`COLAB_RENDER_URL` 미설정 · 면제하려면 `COLAB_RENDER_LATENCY_SKIP=1`」 을 적어 사람이 어느 쪽인지 선택하게 만든다.

**보강 두 가지**

- 면제 변수는 `${VAR:-1}` 처럼 관대한 기본값을 두지 않는다. 미설정 = 무언.
- selftest 픽스처 셋 — URL 없음·면제 없음 → exit 1 / 면제만 → exit 0 + skip 문구 / URL 있고 응답 없음 → exit 1. 이 셋이 red 로 증명돼야 fail-closed 가 성립한다.

- 판정: 결함 있음
- 지금 빠진 갈래: 명시 면제 갈래가 없고, 무언(7행)과 측정 실패(13행)가 「측정 생략」이라는 이름으로 통과(exit 0)로 합쳐져 있다
- 상태1 선언: 실제 측정 → p95 ≤ 1200 green exit 0 / > 1200 red exit 1 / 응답 없음·비숫자는 red(준비) · exit 1
- 상태2 명시 면제: 측정하지 않고 요약줄에 「skipped 1 · 측정 0건 · 면제 변수명」을 드러내며 green 이 아닌 skip 으로 계수 · exit 0
- 상태3 무언: 「URL 미설정 · 면제 변수명 안내」를 적고 red(준비)로 실패 · exit 1
