**결론** — 합격선 파일이 없으면 검사를 한 건도 하지 않고 `check-config green` · exit 0 을 낸다. green-by-skip 모양이고 결함이다.

**흐름 (`check-config.sh`, 실행 실측)**

- `:5` `CONF` 는 환경변수 `COLAB_THRESHOLD_FILE` 에서 오고 기본값은 빈 문자열.
- `:7` 빈 문자열 → 조건 참 → `:8` 안내 문구 출력. `:10`~`:15` 의 검사 본체(합격선 읽기 · `artifacts/` 계수 · 비교 · `exit 1`)는 전부 건너뛴다.
- `:16` 종료 → `:18` `check-config green` 출력 → `:19` `exit 0`.
- 실측 출력 2줄, 종료 코드 0. 검사 대상 건수 0 · 비교 0회.

**규약 대조**

- 선언되면 검사한다 — 파일이 있을 때만 성립(`:10`~`:15`).
- 명시적 면제 — 없음. 면제 플래그 없이 「부재 = 건너뜀」이 기본값이고, 건너뛴 건수도 드러내지 않는다.
- 아무 말도 없으면 실패 — 위반. 부재가 곧 통과로 떨어진다. `:8` 의 문구는 사람 눈에만 보이고 요약줄·종료 코드는 「green」이라 CI 는 구별 불가.
- SKILL.md §4 첫째 줄 「설정 값이 없으면 조용히 넘어가고 다음 줄에서 통과를 찍는가」 에 정확히 해당. 셋째 줄 「기본값이 관대한 쪽」 도 겹친다(`${…:-}` 가 빈값 → 통과 경로).

**옳은 동작** — `:7` 분기에서 `red(준비)` 로 종료(요약줄에 「합격선 파일 없음 · 검사 0건」을 드러내고 0 이 아닌 종료 코드). 면제는 별도 명시 변수(예 `COLAB_THRESHOLD_SKIP=1`)로만 허용하되 그때도 「건너뜀 N건」을 요약줄에 기재하고 `green` 표기는 쓰지 않는다.

- 판정: 결함 있음
- 모양: 설정 값(합격선 파일) 부재 시 조용히 건너뛰고 다음 줄에서 통과를 찍는 green-by-skip
- 지금 나오는 결과: `check-config green` · exit 0
- 옳은 결과: red(준비) · exit 1
