**결론 — 합격선 변수가 없으면 이 검사는 「`cases.txt` 가 존재하고 `case ` 로 시작하는 줄이 1개 이상」만 보장한다.** 회귀 시험 최소 건수라는 검사 의도는 성립하지 않는다.

**판독**

- `check-coverage.sh:5` — `MIN_CASES="${COLAB_MIN_CASES:-1}"`. `:-` 는 미선언·빈 문자열 둘 다 우변으로 떨어진다. 아무도 선언하지 않으면 합격선 = 1.
- `check-coverage.sh:6` — `TIMEOUT_S="${COLAB_CASE_TIMEOUT:-9999}"`. 같은 형태의 관대한 기본값. 다만 이 값은 출력 문구에만 쓰이고 판정에 관여하지 않는다.
- `check-coverage.sh:8` 은 `case ` 로 시작하는 줄을 세고, `:10` 은 그 수가 합격선 미만일 때만 실패한다. 현재 `cases.txt` 는 2줄이라 어떤 기본값에서도 green 이다.
- 검사가 실패하는 유일한 조건은 「`cases.txt` 부재」다. 실측: 파일 삭제 시 exit 1.

**부수 결함 — 빈 `cases.txt` 는 green 이다.** 실측 결과:

```
check-coverage.sh: line 10: [: 0
0: integer expression expected
check-coverage green — 시험 0
0건 (최소 1 · 상한 9999s)
exit=0
```

원인은 `:8` 의 `grep -c … || echo 0`. `grep -c` 는 0건이어도 stdout 에 `0` 을 찍고 exit 1 을 내므로 `echo 0` 이 한 번 더 붙어 `N` 이 두 줄이 된다. `:10` 의 `[` 는 정수 비교 오류로 exit 2 를 내고, `set -e` 가 없어 if 가 거짓으로 흘러 `:15` green 에 도달한다. 수정은 `N="$(grep -c '^case ' cases.txt 2>/dev/null)"; N="${N:-0}"` 또는 `grep -c … || true` 로 stdout 을 한 줄로 고정.

**고칠 방향 — 세 상태**

- 선언 (`COLAB_MIN_CASES=<양의 정수>`) — 정수인지 검증한 뒤 `N < MIN` 이면 exit 1.
- 명시 면제 (`COLAB_MIN_CASES=skip` 같은 예약어 또는 `COLAB_MIN_CASES_WAIVED=1`) — `::warning::합격선 면제 · 시험 N건` 을 찍고 exit 0. 건수를 숨기지 않는다.
- 무언 (미선언·빈 문자열) — `::error::COLAB_MIN_CASES 미선언` 을 찍고 exit 1. `${COLAB_MIN_CASES:-1}` 대신 `${COLAB_MIN_CASES:?}` 또는 명시 분기.
- `COLAB_CASE_TIMEOUT` 도 판정에 쓰일 예정이라면 같은 세 상태를 적용한다.
