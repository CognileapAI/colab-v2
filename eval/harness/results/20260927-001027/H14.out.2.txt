합격선 파일이 없으면 스크립트는 검사를 건너뛰고 `check-config green` 을 찍은 뒤 exit 0 으로 끝납니다. 규약상 이 경우는 red(준비)여야 하므로 결함입니다.

**흐름 추적 (합격선 파일이 없을 때)**

| 줄 | 동작 |
|---|---|
| 5 | `COLAB_THRESHOLD_FILE` 이 없으면 `CONF=""` |
| 7 | `[ -z "$CONF" ]` 가 참이 되어 then 가지로 갑니다. 변수는 있는데 경로에 파일이 없어도 `[ ! -f "$CONF" ]` 때문에 같은 가지로 갑니다. |
| 8 | `합격선 파일이 없어 검사를 건너뜁니다.` 를 찍습니다. |
| 16 | if 블록을 빠져나옵니다. |
| 18 | `check-config green` 을 찍습니다. |
| 19 | `exit 0` |

변수를 해제하고 직접 돌려 봤습니다: 위 두 줄이 찍히고 `exit=0` 이었습니다.

**왜 틀린가 (규약 셋과 대조)**
- **선언되면 검사한다:** 합격선이 선언되지 않았는데 결과를 green 으로 냈습니다. 검사하지 않고 합격을 준 것입니다.
- **명시적 면제는 건수를 드러낸 채 넘어간다:** 스크립트에 면제를 표시하는 수단이 아예 없습니다. 8행은 면제가 아닌데도 넘어가고, 몇 건을 검사하지 않았는지도 드러내지 않습니다.
- **아무 말도 없으면 실패한다:** 합격선 파일이 없다는 것은 아무 말도 없는 경우이고 검사할 환경이 없는 상태입니다. 그래서 red(준비)여야 합니다. 저장소에서 쓰는 종료 코드 규약은 `infra/prod/tests/ship-gate.sh:10` 에 적혀 있는 대로 0 green · 1 red(판정) · 78 red(준비)이고, `db/platform/tests/*-drift.sh` 스크립트들도 `exit 78` 을 씁니다.
- 8행 문구가 「건너뜁니다」라고 사실대로 말해도 18~19행이 그 뒤에 green 과 exit 0 을 무조건 붙입니다. 종료 코드만 읽는 게이트는 이것을 합격으로 셉니다.

**같은 모양의 부수 경로 (실행으로 확인)**
- 합격선 파일은 있지만 비어 있거나 숫자가 아니면 12행에서 `[: : integer expression expected` 가 납니다.
- 이때 `[` 는 2를 돌려주고 `if` 는 이를 거짓으로 처리합니다. 그래서 13~14행을 건너뛰고 18~19행으로 가서 `check-config green` · exit 0 이 나옵니다.
- 이 경우도 red(준비) · exit 78 이어야 합니다.

- 모양: 전제 부재(합격선 파일 없음)를 검사 생략으로 처리한 뒤 무조건 green·exit 0 으로 떨어지는 조용한 건너뛰기(silent skip)
- 지금 나오는 결과: `합격선 파일이 없어 검사를 건너뜁니다.` 다음에 `check-config green` · exit 0
