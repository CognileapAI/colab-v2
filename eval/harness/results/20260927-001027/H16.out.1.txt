## 판정: 결함 있음

합격선 변수 `COLAB_MIN_CASES` 를 선언하지 않으면 이 검사는 `cases.txt` 에 `case ` 로 시작하는 줄이 1개 이상 있는지만 본다. 그런데 파일이 비어 있으면 그 1건 조건마저 통과로 빠진다. 시험 건수에 대해 사실상 아무것도 보장하지 않는다.

### 줄별 근거 (`check-coverage.sh`)

| 행 | 코드 | 미선언일 때 |
|---|---|---|
| 5 | `MIN_CASES="${COLAB_MIN_CASES:-1}"` | `1` 로 떨어진다. 합격선을 정한 적이 없는데도 "최소 1건" 이 합격선이 된다 |
| 6 | `TIMEOUT_S="${COLAB_CASE_TIMEOUT:-9999}"` | `9999` 로 떨어진다. 15행에서 출력만 하고 어디서도 적용하지 않는다. green 메시지에 "상한 9999s" 가 찍혀 상한을 검사한 것처럼 보인다 |
| 8 | `grep -c ... \|\| echo 0` | 파일이 없으면 `N=0` 이다. 파일이 있는데 일치하는 줄이 없으면 grep 이 `0` 을 출력하고 exit 1 로 끝나서 `echo 0` 이 한 번 더 붙는다. 결과는 `N="0\n0"` |
| 10 | `[ "$N" -lt "$MIN_CASES" ]` | `N="0\n0"` 이면 `integer expression expected` 로 `[` 가 exit 2 를 낸다. `if` 는 이를 거짓으로 보고 통과 쪽으로 넘어간다. `set -e` 도 없다 |

### 실측 (`COLAB_MIN_CASES` 미선언)

- 지금 `cases.txt`(2건): `check-coverage green — 시험 2건 (최소 1 · 상한 9999s)`, exit 0
- 빈 `cases.txt`(0건): `[: 0\n0: integer expression expected` 가 나온 뒤 `check-coverage green — 시험 0\n0건`, **exit 0**
- `cases.txt` 없음: `::error::시험 0 건 < 최소 1 건`, exit 1. 세 경우 중 실패한 것은 이것뿐이다
- 비교용으로 `COLAB_MIN_CASES=5` 를 주면 `::error::시험 2 건 < 최소 5 건`, exit 1. 선언했을 때만 검사다운 검사가 된다

### 고칠 방향 (파일은 고치지 않았다)

- 5행: `:-1` 기본값을 없애고 세 상태로 나눈다.
  - 미선언이면 `::error::` 와 함께 exit 1 로 끝낸다.
  - 명시 면제값(예: `COLAB_MIN_CASES=exempt`)이면 실측 건수 N 을 드러낸 채 `::warning::` 을 내고 exit 0 으로 끝낸다.
  - 음이 아닌 정수이면 N 과 비교한다.
  - 그 밖의 값이면 exit 1 로 끝낸다.
- 6행: 기본값 `9999` 도 같은 규약으로 처리한다. 적용하지 않을 값이면 변수와 출력 문구를 함께 지운다.
- 8행: `|| echo 0` 을 없앤다. 파일이 없으면 exit 1 로 끝낸다. `N` 이 정수가 아니면 비교하기 전에 exit 1 로 끝내서, 비교 연산이 오류를 내도 통과로 빠지지 않게 한다.

- 판정: 결함 있음
- 관대한 기본값: check-coverage.sh:5 · COLAB_MIN_CASES=1
- 상태1 선언: 선언한 정수 합격선과 `cases.txt` 의 실측 건수 N 을 비교하고, N < 합격선이면 exit 1 로 끝낸다
- 상태2 명시 면제: 면제값이면 비교를 건너뛰되 "면제 · 실측 N건" 을 `::warning::` 으로 출력하고 exit 0 으로 끝낸다
- 상태3 무언: 합격선이 선언되지 않았다는 `::error::` 를 출력하고 exit 1 로 끝낸다
