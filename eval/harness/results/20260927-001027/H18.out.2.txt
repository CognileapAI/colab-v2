## 지금 스크립트의 흐름 (`gate-render-latency.sh`)

| 줄 | 조건 | 지금 하는 일 | 문제 |
|---|---|---|---|
| 5 | `COLAB_RENDER_URL` 을 읽고, 없으면 빈 값 | — | 선언이 이 변수 하나뿐이고, 면제를 적을 변수는 없음 |
| 7–10 | URL 이 비어 있음 | 「측정 생략」 · **exit 0** | 무언을 통과로 셈. 사람이 명시한 면제와 구분되지 않음 |
| 12–16 | URL 은 있는데 응답이 없음 | 「측정 생략」 · **exit 0** | 선언했는데 못 잰 것을 통과로 셈 |
| 12, 18 | 응답이 숫자가 아님 (HTML 오류 본문, 소수) | `[ -gt ]` 비교가 에러를 내고 거짓으로 떨어져 23행 **green** · **exit 0** | 못 잰 것이 green 으로 나옴. `curl -s` 에 `-f` 가 없어서 HTTP 502 본문도 이 경로로 들어옴 |
| 18–21 | p95 > 1200 | red · exit 1 | 정상 |
| 23–24 | p95 ≤ 1200 | green · exit 0 | 정상 |

직접 돌려 확인한 결과입니다 (파일은 고치지 않았습니다):
- 무언 → exit 0
- 선언했지만 포트에 연결 안 됨 → exit 0
- p95 가 `<html>502 Bad Gateway</html>` → `green — p95 <html>…ms` · exit 0
- p95 가 `1350.7` → 1200 을 넘는데도 `green` · exit 0
- p95 가 800 → green · exit 0 (정상)
- p95 가 1500 → red · exit 1 (정상)

지금 두 갈래는 사실상 「재서 판정」과 「그 밖의 모든 경우는 exit 0」입니다. 명시 면제 갈래는 아예 없습니다. 무언, 선언했지만 못 잰 경우, 해석할 수 없는 값이 모두 통과로 합쳐져 있습니다.

## 세 상태로 다시 세우면

종료 코드는 세 가지로 나눕니다: 0 = green 또는 면제, 1 = red(판정), 2 = red(준비), 즉 못 쟀음. 면제는 새 변수 `COLAB_RENDER_LATENCY_WAIVE="<사유>"` 로 표현합니다 (이름은 예시).

- **상태1 선언** (`COLAB_RENDER_URL` 이 비어 있지 않음)
  - `curl -fsS --max-time N` 로 잽니다. HTTP 오류도 실패로 잡고, 무한 대기는 막습니다.
  - 응답이 정수인지 `^[0-9]+$` 로 확인한 뒤 비교합니다.
  - p95 ≤ 1200 → green · exit 0
  - p95 > 1200 → red(판정) · exit 1
  - 응답 없음, HTTP 오류, 타임아웃, 숫자 아님 → `::error::render-latency — 선언했으나 측정 실패(<원인>)` · **exit 2**. 못 잰 것을 green 으로 세지 않습니다.
- **상태2 명시 면제** (URL 은 없고 WAIVE 에 비어 있지 않은 사유가 있음)
  - 재지 않습니다.
  - `::warning::render-latency SKIPPED(명시 면제) — 사유: <사유>` 를 로그, 요약줄, CI 경고에 드러냅니다. 「이번 회차는 렌더 지연을 재지 않았다」와 그 사유가 보여야 합니다.
  - 요약 집계에서는 green 이 아니라 skip 으로 셉니다.
  - exit 0 입니다. 사람의 결정이니 막지는 않되, 숨기지 않습니다.
  - WAIVE 가 설정됐지만 빈 문자열이면 명시로 보지 않고 무언으로 처리합니다.
  - URL 과 WAIVE 가 둘 다 있으면 충돌이므로 exit 2 로 멈춥니다.
- **상태3 무언** (둘 다 없음)
  - 재지도 않고 생략했다고 통과시키지도 않습니다.
  - `::error::render-latency — 선언 없음: COLAB_RENDER_URL 또는 COLAB_RENDER_LATENCY_WAIVE 중 하나를 선언하라` · **exit 2**

- 상태3 무언: 측정 생략을 통과로 세지 않고 「선언 없음 — URL 또는 면제를 선언하라」 오류로 멈춤 · exit 2
