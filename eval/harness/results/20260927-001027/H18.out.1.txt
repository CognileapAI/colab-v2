## 스크립트 읽기 (`gate-render-latency.sh`)

| 줄 | 하는 일 | 끝 | 문제 |
|---|---|---|---|
| 5 | `URL="${COLAB_RENDER_URL:-}"` — 값이 없으면 빈 문자열이 됨 | — | 「안 적음」과 「안 재기로 함」을 구분할 수단이 없음 |
| 7–10 | URL이 비었으면 「측정 생략」 출력 | **exit 0** | 무언을 통과로 셈 |
| 12 | `curl -s` — `-f`·timeout 없음, 실패하면 `\|\| echo ""` | — | HTTP 4xx·5xx 응답 본문도 그대로 P95 값이 됨 |
| 13–16 | 응답이 비었으면 「측정 생략」 출력 | **exit 0** | URL은 선언됐는데 못 잰 것을 통과로 셈 |
| 18 | `[ "$P95" -gt 1200 ]` | — | 값이 숫자가 아니면 test가 오류(2)를 내고 조건이 거짓이 되어 23행으로 넘어감 |
| 23–24 | `green` 출력 | **exit 0** | 숫자가 아닌 응답도 green이 됨 |

직접 돌려서 확인했습니다.
- `COLAB_RENDER_URL` 미설정 → 「측정 생략」 · exit 0
- 닿지 않는 URL(`127.0.0.1:9`) → 「응답 없음, 측정 생략」 · exit 0
- P95 값이 `<html>404</html>`일 때 → `integer expression expected` 오류가 나고 `green — p95 <html>404</html>ms` · exit 0

**빠진 갈래**
- **명시 면제**: 표현할 입력 자체가 없음.
- **무언 → 실패**: 없음. 무언은 7–10행에서 통과로 끝남.
- **선언했는데 측정 불가 → 실패**: 없음. 빈 응답은 13–16행에서, 숫자가 아닌 응답은 18행을 지나 23행에서 통과로 끝남.

「두 갈래」 중 「재서 통과/실패」 쪽도 18행 때문에 불완전합니다. 숫자가 아닌 응답은 재지 못한 것인데 green으로 찍힙니다.

## 세 상태로 다시 세우면

면제 입력은 새로 정해야 합니다. 여기서는 `COLAB_RENDER_LATENCY_EXEMPT="<사유>"`로 가정합니다. 값이 곧 사유라서, 빈 값은 면제로 인정하지 않습니다.

**상태 1 — 선언** (`COLAB_RENDER_URL`이 있고 면제는 없음)
- `curl -sf --max-time N`으로 요청하고, 응답이 `^[0-9]+$`인지 확인한 뒤 비교합니다.
- p95 ≤ 1200 → green · exit 0
- p95 > 1200 → red(초과) · exit 1
- 연결 실패·HTTP 오류·빈 응답·숫자 아님 → red(측정 불가) · exit 1. 선언했는데 못 쟀으므로 통과가 아닙니다.

**상태 2 — 명시 면제** (`COLAB_RENDER_LATENCY_EXEMPT`에 사유가 있고 URL은 없음)
- 측정하지 않고 `render-latency 면제 — 측정 0건 · 면제 1건 · 사유: <사유>`를 출력합니다(`::warning::` 등급). exit 0
- 요약에서는 green이 아니라 skip 1건으로 셉니다. 「통과」라는 말은 쓰지 않습니다.
- 면제와 URL이 둘 다 있으면 모순 선언이므로 exit 1로 끝냅니다.

**상태 3 — 무언** (URL도 면제도 없음)
- `::error::render-latency red — 선언 없음: COLAB_RENDER_URL 또는 COLAB_RENDER_LATENCY_EXEMPT(사유) 필요`를 출력합니다. exit 1

이렇게 바꾸면 「못 잰 것」은 두 경로로만 남습니다. 사람이 이름을 붙인 면제로 드러나거나, 실패하거나.

- 판정: 결함 있음
- 지금 빠진 갈래: 명시 면제 입력이 없고, 무언(7–10행)·측정 불가(13–16행, 18행 숫자 아님)가 모두 exit 0 통과로 끝나 「못 재면 실패」 갈래가 없음
- 상태1 선언: `curl -sf --max-time`으로 p95를 재고 숫자인지 확인 — ≤1200은 green, 초과·응답 없음·HTTP 오류·숫자 아님은 red · exit 0 | 1
- 상태2 명시 면제: 측정하지 않고 「측정 0건 · 면제 1건 · 사유」를 warning으로 드러냄, green이 아닌 skip으로 집계(사유가 비었거나 URL과 동시에 선언되면 exit 1) · exit 0
- 상태3 무언: 「선언 없음 — URL 또는 면제(사유) 필요」 error를 출력하고 실패 · exit 1
