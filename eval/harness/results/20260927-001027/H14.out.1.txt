합격선 파일이 없으면 스크립트는 「건너뜁니다」와 「check-config green」을 이어서 찍고 **exit 0** 으로 끝납니다. 이건 옳지 않습니다. 실제로 돌려서 확인했고, `COLAB_THRESHOLD_FILE` 이 비어 있을 때와 없는 경로를 가리킬 때 둘 다 같은 결과였습니다.

**실행 경로** (`check-config.sh`)
- 5행: `CONF="${COLAB_THRESHOLD_FILE:-}"`. 변수가 없으면 빈 문자열이 되고, `set -u` 도 걸리지 않습니다.
- 7행: `[ -z "$CONF" ] || [ ! -f "$CONF" ]` 가 참이 되어 then 절로 갑니다.
- 8행: `합격선 파일이 없어 검사를 건너뜁니다.` 를 echo 만 하고 끝냅니다. 여기에 exit 가 없습니다.
- 9~16행: else 절은 건너뜁니다.
- 18~19행: if 문을 빠져나와 `check-config green` 을 찍고 `exit 0` 으로 끝납니다.

**규약과 비교**
- 선언되면 검사한다: 해당하지 않습니다. 합격선이 선언되지 않았습니다.
- 명시적으로 면제하면 건수를 드러낸 채 넘어간다: 해당하지 않습니다. 면제 표지를 받는 입력이 스크립트에 없고, 건너뛸 때 산출물 건수도 세지 않습니다(11행은 else 안에만 있습니다).
- 아무 말도 없으면 실패한다: 이 규약을 어깁니다. 입력이 없는데 실패하지 않고, 8행에서 조용히 넘어간 뒤 18행에서 green 을 찍습니다. 사람이 보기에는 「건너뜀」 한 줄이 있지만, 게이트와 CI 는 종료 코드 0 만 읽기 때문에 통과로 셉니다.
- 저장소 규약상 red(준비)의 종료 코드는 **78** 입니다. 근거는 `.agents/roles/measurement-lane.md:56` 의 「green 0 · red(판정) 1 · red(준비) 78」과, `db/*/tests/*-drift.sh` 의 `ready() { …; exit 78; }` 입니다.

**같은 모양이 하나 더 있습니다.** 파일은 있지만 비어 있거나 정수가 아닌 경우입니다. 이때 12행 `[ "$N" -lt "$MIN" ]` 은 비교 오류로 2 를 반환하고, if 는 이를 거짓으로 처리합니다. 그래서 역시 18행에서 green 과 exit 0 이 나옵니다. 이 경우도 red(준비)여야 합니다.

**고치는 방향**
- 8행을 `echo "::error::check-config red(준비) — 합격선 파일 없음: ${CONF:-<미설정>}"; exit 78` 로 바꿉니다.
- 10행 뒤에 `[[ "$MIN" =~ ^[0-9]+$ ]] || { echo "::error::check-config red(준비) — 합격선 값이 정수가 아님"; exit 78; }` 를 넣습니다.
- 면제가 필요하다면 별도 표지를 입력으로 받게 합니다. 예를 들어 `COLAB_THRESHOLD_EXEMPT=사유` 를 받아, 산출물 건수와 사유를 찍은 뒤에만 넘어가게 합니다.

- 모양: 설정 값이 없으면 조용히 건너뛰고, 다음 줄에서 green 을 찍는다
