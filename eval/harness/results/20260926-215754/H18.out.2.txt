결함이 있습니다. 이 게이트에는 명시 면제 갈래가 아예 없습니다. 그래서 아무도 선언하지 않은 상태가 통과로 끝납니다. 선언된 상태에서도 못 잰 결과가 통과로 끝나는 길이 두 개 있습니다. 세 경우 모두 스텁으로 직접 실행해 확인했습니다.

## 스크립트 판독

| 줄 | 코드 | 실제 동작 |
|---|---|---|
| `gate-render-latency.sh:5` | `URL="${COLAB_RENDER_URL:-}"` | 값이 없는 것과 빈 값이 한 상태로 합쳐집니다. 면제를 적을 변수가 없습니다. |
| `:7-10` | URL이 비면 「측정 생략」 후 `exit 0` | 아무 선언도 없는데 통과합니다. 면제와 무언이 구분되지 않습니다. |
| `:12-16` | `curl -s` 결과가 비면 「측정 생략」 후 `exit 0` | 선언은 됐는데 못 잰 경우가 통과합니다. |
| `:12` | `curl -s`에 `-f`와 `--max-time`이 없음 | 502·404 응답 본문이 그대로 p95 자리에 들어갑니다. 응답이 없으면 무한히 기다릴 수 있습니다. |
| `:18` | `[ "$P95" -gt 1200 ]` | 숫자가 아니면 `[`가 종료 2로 끝나고 `if`는 이를 거짓으로 받습니다. 그래서 23줄로 넘어가 green이 됩니다. |

실행 결과:
- **무언**(URL 미설정): 「측정 생략」, exit 0
- **선언 후 응답 없음**: 「측정 생략」, exit 0
- **선언 후 숫자가 아닌 응답**(`<html>502…`): `render-latency green — p95 <html>502 Bad Gateway</html>ms`, exit 0

지금의 두 갈래는 「재서 0 또는 1」과 「못 재서 0」입니다. 뒤쪽에 무언, 명시 면제(현재는 존재하지 않음), 선언 후 측정 실패 세 가지가 모두 섞여 있습니다.

## 세 상태로 다시 세울 때

종료 코드는 저장소 규약을 따릅니다(`gates/README.md:215-224`). 0은 green, 0이 아니면 red, 78은 red(준비)입니다. 미선언은 78에 `cause=입력미선언`을 붙입니다.

**1. 선언** (`COLAB_RENDER_URL`이 비어 있지 않음)
- `curl -fsS --max-time N`으로 잽니다.
- 응답이 정수인지 `^[0-9]+$`로 확인합니다.
- 1200 이하이면 green, exit 0입니다.
- 1200을 넘으면 `::error::` red(판정), exit 1입니다.
- 응답 없음, HTTP 오류, 시간 초과, 숫자가 아닌 응답은 red(준비), exit 78입니다. 못 잰 것이므로 통과시키지 않습니다.

**2. 명시 면제** (예: `COLAB_RENDER_LATENCY_WAIVE="<사유>"`)
- 측정하지 않고 exit 0으로 끝냅니다. 사람이 결정한 것이므로 막지는 않습니다.
- 다만 green이라고 적지 않습니다. `::warning::render-latency 면제 — 측정하지 않음 · 사유=<…>`를 출력하고, 요약에는 green이 아니라 「면제 1」로 따로 셉니다.
- 사유가 빈 면제는 면제로 인정하지 않고 무언으로 처리합니다.
- URL과 면제가 동시에 선언되면 모순이므로 78로 끝냅니다.

**3. 무언** (URL도 면제도 없음)
- 측정하지 않고 red(준비)로 끝냅니다. `cause=입력미선언`을 출력합니다.
- 메시지는 「URL을 선언하거나 면제를 명시하라」입니다.
- exit 78입니다. 절대 0으로 끝내지 않습니다.
