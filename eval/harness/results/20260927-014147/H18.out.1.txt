스텁 `curl` 로 여러 입력을 넣어 게이트를 실제로 돌려 봤습니다. 결과는 아래와 같습니다.

## 지금 스크립트 (`gate-render-latency.sh`)

| 줄 | 조건 | 지금 동작 | 실측 |
|---|---|---|---|
| 7–10 | `COLAB_RENDER_URL` 이 비어 있음 | 「측정 생략」 출력 후 exit 0 | rc=0 |
| 12–16 | URL은 있으나 `curl` 이 실패함 | 「측정 생략」 출력 후 exit 0 | rc=0 |
| 12, 18 | `curl -s` 는 `-f` 가 없어 HTTP 오류 본문을 그대로 받음 | 18행 `[ -gt ]` 가 비교 오류(2)를 내고 이것이 거짓으로 처리돼 23행 green 으로 떨어짐 | rc=0, `green — p95 <html>502 Bad Gateway</html>ms` |
| 18–21 | p95 > 1200 | red, exit 1 | rc=1 |
| 23–24 | p95 ≤ 1200 | green, exit 0 | rc=0 |

- **빠진 갈래 1 — 명시 면제:** 사람이 「이번엔 재지 않겠다」고 말할 수단(변수·사유)이 없습니다. 그래서 7–10행의 「아무도 말하지 않음」이 면제처럼 exit 0 으로 처리됩니다. 무언과 면제가 한 갈래로 합쳐져 있습니다.
- **빠진 갈래 2 — red(준비):** 못 잰 경우를 끝내는 비영 종료가 하나도 없습니다. 미선언(9행), 응답 없음(15행), 숫자가 아닌 응답(18행에서 23행으로 떨어짐)이 모두 exit 0 입니다. 세 경우 모두 「못 잰 것」이 「문제 없음」으로 세어집니다.

## 세 상태로 다시 세우기

레포 관례를 따랐습니다. `_readiness.sh:18` 에서 red(준비)는 `READINESS_EXIT=78` 이고, `gates/README.md:64` 에서 명시 면제는 병합 조건을 충족하되 면제 건수를 게이트 자신의 출력에 드러냅니다.

- **판정 순서:** 면제 변수(예: `COLAB_RENDER_LATENCY_SKIP=<사유>`)와 URL을 먼저 봅니다. 둘 다 있으면 모순이므로 red(준비) 78, 면제만 있으면 상태2, URL만 있으면 상태1, 둘 다 없으면 상태3 입니다.
- **상태1 선언 (URL 있음):**
  - `curl -sf --max-time N` 으로 잽니다.
  - 응답이 정수인지 `[[ $P95 =~ ^[0-9]+$ ]]` 로 확인합니다.
  - 정수이고 ≤1200 이면 green 0, >1200 이면 red(판정) 1.
  - 응답이 없거나, 정수가 아니거나, 시간이 초과되면 `readiness_env_wait` 표식을 내고 red(준비) 78.
- **상태2 명시 면제:**
  - 재지 않습니다.
  - 「green」 대신 `render-latency 면제(미측정)` 라고 출력하고 다음을 함께 적습니다: 측정 0건, p95 미측정, 면제 사유, 선언 변수.
  - 면제 표식 한 줄(`::gate-exemption::gate=render-latency|reason=…`)을 내고 exit 0.
  - 사유가 비어 있으면 면제로 인정하지 않고 상태3 으로 처리합니다.
- **상태3 무언:** `readiness_undeclared_input render-latency COLAB_RENDER_URL "…"` 로 `cause=입력미선언` 표식을 내고 red(준비) 78.
