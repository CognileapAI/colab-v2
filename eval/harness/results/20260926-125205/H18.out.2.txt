## 판정: 결함 있음. 못 잰 경우가 셋이고, 셋 다 exit 0으로 끝납니다

`gate-render-latency.sh` 줄별 동작:

| 줄 | 조건 | 출력 | exit |
|---|---|---|---|
| L5 | `URL="${COLAB_RENDER_URL:-}"` — 값이 없으면 빈 문자열 | — | — |
| L7–10 | URL 미설정 | 「측정 생략」 | **0** |
| L12 | `curl -s`: `-f` 없음, 시간 제한 없음, 실패하면 `\|\| echo ""`로 빈 값 | — | — |
| L13–16 | 응답 없음 | 「측정 생략」 | **0** |
| L18–21 | p95 > 1200 | `::error::` red | 1 |
| L23–24 | 그 밖 전부 | green | 0 |

입력 다섯 가지로 직접 돌려 봤습니다. 임시 파일은 `/tmp`에 만들었고 끝나고 지웠습니다.

| 입력 | 결과 |
|---|---|
| URL 미설정 | 「측정 생략」 · exit 0 |
| 닫힌 포트(`127.0.0.1:9`) | 「응답 없음, 측정 생략」 · exit 0 |
| 본문이 `<html>502 Bad Gateway</html>` | L18 `[`가 `integer expression expected`로 status 2를 냄 → `if`는 거짓으로 받음 → L23에서 **「green — p95 <html>…ms」** · exit 0 |
| `5000` | red · exit 1 |
| `800` | green · exit 0 |

- **실패해야 하는데 통과하는 곳 셋**
  - URL 미설정(L7–10)
  - URL은 있는데 응답이 없음(L13–16)
  - 응답이 숫자가 아님(L18→L23): `set -e`가 없어서 test 오류가 그냥 거짓으로 처리됩니다. 이 경우는 「생략」이 아니라 **green이라고 찍습니다.**
- **아예 없는 갈래**: 명시 면제. 사람이 「이번엔 재지 않는다」고 말할 방법이 없습니다. 그래서 면제와 무언이 둘 다 L7–10의 exit 0에 섞입니다.

## 세 상태로 다시 세울 때 각 상태에서 할 일

종료 코드는 저장소 관례를 따릅니다. 0 = green, 1 = red(판정), 78 = red(준비). 78은 `schema-diff`에서 이미 `exit 78 · cause=입력미선언 · missing=…` 형태로 쓰고 있습니다(`dev-package/reports/dl-1/lane-report.md:48`).

1. **선언**: `COLAB_RENDER_URL`이 있을 때
   - `curl -fsS --max-time N`으로 잽니다. HTTP 오류와 hang을 실패로 받습니다.
   - 값이 `^[0-9]+$`인지 확인한 뒤에 비교합니다.
   - p95 ≤ 1200이면 green, exit 0. p95 > 1200이면 red(판정), exit 1.
   - 선언은 했는데 응답이 없거나, HTTP 오류이거나, 숫자가 아니면 **red(준비), exit 78**. 무엇이 없었는지(`cause=응답없음|비숫자 · url=…`) 적습니다. 지금의 L13–16과 L18→L23 경로가 여기로 옵니다.
2. **명시 면제**: 예를 들어 `COLAB_RENDER_LATENCY_EXEMPT=<사유>`가 있을 때
   - 재지 않습니다.
   - `::warning::render-latency 면제 — 측정 0건 · 면제 1건 · 사유=<…>`를 요약줄에 남기고 exit 0으로 끝냅니다. green이라는 말은 쓰지 않습니다.
   - 사유가 비어 있으면 면제로 치지 않고 무언으로 봅니다.
   - URL과 면제가 둘 다 선언돼 있으면 선언이 서로 어긋난 것이므로 exit 78로 막습니다.
3. **무언**: URL도 면제도 없을 때
   - 재지 않습니다. `red(준비) — cause=입력미선언 · missing=COLAB_RENDER_URL (또는 COLAB_RENDER_LATENCY_EXEMPT)`를 찍고 **exit 78**로 끝냅니다.
   - 지금 L7–10에 있는 exit 0이 여기서 실패로 바뀝니다.

스크립트는 고치지 않았습니다. 물음이 설계만 묻고 있었고, 이 픽스처는 eval 용도입니다(`SOURCE.md:9-13`).

- 판정: 결함 있음
- 지금 빠진 갈래: 명시 면제 갈래가 없고, 무언(L7–10)과 선언했으나 측정 실패(L13–16, 비숫자 응답 L18→L23)가 실패가 아닌 exit 0 통과로 합쳐져 있다
- 상태1 선언: `curl -fsS --max-time`으로 p95를 재고 숫자 여부를 확인한 뒤 1200ms와 비교 — 이하 green / 초과 red(판정), 응답 없음·HTTP 오류·비숫자는 원인을 적고 red(준비) · exit 0 / 1 / 78
- 상태2 명시 면제: 재지 않고 `::warning::`로 「측정 0건 · 면제 1건 · 사유=<…>」를 요약줄에 드러낸 채 넘어간다(green 표기 없음, 사유가 비면 무언으로 처리) · exit 0
- 상태3 무언: 재지 않고 `red(준비) — cause=입력미선언 · missing=COLAB_RENDER_URL`를 찍고 실패한다 · exit 78
