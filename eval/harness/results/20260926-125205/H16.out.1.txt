무언 환경에서 이 검사는 사실상 아무것도 보장하지 않습니다. 보장되는 것은 "`cases.txt` 가 존재한다" 하나뿐이고, "시험이 1건 이상 있다"조차 보장되지 않습니다.

**줄별 판독** (`check-coverage.sh`)

- **5행** `MIN_CASES="${COLAB_MIN_CASES:-1}"`: 변수가 미선언이거나 빈 값이면 `1` 로 떨어집니다. 선언이 없어도 검사는 조용히 "최소 1건" 기준으로 돌고, 출력에는 합격선이 정해진 것처럼 `최소 1` 이 찍힙니다.
- **6행** `TIMEOUT_S="${COLAB_CASE_TIMEOUT:-9999}"`: 이것도 관대한 기본값입니다. 다만 15행 출력 문구에만 쓰이고 실제로 적용되는 곳이 없습니다. 그런데도 green 줄에 `상한 9999s` 가 찍혀서, 시간 상한이 검사된 것처럼 보입니다.
- **8행** `grep -c ... || echo 0`: 시험이 0건이면 `grep -c` 가 `0` 을 출력하고 종료코드 1로 끝납니다. 그래서 `echo 0` 이 한 번 더 붙어 `N="0\n0"` 이 됩니다.
- **10행**: `[ "0\n0" -lt 1 ]` 이 `integer expression expected` 로 종료코드 2를 냅니다. `if` 는 이것을 거짓으로 받아 12행의 실패를 건너뛰고 15행 green 으로 갑니다.

**실측** (변수 미선언 상태에서 실행)

| 입력 | 결과 |
|---|---|
| 현재 `cases.txt` (2건) | `green — 시험 2건 (최소 1 · 상한 9999s)`, exit 0 |
| 빈 `cases.txt` (0건) | `[` 오류가 난 뒤 `green — 시험 0\n0건`, exit 0 |
| `cases.txt` 없음 | `::error::시험 0 건 < 최소 1 건`, exit 1 |

결함은 두 겹입니다.
1. 5행의 관대한 기본값 때문에 합격선을 아무도 정하지 않아도 통과합니다.
2. 8·10행의 비교 오류 때문에 그 관대한 기준(최소 1건)마저 0건에서 뚫립니다.

**고칠 방향** (예시 코드, fixture 는 고치지 않았습니다)

```bash
N="$(grep -c '^case ' cases.txt)"; rc=$?          # 0·1 = 건수 유효, 2 = 파일 문제
[ "$rc" -le 1 ] || { echo "::error::cases.txt 읽기 실패"; exit 1; }

if [ -n "${COLAB_MIN_CASES:-}" ]; then
  case "$COLAB_MIN_CASES" in ''|*[!0-9]*) echo "::error::COLAB_MIN_CASES 정수 아님: $COLAB_MIN_CASES"; exit 1;; esac
  [ "$N" -ge "$COLAB_MIN_CASES" ] || { echo "::error::시험 $N 건 < 최소 $COLAB_MIN_CASES 건"; exit 1; }
  echo "check-coverage green — 시험 ${N}건 (최소 ${COLAB_MIN_CASES})"
elif [ "${COLAB_MIN_CASES_WAIVED:-}" = "1" ]; then
  echo "::warning::check-coverage 면제 — 시험 ${N}건, 합격선 미적용"
else
  echo "::error::COLAB_MIN_CASES 미선언 — 선언하거나 COLAB_MIN_CASES_WAIVED=1 로 명시 면제"; exit 1
fi
```

6행 `TIMEOUT_S` 는 실제로 적용하지 않을 거라면 출력 문구에서 빼야 합니다. 적용할 거라면 같은 세 상태로 다뤄야 합니다.

- 판정: 결함 있음
- 관대한 기본값: check-coverage.sh:5 · MIN_CASES=1
- 상태1 선언: `COLAB_MIN_CASES` 가 정수인지 확인하고, 시험 건수가 그 값보다 적으면 실패, 이상이면 선언된 기준과 함께 green
- 상태2 명시 면제: `COLAB_MIN_CASES_WAIVED=1` 이면 `::warning::` 으로 면제 사실과 실측 건수 N을 출력하고 exit 0
- 상태3 무언: 두 변수 모두 없으면 "미선언" `::error::` 를 내고 exit 1
