**판정 요지** — 스크립트는 「선언」과 「무언」만 구분하고, 무언을 exit 0 으로 통과시킨다. 「명시 면제」 갈래는 없다.

**현재 스크립트 갈래(`gate-render-latency.sh`)**

- 5행 `URL="${COLAB_RENDER_URL:-}"` — 선언 여부만 읽는다.
- 7~10행 — URL 비어 있음(무언) → 「측정 생략」 출력 · exit 0. **못 잰 것을 통과로 센다.**
- 12~16행 — URL 있으나 응답 없음 → 「측정 생략」 출력 · exit 0. 같은 결함(선언은 됐는데 못 잰 것도 통과).
- 18~21행 — p95 > 1200 → red · exit 1.
- 23~24행 — p95 ≤ 1200 → green · exit 0.
- 「사람이 이번에는 재지 않겠다」를 적을 변수(예: `COLAB_RENDER_LATENCY_SKIP=1` 과 사유)가 어디에도 없다. 누군가 환경 설정을 잊어도, 의도적으로 빼도 같은 줄이 찍히고 같은 코드로 끝나 둘을 로그에서 구분할 수 없다.

**세 상태로 세울 때 각 상태의 행동**

- **상태1 선언**(`COLAB_RENDER_URL` 있음) — 실제로 잰다. p95 ≤ 1200 → green exit 0. p95 > 1200 → red exit 1. **응답 없음은 생략이 아니라 red(준비) exit 1** — 선언해 놓고 못 쟀으면 판정 불능이지 통과가 아니다.
- **상태2 명시 면제**(면제 변수가 켜져 있음) — 재지 않는다. 출력에 **면제라는 사실 · 누가/왜(사유 변수) · 이 결과가 green 이 아니라 「미측정」임**을 드러내고 exit 0 으로 끝낸다. 면제 변수와 URL 이 동시에 있으면 면제가 아니라 모순이므로 exit 1.
- **상태3 무언**(둘 다 없음) — **red(준비) exit 1.** 「URL 도 면제 선언도 없다 — 재려면 URL, 빼려면 면제 변수」를 안내한다. 지금의 exit 0 이 바로 green-by-skip 이다.

`set -u` 는 있으나 `set -e` 가 없어 `curl` 실패 시 빈 문자열로 흘러가고, 18행은 `P95` 가 숫자가 아니면(HTML 오류 페이지 등) `[ -gt ]` 가 실패해 red 로 가지 않고 그냥 지나가 23행 green 이 찍힌다. 세 상태 재설계 시 숫자 검증도 같이 넣어야 한다.

- 지금 빠진 갈래: 명시 면제 갈래 자체가 없고, 무언(7~10행)과 응답 없음(13~16행)이 exit 0 으로 통과된다
- 상태1 선언: p95 측정 → ≤1200 green · exit 0 / >1200 red · exit 1 / 응답 없음·비숫자 red(준비) · exit 1
- 상태2 명시 면제: 측정 생략 — 면제 변수·사유·「미측정(green 아님)」을 출력에 드러낸다 · exit 0 (URL 과 동시 선언 시 모순 · exit 1)
- 상태3 무언: 측정 생략하되 red(준비)로 판정, 필요한 두 선언 중 하나를 안내 · exit 1
