결함이 있습니다. 합격선 파일이 없으면 스크립트는 검사를 건너뛰었다고 알린 뒤 green 을 찍고 exit 0 으로 끝납니다. 두 경우(환경 변수 미설정, 없는 경로 지정) 모두 직접 돌려 확인했습니다.

## 실행 경로 (`check-config.sh`)

| 줄 | 동작 |
|---|---|
| 5 | `CONF="${COLAB_THRESHOLD_FILE:-}"` — 변수가 없으면 빈 문자열입니다. |
| 7 | `[ -z "$CONF" ] \|\| [ ! -f "$CONF" ]` 가 참이 되어 then 가지로 갑니다. |
| 8 | 「합격선 파일이 없어 검사를 건너뜁니다.」를 출력하고 끝냅니다. `exit` 가 없습니다. |
| 9–16 | else 가지라서 건너뜁니다. 검사가 한 번도 돌지 않습니다. |
| 18 | `check-config green` 을 출력합니다. |
| 19 | `exit 0` 으로 끝납니다. |

실측 결과는 둘 다 같습니다.
```
합격선 파일이 없어 검사를 건너뜁니다.
check-config green
exit=0
```

## 규약과 대조

- **선언되면 검사한다:** 합격선 파일이 있을 때만 10–15줄이 돕니다. 이 경우는 규약대로 동작합니다.
- **명시적으로 면제하면 건수를 드러낸다:** 면제를 선언하는 경로가 스크립트에 없습니다. 8줄은 면제가 아니라 「못 돈 것」이고, 건너뛴 건수도 드러내지 않습니다.
- **아무 말도 없으면 실패한다:** 어긋납니다. 7줄의 조건 두 개가 모두 green 으로 이어집니다.
  - `-z "$CONF"`: 아무 말도 없는 경우입니다. 실패해야 합니다.
  - `! -f "$CONF"`: 선언은 했는데 환경에 파일이 없는 경우입니다. red(준비) 여야 합니다.
- 8줄 안내문은 사람 눈에만 보입니다. CI 가 읽는 종료 코드는 0 이라서 「환경이 없어 못 돈 것」이 통과로 기록됩니다.
- 저장소의 종료 코드 규약은 `infra/prod/tests/ship-gate.sh:10` 과 `db/platform/tests/*-drift.sh` 기준으로 exit 0 green · exit 1 red(판정) · exit 78 red(준비) 입니다.

**같은 모양이 하나 더 있습니다.** 합격선 파일이 비어 있거나 숫자가 아니면 12줄의 `[ "$N" -lt "$MIN" ]` 이 `integer expression expected` 로 실패하고 상태 코드 2 를 냅니다. `if` 는 이를 거짓으로 받고, `set -e` 도 없어서 그대로 18줄로 내려가 `check-config green` · exit 0 이 됩니다. 빈 파일로 돌려 확인했습니다.

**고치는 방향:** 8줄을 `echo "::error::check-config red(준비) — 합격선 파일 없음: ${CONF:-<미설정>}"; exit 78` 로 바꿉니다. 10줄 뒤에는 `MIN` 이 정수인지 확인하는 검사를 넣고, 정수가 아니면 역시 exit 78 로 끝냅니다. 면제가 필요하면 명시적인 면제 선언을 따로 두고, 면제했다는 사실과 건수를 출력하게 합니다.
