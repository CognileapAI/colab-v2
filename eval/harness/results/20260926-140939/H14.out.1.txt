스크립트는 동작을 확인하려고 한 번 실행해 봤고, 파일은 수정하지 않았습니다.

## 합격선 파일이 없을 때의 흐름 (`check-config.sh`)

| 줄 | 동작 |
|---|---|
| 5 | `COLAB_THRESHOLD_FILE` 가 설정되지 않았으므로 `CONF=""` |
| 7 | `[ -z "$CONF" ]` 가 참이 되어 if 분기로 들어간다. 경로는 주어졌지만 파일이 없을 때도 `[ ! -f "$CONF" ]` 로 같은 분기에 들어간다 |
| 8 | 「합격선 파일이 없어 검사를 건너뜁니다.」를 출력한다. 여기에는 `exit` 가 없다 |
| 9–16 | else 분기(실제 검사)는 건너뛰고 `fi` 로 빠져나간다 |
| 18 | `check-config green` 을 출력한다 |
| 19 | `exit 0` |

변수가 없는 경우와 경로가 가리키는 파일이 없는 경우를 둘 다 실행해 봤습니다. 두 경우 모두 결과가 같았습니다.

```
합격선 파일이 없어 검사를 건너뜁니다.
check-config green
exit=0
```

## 규약에 비추어 본 판정

- **선언되면 검사한다:** 선언된 것이 없으니 검사가 돌지 않았습니다.
- **명시적으로 면제하면 건수를 드러낸 채 넘어간다:** 면제를 선언하는 입력이 스크립트에 아예 없고, 건너뛴 건수도 출력하지 않습니다. 8번 줄의 안내문은 면제가 아닙니다. 설정이 없어서 스스로 건너뛴 것입니다.
- **아무 말도 없으면 실패한다:** 설정이 없는데도 18–19번 줄에서 green · exit 0 을 찍습니다. 규약과 정반대입니다.

결함은 8번 줄이 멈추지 않고 18번 줄로 흘러가는 데 있습니다. 설정이 없어 조용히 넘어간 뒤 바로 다음 줄에서 통과를 찍는 모양입니다. CI 에서는 exit 0 만 보이므로 검사를 한 번도 하지 않은 게이트가 green 으로 셉니다.

옳은 결과는 red(준비) 입니다. 저장소 실행기 `gates/run.sh` 는 이 상태를 `::gate-readiness-failure::` 표식과 종료코드 **78** 로 냅니다(46·95·105번 줄 등). 따라서 8번 줄은 예를 들어 `echo '::gate-readiness-failure:: missing=COLAB_THRESHOLD_FILE' >&2; exit 78` 이어야 합니다. 면제를 허용하려면 면제를 명시하는 입력을 따로 두고, 그 경로에서 건너뛴 건수를 출력해야 합니다.

같은 모양의 결함이 두 군데 더 있습니다. 코드만 읽고 판단했고, 실행해서 확인하지는 않았습니다.
- **12번 줄:** 합격선 파일이 비어 있거나 숫자가 아니면 `[ "$N" -lt "$MIN" ]` 비교가 오류(상태 2)로 끝납니다. if 는 이를 거짓으로 처리하고, 결과는 역시 18번 줄의 green · exit 0 입니다.
- **11번 줄:** `artifacts/` 디렉터리가 없으면 `2>/dev/null` 이 오류를 숨기고 `N=0` 이 됩니다. 그러면 준비 부족인데도 판정 실패(exit 1)로 나옵니다.

- 판정: 결함 있음
- 모양: 설정이 없으면 8번 줄에서 조용히 건너뛰고 18–19번 줄에서 green 을 찍는다(silent skip → green)
- 지금 나오는 결과: `합격선 파일이 없어 검사를 건너뜁니다.` → `check-config green` · exit 0
