검사 스크립트를 읽고, 변수를 선언하지 않은 채로 직접 돌려 봤습니다. 결론은 **이 검사는 아무것도 보장하지 않는다**입니다. 기본값이 관대한 쪽으로 떨어지고, 8행의 결함 때문에 시험이 0건이어도 통과가 나옵니다.

## 줄별 판독

- **5행** `MIN_CASES="${COLAB_MIN_CASES:-1}"`: 변수가 없거나 빈 값이면 `1`이 됩니다. 이 대입 형태는 `set -u`(3행)에 걸리지 않아서, 값이 없다는 사실이 가려집니다. 사람이 합격선을 정하지 않았는데 "최소 1건"이라는 기준이 조용히 생깁니다.
- **6행** `TIMEOUT_S="${COLAB_CASE_TIMEOUT:-9999}"`: 같은 형태의 관대한 기본값입니다. 검사에는 쓰이지 않고 15행 green 메시지에 `상한 9999s`로 찍히기만 합니다. 상한을 검사한 것처럼 보이게 만드는 표기입니다.
- **8행** `grep -c ... || echo 0`: 일치하는 줄이 0건이면 `grep -c`가 `0`을 출력한 뒤 exit 1로 끝납니다. 그러면 `echo 0`이 한 번 더 실행돼 `N`이 `"0\n0"`이 됩니다.
- **10행** `[ "$N" -lt "$MIN_CASES" ]`: `N`이 정수가 아니니 `[`가 exit 2로 끝나고, `if`는 이를 거짓으로 처리합니다. 그래서 15행으로 넘어가 green, exit 0이 됩니다.

## 실측

| 조건 | 결과 |
|---|---|
| 변수 선언 없음 · 현재 `cases.txt`(2건) | green · exit 0 · `최소 1 · 상한 9999s` |
| 변수 선언 없음 · 빈 `cases.txt` | `integer expression expected` 경고 뒤 green · exit 0 · `시험 0\n0건` |
| `COLAB_MIN_CASES=5` · 빈 `cases.txt` | green · exit 0 |

변수를 선언하지 않았을 때 보장하는 것은 "`case`로 시작하는 줄이 1건 이상"조차 아닙니다. 8행 때문에 0건도 통과합니다. 합격선을 선언한 경우(상태 1)에도 0건이면 통과하므로, 5행만 고쳐서는 부족하고 8행도 함께 고쳐야 합니다. 두 결함 모두 "값이 없으면 검사가 무의미해지는데 통과가 나오는" 모양입니다.

## 고칠 방향 (세 상태)

아래는 제안 형태이고, 픽스처 파일은 고치지 않았습니다.

```bash
[ -f cases.txt ] || { echo "::error::cases.txt 없음"; exit 1; }
N="$(grep -c '^case ' cases.txt)"            # 0건이면 "0" 한 번만 (rc=1 은 무시)

case "${COLAB_MIN_CASES-}" in
  exempt)  echo "::warning::check-coverage 면제 — 시험 ${N}건 · 합격선 미검사"; exit 0 ;;
  '')      echo "::error::COLAB_MIN_CASES 미선언 — 합격선을 선언하거나 exempt 로 면제하라"; exit 1 ;;
  *[!0-9]*) echo "::error::COLAB_MIN_CASES='${COLAB_MIN_CASES}' 는 정수가 아니다"; exit 1 ;;
esac
[ "$N" -ge "$COLAB_MIN_CASES" ] || { echo "::error::시험 $N 건 < 최소 $COLAB_MIN_CASES 건"; exit 1; }
```

`COLAB_CASE_TIMEOUT`은 실제로 검사하도록 같은 세 상태를 적용하거나, 검사하지 않을 거라면 15행 메시지에서 `상한`을 지워야 합니다.

- 판정: 결함 있음
- 관대한 기본값: check-coverage.sh:5 · MIN_CASES=1
- 상태1 선언: `COLAB_MIN_CASES`가 정수이면 `N`과 비교해 미달이면 `::error::`와 exit 1, 정수가 아니면 exit 1 (8행 `|| echo 0` 제거가 전제)
- 상태2 명시 면제: `COLAB_MIN_CASES=exempt`이면 `::warning::`에 시험 건수 `N`을 찍고 exit 0
- 상태3 무언: `COLAB_MIN_CASES`가 없거나 비어 있으면 `::error::` 미선언 메시지와 함께 exit 1
