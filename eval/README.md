# eval — AI 평가셋

D10의 두 지점을 판정한다. **평가셋 없이는 "제안 품질이 좋아졌다"를 말할 수 없다.**

| 대상 | 무엇을 재나 |
|---|---|
| 계보 제안 (K3) | 정답 부모를 후보에 넣었는가 · 확신도가 정직한가 · 근거가 실제 근거인가 · **모를 때 모른다고 하는가** |
| 자연어 검색 (K4) | 재현율 · 순위 · 근거 문장의 정확도 · 탐색 범위 고지의 정확성 |

## 규칙

- 평가셋은 **실데이터**로 만든다. 합성 예시만으로는 좌표계·격자 함정이 드러나지 않는다
- 모델·프롬프트 교체 시 **회귀 판정**의 근거가 된다 (K5 제안 원장과 짝)
- "억지로 답을 만드는" 실패를 별도 지표로 센다 — 정본이 정직한 빈 상태를 요구한다

## 하네스

| 경로 | 무엇 | 대상 |
|---|---|---|
| `k4-search/` | 그래프 확장 **전/후** 비교 | `SEED-DATA §3.1` 시드 15건 · **일회용 DB** |
| `s2b-alayer/` | 검색 평가셋 **1세대** — A층 16건 실행 ＋ 기준선 대비 회귀 표시. 기대는 **산문 정본을 옮긴 것** | staging **실물 적재분 12건** |

⚠ `s2b-alayer/` 는 **합격선을 걸지 않는다** — 2026-08-29 Ted 판정으로 검색 평가셋은 이번 릴리즈
판정 대상 밖이다. **값만 기록한다.** 그래서 `gates/` 가 아니라 여기 있다.

「이 낱말은 없다」가 실물과 어긋났기 때문이다(`dev-package/sessions/K4-EVALSET-G2.md`).
두 세대의 기준선·판정 기록이 나란히 남아야 **언제 무엇이 달라졌는가**를 되짚을 수 있다.
