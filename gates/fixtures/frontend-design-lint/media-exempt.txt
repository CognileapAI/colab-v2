# 파일 = frontend 기준 경로 · 조건 = `@media`/`@container` 머리(정규화해 비교 — `@media(max-width:720px)` 와 `@media (max-width: 720px)` 는 같은 조건)
# · 개수 = 그 파일에서 그 조건을 가진 머리 수(찾은 수와 같아야 한다) · 사유 = 옮길 자리(다음 intent) 또는 영구 예외 근거.
# 줄 번호는 적지 않는다. 형식 오류 · 빈 사유 · 개수 어긋남 · 맞는 것 없음 · 같은 조건 두 줄은 red 이고 아무것도 면제하지 않는다.
# hover 하위 조건(`(hover: hover)` 밖 `:hover`)은 이 목록으로 면제하지 않는다.
