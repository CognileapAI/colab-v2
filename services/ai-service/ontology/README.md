# ontology — 수문학 의미 체계

**소유: 수문학 도메인.** 개발자가 대신 정하면 아무도 검증하지 않는다.

WU-G8(1차 범위 합의) → WU-K1(스키마) → WU-K2(시드 적재) 순서로 채운다.

## 1차 범위 후보 (G8에서 확정)

- **변수** — 강수 · 유출 · 수위 · 유량 · 증발산 …
- **좌표계** — 국내 실무에서 쓰이는 것과 그 사이 변환 관계
- **공간 위계** — 유역 ⊃ 소유역 ⊃ 행정구역, 그리고 통용 지명(예: "낙동강 유역")
- **관측소** — 식별자 체계와 공간 위치
- **가공 방식 계열** — 집계 · 보간 · 크롭 · 리샘플. 무엇이 같은 계열인가
- **출처 기관** — 데이터 제공 주체

## 왜 그래프인가

v2가 AI에게 시키는 두 일이 모두 **관계 질의**이기 때문이다.
"이 파일과 같은 변수·같은 공간·더 낮은 가공 단계인 데이터셋이 있는가"와
"'낙동강 유역 강우'가 가리키는 개념은 무엇인가" — 둘 다 벡터 유사도만으로는 답이 안 된다.
