# viz-render

**담는 도메인** — D7 Visualization

프로파일: 중 CPU · 지연 민감 · 캐시 가능. **geo 라이브러리가 여기에만 들어간다.**

## 소유하는 것

COG 바이트 범위 타일 서빙 · 2D 렌더(격자 · 경계 · 점 3종) · 색상과 색상 간격 · 스크린샷 추출

## 정본 제약 (E-03)

- 한 번에 **값 하나**를 그린다
- 색상과 **색상 간격**을 사용자가 조절한다
- 시각화 설정은 **저장하지 않는다** — 클라이언트 렌더
- 데이터 2개 중첩은 **1차 범위 밖**(P1로 내려감)

## 규칙

- 인제스트 시 overview를 미리 만든다 (요청 시 생성 금지)
- 타일 URL과 파라미터를 정규화해 CDN 캐시 적중률을 올린다
