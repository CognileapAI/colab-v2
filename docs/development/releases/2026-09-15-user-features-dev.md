## 배포 대상과 수용 조건

대상은 [dev 사이트](https://d31zgpff2091oh.cloudfront.net) 하나다. prod 배포와 데이터 초기화는 포함하지 않는다.
이 문서 자체는 배포 완료 기록이나 승인 대체물이 아니다.

1. 사람이 이 릴리스 PR에서 위 구현과 근거를 검토하고 develop에 병합한다.
2. **최종 후보는 이 PR의 실제 병합 SHA**다. 기존 660854bb를 PR 병합 SHA로 적지 않는다.
3. 최종 후보의 CI 집계와 producer artifacts를 새로 회수하고, 실제 PR 기록과 함께 [릴리스 증거 계약](../release-evidence.md)을 검증한다.
4. [기존 배포 실행기](../../../infra/releases/README.md)로 이미지·웹을 배포한 뒤 실행 SHA, 공개 웹 파일 hash, deploy doctor의 15개 항목을 한 번의 실행으로 확인한다.
5. 배포 검증이 통과하면 #33·#41·#42에 `in review` 라벨을 추가하고 열린 상태로 사용자 검토를 받는다. 일부만 수정한 #53 전체를 검토 완료 대상으로 표시하지 않는다.

이 후속 PR의 변경은 릴리스 기록뿐이다. 최종 후보의 기능 파일이 660854bb와 같은지 다시 대조하고, 문서 변경으로 선택 제외된 CI 항목을 기능 시험 재실행으로 보고하지 않는다.
