두 채널 모두 개발자와 운영자가 함께 받습니다. 채널 이름은 설명용입니다.

이럴 때, 이렇게 옵니다.

상황을 누르면 흐름과 알림 예시가 바뀝니다. 실제 메시지를 보내지는 않습니다.

1
5분마다 서비스를 확인실패 한 번으로 장애를 단정하지 않아요.
2
두 번 연속 실패하면 이상 알림같은 이상이 계속되면 반복 알림을 줄여요.
3
다시 정상으로 확인되면 복구 알림처음부터 정상이었다면 복구라고 하지 않아요.

보고에 들어가는 활동과 범위

실제 사용 환경 dev의 모든 연구실을 대상으로 하고, 명시한 시험 연구실·계정은 제외합니다. 전날 00:00부터 당일 00:00 직전까지의 활동을 셉니다.

업로드·등록, 자료 변경·삭제, 프로젝트 생성·삭제, 다운로드 요청(티켓 발급), 접근 요청·승인·거절, 권한 변경을 포함합니다. 일반 활동은 사용자별 요약, 삭제·권한 변경·접근 승인·거절은 개별 상세로 보여 줍니다.

사용자에게 직접 보내는 알림은 이번 범위에 없습니다. AWS 사건 종료와 CoLAB 서비스의 실제 복구도 구분합니다.
