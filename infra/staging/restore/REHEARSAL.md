# 복원 리허설 1회차 — 절차

> **`R1-RESTORE-DRAFT §5` 의 권고 그대로다: 1 · 3 · 6 을 한 묶음으로.**
> 여기에 **볼륨 백업 왕복**을 더한다 — `§5` #4 가 「먼저 볼륨 백업 절차부터 세워야 한다」고 적은
> 선행 결손이 채워졌기 때문이다(`infra/staging/backup/backup-volume.sh`).
>
> 집행 = `infra/staging/restore/rehearsal.sh`. **이 문서를 읽고 나서 돌린다.**

## 왜 안전한가 — 먼저 이것부터

| | |
|---|---|
| 살아 있는 staging 에 **읽는** 것 | `pg_dump`(백업 경로 그대로) · `docker image inspect` · 볼륨 `:ro` 마운트 |
| **쓰는** 곳 | 일회용 컨테이너 `r1_*`(tmpfs PGDATA · 호스트 포트 없음) · 일회용 볼륨 `r1_vol_*` · 임시 디렉터리 |
| 살아 있는 컨테이너·볼륨·DB·비밀 파일 | **한 바이트도 쓰지 않는다** |

**그래서 어떤 파괴적 단계보다 먼저 돌려도 된다.** 리허설이 사고를 앞당기지 않는다.
`restore-rehearsal.sh`(IS3)의 「대상은 언제나 방금 만든 빈 일회용 인스턴스」 전제를 그대로 물려받는다.

## 무엇을 덮는가 / 안 덮는가

| §5 # | 항목 | 이 리허설에서 |
|---|---|---|
| 1 | `DROP SCHEMA public CASCADE` → 재적재 | ✅ 전부 — 교체 직후 테이블 0 확인까지 |
| 3 | 비밀 파일 제자리 덮어쓰기 vs `mv`(inode) | ✅ **양성·음성 둘 다.** `mv` 뒤 옛 값이 계속 읽히는 것을 실물로 본다 |
| 6 | RLS·GRANT 생존 | ✅ **음성이 먼저** — `--no-privileges` 덤프라 GRANT 없는 앱 롤은 못 읽는 것이 정상이다 |
| 4 | 볼륨 백업 왕복 | ✅ 백업 → 일회용 볼륨 복원 → **매니페스트 전건 sha256** |
| 5 | 이미지 digest | ⚠ 부분 — 대장 대조는 돈다. `:i2` 가 **언제 움직였는지의 이력**은 어디에도 없다 |
| 2 | 컨테이너 8개 왕복 | ⚠ 부분 — 별도 프로젝트명으로 전체를 띄우면 순서·`:?` 키·`volume-init` 은 덮이나 **터널·DNS·실 태그 경합은 안 덮인다**. 2회차 항목 |
| 7 | 복원 소요 실측 | ⚠ 다시 잰다 — 종전 값(platform 317ms · ai 130ms)에 **업로드 바이트가 없다** |
| 8 | 원인 규명(P9) | ❌ 덮이지 않는다. 게이트로 남긴다 |

## 순서

```
set -a; . "$ENVFILE"; set +a
infra/staging/restore/rehearsal.sh          # 실패 조사가 필요하면 --keep
```

1. **재료** — `backup-full.sh` 1회(원장 먼저, 볼륨 나중). 읽기만 한다.
2. **§5-1** 일회용에 적재 → `DROP SCHEMA` → 재적재 → **기대치는 덤프에서 읽어** 대조.
3. **§5-3** `0600` · `:ro` 파일 바인드 재현 → 제자리 덮어쓰기(양성) · `mv`(음성).
4. **§5-6** 앱 롤 생성 → GRANT 전 **읽기 거부**(음성) → GRANT 후 스코프 없는 조회 **0행**(양성).
5. **볼륨 왕복** → 아카이브 검사(원장 오라클 포함) → 일회용 볼륨 복원 → sha256 전건.
6. **digest 대장 대조**(읽기 전용).
7. **`subjects.json` 형식 확인** — 형식은 레포에서 읽힌다.

## 리허설 뒤에 적는 것

- 각 구간 **소요 시간** — 실사고 때 「얼마나 걸리는가」의 유일한 근거다.
- `§5-3` 음성이 이 호스트에서 **실제로 성립했는가** — 성립 안 하면 `§4.2-1` 의 근거를 다시 재야 한다.
- 볼륨 복원 소요 — `IS3 §15` 의 317ms/130ms 를 **대체하는 새 값**이다.
- 판정·값은 `PLAN-SoT §9` 에. 이 문서에는 절차만 남긴다.

## ⚠ 이 리허설이 **닫지 못하는** 완료 정의

- **완-비2 「재발급본으로 기동이 선다」** — 컨테이너 8개 왕복이 필요하고 그것은 `§5-2`(부분 리허설)다.
  **형식을 안 것과 기동이 선 것은 다르다.** 2회차로 넘긴다.
- **`§5-8` 원인 규명** — 사고의 원인은 사고가 나야 있다.
