# 검증문서: 업로드와 계보 (긴급 범위)

## 1) 검증 목적 / 범위
### 1.1 검증 목적
- 업로드 플로우(파일 놓기 → 분석 → 분류 → 메타데이터 입력 → 연결 → 데이터셋 만들기)와 데이터셋 상세(계보·미리보기·활용·접근)가 정책 문서의 규칙대로 동작하는지 검증한다.

### 1.2 검증 범위
- 포함:
  - 업로드 전체 화면 모달의 두 장면과 등록 3단계
  - 계보 직접 연결, 기록 없음, 연결 가능 가공 단계 필터(부모 Lv ≤ 자기 Lv)
  - 미리보기(업로드 즉시 · 상세 뷰어 · 확장보기 · 실패 상태)
  - 데이터셋 상세의 계보 그래프·상세 행·수정 모달·활용·접근·파일 목록
- 제외:
  - AI 기능 전부(이번 범위에서 배제), 데이터셋 목록 화면, 권한 세분화, 이종 포맷 일괄 업로드(한 데이터셋은 한 확장자다)
