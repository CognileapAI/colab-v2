# A. Reader Layer (업무 언어로 이해하기)

## 1) 한 장 요약 (TL;DR)
### 1.1 목적 (Why)
- 파일을 올리는 순간에 메타데이터와 계보를 사람이 기록하게 하여, 올린 사람 없이도 데이터의 정체와 출처를 믿을 수 있게 한다.

### 1.2 누가/언제 쓰나 (Who/When)
- 주요 사용자: A2 대학원생(업로드·계보 기록), 연구실 구성원 전체(상세 열람·다운로드)
- 사용 시점/상황: 가공을 마친 데이터를 연구실에 등록할 때, 등록된 데이터를 찾아 쓸지 판단할 때

### 1.3 무엇이 가능한가 (What)
- 파일을 올리고 메타데이터를 직접 적어 데이터셋을 만든다
- 가공 전 데이터를 찾아 계보로 연결하거나, 못 찾으면 기록 없음으로 남긴다
- 서버가 그린 미리보기 한 장으로 내용을 확인하고 대표 그림으로 쓴다
- 상세 화면에서 계보 그래프를 타고 다른 데이터셋으로 이동하고, 계보를 나중에 바로잡는다

### 1.4 핵심 규칙 Top 7
1. 파일에서 자동으로 읽는 값은 확장자와 용량뿐이다. 확장자로 포맷을 단정하지 않는다.
2. 업로드는 포맷을 가리지 않는다. 같은 확장자 파일 여러 개가 데이터셋 하나가 된다.
3. 분류·유형·가공 단계는 고려대 정의를 그대로 쓴다. 분류 5종 · 유형 6종 · Lv0~Lv3. 등록 첫 단계 `분류`에서 고르고, 고른 값 아래 정의·대표 예시를 보인다.
4. 가공 단계는 자동으로 맞추지 않는다. 규칙은 `부모 Lv ≤ 자기 Lv` 이고 같은 단계 가공을 허용한다. 분류에서 고른 자기 Lv 가 기준이며, 연결에서는 그 이하의 가공 전 데이터만 고를 수 있다. 연결 뒤 자기 Lv 를 낮추면 연결을 지우지 않고 확인 필요로 표시하고 데이터셋 만들기를 막는다.
5. 변수는 여러 개다. 단위·값 범위·결측률을 변수마다 받고 대표 변수 하나를 고른다.
6. 설명은 필수다. 칸을 따로 만들지 않은 필수 항목도 여기에 적는다.
7. 계보를 모르면 막지 않고 기록 없음으로 남긴다. 미리보기를 못 그려도 등록·계보·다운로드는 그대로 된다.

## 2) 업무 흐름(Flow)으로 보는 규칙 맵

| Flow Step (사용자 행동) | 시스템이 하는 일 | 관련 규칙 |
|---|---|---|
| 파일을 끌어다 놓는다 | 올리기 → 읽기 → 확장자·용량 확인 순으로 분석하고, 끝나야 다음을 켠다 | "파일 분석" |
| 다음으로 넘어간다 | 서버가 첫 변수·기간 평균으로 미리보기 한 장을 자동으로 그린다 | "바로 미리보기" |
| 메타데이터를 적는다 | 확장자·용량은 자동으로 채우고, 나머지는 입력을 받는다 | "메타데이터 입력" |
| 가공 전 데이터를 연결한다 | 검색 모달에서 골라 직접 연결로 기록하고, 가공 단계 선택 범위를 좁힌다 | "계보 직접 연결", "가공 단계 선택 범위" |
| 프로젝트를 담는다 | 목록에서 고르거나 유형·이름만으로 빠르게 만든다 | "프로젝트·논문 연결" |
| 데이터셋을 만든다 | 이름을 확인하고 상세 화면으로 보낸다 | "데이터셋 만들기" |
| 업로드를 닫는다 | 입력 내용이 사라짐을 확인받고 닫는다 | "닫기 확인" |
| 상세에서 계보를 본다 | 그래프와 상세 행을 보여주고, 노드를 누르면 그 데이터셋 상세로 보낸다 | "계보 표시와 이동" |
| 계보를 바로잡는다 | 수정 모달에서 연결을 추가하고 직접 연결로 남긴다 | "계보 수정" |

## 3) 사용 예시 (정상/경계/실패)

### 3.1 정상 시나리오
- 상황: nc 파일을 놓고 분석 완료 후 메타데이터를 적고, Lv1 가공 전 데이터를 연결하고, 프로젝트 1건을 담아 데이터셋을 만든다.
- 결과: 찾기 모달에 자기 Lv(Lv2) 이하 후보만 고를 수 있고, 데이터셋 상세로 이동하며 계보 그래프에 원천·가공 전·이 데이터가 표시된다.
- 근거: "가공 단계 선택 범위", "데이터셋 만들기"

### 3.2 경계 시나리오(Threshold)
- 상황: Lv1 부모를 연결했는데 사용자가 이미 가공 단계를 Lv1로 직접 골라 둔 상태다.
- 결과: 값을 바꾸지 않는다. 사람이 정한 값을 시스템이 되돌리지 않는다.
- 근거: "가공 단계 선택 범위"

### 3.3 실패 시나리오(차단/오류)
- 상황: 데이터셋 이름을 비우고 "데이터셋 만들기"를 누른다.
- 안내: "데이터셋 이름을 적어 주세요"
- 복구: 메타데이터 입력 단계로 이동하고 이름 입력칸에 포커스를 준다.
- 근거: "데이터셋 만들기"

| 가공 단계(Lv) | Lv0 원시 · Lv1 기초 전처리 완료 · Lv2 도출된 2차 산출물 · Lv3 유형화·고차 분석 결과 | 고려대 Data Level 정의 |

| 대표 그림 | 데이터셋을 대표하는 썸네일. 미리보기 축소본이 기본값 | 직접 올린 이미지로 교체 가능 |
