# db — 선언 스키마 SoT

**두 체인이 분리된다.** 섞으면 서로를 막는다.

| 경로 | 담는 것 | 마이그레이션 head |
|---|---|---|
| `platform/` | D1 D2 D3 D4 D5 D6 D8 | 독립 |
| `ai/` | D9 D10 | **독립** |

## 왜 나누나

| | 변경 주기 | 소급 비용 |
|---|---|---|
| 플랫폼 | 느리다 | **높다** — E-00이 "여기서 틀리면 뒤가 전부 소급된다"고 적어뒀다 |
| 온톨로지 | 빠르다 | 낮다 — 다시 적재하면 된다 |

같은 체인에 두면 온톨로지 한 줄 추가가 플랫폼 마이그레이션을 기다리게 된다.

## 규칙

- 도메인별 테이블 소유 + 접두사. 타 도메인 테이블 직접 FK 금지
- **single-head 강제** — 두 체인 각각
- 선언 스키마 ↔ 적용 DB **diff 게이트**
- 정규 ID 타입은 `contracts/schemas/common.json` 에서만 정의
